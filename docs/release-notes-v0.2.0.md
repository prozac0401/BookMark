# WorkBookmark 0.2.0

책갈피를 **목록 또는 포스트잇 스티커**로 볼 수 있습니다. 설정에서 표시 방식을 선택하면 단축키와 트레이 아이콘이 그 방식으로 열립니다. 처음 사용하거나 이전 버전에서 업데이트한 경우에는 기존 목록을 기본으로 유지합니다.

## 변경 사항

- **이동·크기 조절:** 지우지 않은 책갈피마다 독립 스티커를 띄웁니다. 위쪽을 끌어 옮기고 가장자리·모서리로 크기를 조절합니다.
- **작업에 맞는 표시:** 접기·펼치기와 항상 위 표시를 지원하고, 스티커 위치·크기와 표시 상태를 다시 실행할 때 복원합니다. 부드러운 종이색 바탕에 이름, 저장 위치, 메모와 이어가기 버튼을 배치했습니다.
- **같은 책갈피 공유:** 스티커의 **이어가기**로 저장한 작업을 엽니다. 기존 한 줄 메모를 편집할 수 있으며, 목록과 스티커에 같은 내용이 표시됩니다.
- **삭제와 숨기기 구분:** **지우기**는 목록과 스티커에서 함께 지웁니다. **× / Esc**는 해당 스티커를 잠시 숨깁니다. 원본 파일은 지우지 않습니다.
- **삭제 복원:** 각 삭제 후 10초 동안 최근 항목부터 순서대로 되돌릴 수 있습니다. 시간이 지나거나 앱을 다시 실행한 뒤에도 **트레이 → 최근 삭제…**에서 최근 지운 100개 중 선택해 복원할 수 있습니다. 메모와 스티커 배치도 유지됩니다.
- **트레이 조작:** 선택한 방식으로 책갈피 보기, 목록 검색, 스티커 모두 숨기기와 위치 모으기를 제공합니다. 이미 실행 중인 앱을 다시 실행하면 선택한 표시 방식으로 책갈피를 보여 줍니다.

사용하려면 **트레이 → 설정 → 포스트잇 스티커로 보기 → 적용**을 선택하세요. **Ctrl+Alt+J**로 다시 표시하고, 스티커 모드에서도 **트레이 → 목록에서 찾기**로 검색할 수 있습니다. 자세한 사용법은 [빠른 시작](quick-start.ko.md)과 [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

## 다운로드와 업데이트

[GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.0)에서 **WorkBookmark-0.2.0-win-x64.msi**를 받아 실행하세요. 이전 MSI 설치를 자동 교체하며 책갈피·메모·설정과 로그인 자동 실행 선택을 유지합니다. 설치 완료 화면에서 **업무 책갈피 실행** 여부를 선택할 수 있습니다.

설치 없이 사용하려면 **WorkBookmark-0.2.0-win-x64.zip**을 폴더 전체로 풀어 실행하세요. 기존 포터블 앱이 실행 중이면 트레이에서 먼저 종료하세요. 소스 ZIP, 소스 커밋 정보, MSI 검증 JSON과 SHA-256 목록을 함께 제공합니다.

이번 버전은 스티커 배치를 저장하기 위해 DB를 **v5**로 갱신합니다. 기존 데이터 변경 전 `bookmarks.db.pre-migration-….bak` 백업을 데이터 폴더에 남깁니다. **0.1.7은 v5 DB를 읽을 수 없습니다.** 구버전으로 돌아가려면 현재 데이터 폴더를 보존하고 업그레이드 전 백업을 복원해야 합니다. 업그레이드 이후에 만든 기록은 이전 백업에 포함되지 않습니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 확인하세요.

## 검증 범위

Release 빌드 경고 0개·오류 0개, 자동 검사 **529개**를 통과했습니다. 기존 데이터 이전·백업, 쓰기 실패 시 원본 유지, 스티커 배치와 삭제·복원, 비동기 저장·종료 경합을 확인했습니다. 실제 컨트롤 화면과 검사별 로그는 [0.2.0 검증 기록](evidence/stickers-2026-09-22/README.md), 설치 패키지 검사는 배포 파일의 MSI 검증 JSON에서 확인할 수 있습니다.

Office·브라우저 연동, 회사 인증, 화면 배율과 여러 모니터에서의 사용 조건은 [호환성표](compatibility.md)를 함께 확인하세요. 기능 검증과 실제 업무 환경에서의 장기 사용성 평가는 구분합니다.
