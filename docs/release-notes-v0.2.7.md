# WorkBookmark 0.2.7 · 한 줄 스티커 평가판

평상시 스티커를 **메모 한 줄과 오른쪽 화살표 버튼**으로 줄입니다. 화살표 버튼의 툴팁은 **바로가기**이며 저장된 작업을 엽니다. 메모를 편집할 때만 필요한 높이를 확보합니다.

## 한 줄 스티커

- 100% 배율 기준 기본 내용 영역은 **260×36**, 최소 **240×36**입니다. Windows 크기 조절 테두리는 별도로 더해집니다.
- 메모는 **9.5pt 한 줄**로 표시하며 긴 내용은 말줄임표로 줄입니다. 오른쪽 **28×28 화살표 버튼**으로 작업을 엽니다. 버튼에 마우스를 올리면 **바로가기** 안내를 확인할 수 있습니다.
- 메모가 있으면 메모를 제목으로, 없으면 URL·폴더 주소·파일명을 표시합니다. 메모장 보관본의 대체 제목도 유지합니다. 전체 내용은 툴팁·메모 편집·기존 복사 메뉴에서 확인합니다.
- 배경 여백을 끌어 이동하고 테두리를 끌어 크기를 조절합니다. 접기·펼치기·이동·책갈피 지우기·숨기기 등은 우클릭 메뉴에서 사용합니다.

## 메모 편집

제목을 클릭하거나 **Ctrl+E**, 우클릭 **메모 편집**으로 입력합니다. 편집할 때 **폭을 유지**하며 내용 높이가 160보다 작은 창만 170으로 잠시 확대합니다. 이미 내용 높이가 160 이상인 사용자 창은 크기를 바꾸지 않습니다.

**Enter** 또는 창 전환 자동 저장이 성공하거나 **취소 / Esc**를 선택하면 편집 직전 크기·접힘 상태로 돌아갑니다. 편집을 위해 화면 안쪽으로 자동 보정한 위치는 복구하며 사용자가 직접 이동한 위치는 유지합니다. 임시 편집 크기와 자동 위치 보정은 원래 배치를 덮어쓰지 않습니다.

저장 실패 시 초안과 오류 안내, 펼친 편집 영역을 유지합니다. Enter 또는 다음 창 전환으로 다시 저장할 수 있습니다. 한글 조합 중 제출 방지와 한 줄·최대 500자 규칙은 유지합니다.

## 업데이트와 기존 설정

0.2.6에서 **기본 내용 크기 260×88이었던 항목만** 새 한 줄 기본 크기로 줄입니다. 배율별 외곽 크기를 96 DPI 기준으로 정규화한 저장 값도 비교하므로, 화면 배율에 따른 반올림 차이를 반영합니다. 사용자가 조절한 외곽 크기와 선택한 목록/스티커 모드, 위치·모니터·접힘·삭제 항목의 배치는 유지합니다. 삭제 항목을 이 작업 때문에 다시 표시하지 않습니다.

별도 표시 규칙 적용 버전은 **3**입니다. 완료 표시를 저장하기 전에 배치를 저장하며, 저장 실패 후 다시 실행해도 사용자 크기가 반복해서 줄어들지 않도록 처리합니다. 이전 표시 규칙을 처음 적용하는 설정에는 기존 최초 적용 정책을 유지합니다.

**DB v5·설정 파일 버전 1과 0.2.4의 사용자 지정 MSI 설치 경로 보존 수정**을 유지합니다. 이전 MSI의 사용자 지정 경로 이행은 [기존 설치 안내](windows-installer.ko.md)를 따르세요.

## 검증 결과

| 범위 | 결과 |
|---|---|
| Release 빌드 | 경고 0개·오류 0개 |
| 표시·인라인 메모·설정·시작·배치 관련 자동검사 | `--stickers-only` **121개 통과** |
| 100% 화면 | 12개 렌더·시각 검토 완료 |
| 150% 합성 화면 | 5/5 검사 통과·시각 검토 완료 |
| 실제 마우스·한글 IME·실제 150% 창 테두리·다중 모니터 | 미검증 |
| 패키지 구조·추출 파일·해시 | 소스 커밋 후 기존 패키징에서 한 차례 검사하고 결과를 릴리스에 첨부 |

화살표가 빈 버튼으로 그려질 수 있던 문제를 수정하고 일반·마우스 올림·누름·포커스 상태의 아이콘 출력을 회귀 검사에 포함했습니다. [이번 검증 기록](evidence/sticker-single-row-2026-09-27/README.md)에 로그·화면·측정값을 보관합니다.

150% 검사는 네이티브 96 DPI 환경에서 컨트롤의 144 DPI 내용 영역을 합성하고 검사용 프레임 보정을 적용한 결과입니다. 실제 150% 창 테두리·크기 제한·모니터 전환 검증을 대신하지 않습니다. 0.2.6 및 이전 검사 수를 합산하지 않았습니다. 독립적인 Office·브라우저·IPC·캡처와 설치·제거·재부팅 반복 검사는 추가하지 않았습니다.

## 배포 형식

[0.2.7 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.7)에 기존과 같은 6종을 제공합니다: **WorkBookmark-0.2.7-win-x64.msi**, **WorkBookmark-0.2.7-win-x64.zip**, **Source.zip**, **SourceSnapshot.json**, **WorkBookmark-0.2.7-win-x64.validation.json**, **SHA256SUMS.txt**.

위 빌드·UI 검사와 패키징 검증은 별도입니다. 소스 커밋 이후 기존 패키징의 구조·파일 추출 검사 54개를 한 차례 수행하며, 결과는 릴리스 첨부 검증 JSON에서 확인합니다. 소스 커밋은 SourceSnapshot.json, 파일 해시는 SHA256SUMS.txt에 기록합니다. 패키지 검사는 UI 동작 검증을 대신하지 않습니다. 패키지는 서명되지 않았습니다.
