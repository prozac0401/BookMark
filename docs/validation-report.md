# 검증 및 인수 보고서

2026-09-19 · WorkBookmark 0.1.0 · **제한된 시험판**

## 출시 판단

구현과 self-contained win-x64 실행 파일을 제공합니다. 최종 전체 빌드는 경고 0개·오류 0개이며, 자동시험은 Core/Storage 13개, IPC 12개, Desktop 구성요소 16개로 **41개 모두 통과**했습니다. 이 결과는 명세의 실기 Gate 전체 통과를 뜻하지 않습니다. 지원 중인 Windows 11에서의 재검증, 탐색기 다중 탭/Excel 다중 창 반복 시험, 실제 IME 등 필수 시험이 남아 있어 정식 v1로 승인하지 않습니다.

원래 요구사항 문서 3개는 수정하지 않았습니다. 이 시험판 실행 파일을 빌드할 당시에는 Git HEAD가 없는 초기 작업 디렉터리였으므로 빌드 증거에 커밋 번호를 부여하지 않았습니다. 이후 소스와 게시 안내를 main에 반영하고 v0.1.0-preview.1 태그로 식별합니다. 첨부 소스는 Source.zip의 SHA-256으로도 확인할 수 있습니다. ZIP 해시는 배포 폴더의 SHA256SUMS.txt, 실행 파일과 DLL 해시는 [build-manifest.json](evidence/build-manifest.json)에 있습니다.

## 환경과 재현

Windows 11 Pro x64 23H2 build 22631, Microsoft 365 Excel x64 16.0.20326.20144, 메모리 17,060,524,032 bytes, 논리 CPU 4개에서 시험했습니다. 이 Windows Pro 빌드는 이미 업데이트 지원이 종료되어 명세의 지원 중인 OS 조건을 충족하지 않습니다. DRM·UNC 공유·Office 32비트·Excel 미설치 환경은 제공되지 않았습니다. [호환성표](compatibility.md), [환경 원문](evidence/environment.json).

공식 SDK 10.0.401 ZIP의 SHA-512를 확인하여 저장소 안에만 설치했습니다. 런타임은 10.0.12, Microsoft.Data.Sqlite는 10.0.12입니다. NuGet 소스와 lock 파일을 고정했고 최종 locked restore가 통과했습니다. 시험은 실제 dotnet.exe 명령으로 수행했습니다. 제공한 PowerShell 스크립트의 문법은 확인했지만, 이 도구 호스트에서 -File 실행이 출력을 남기지 않아 스크립트 전체 실행 자체를 통과로 집계하지 않았습니다.

재현 명령은 [README](../README.md)에 있습니다. `scripts/build.ps1 -Package`는 복원→빌드→3개 시험 실행기→self-contained publish→실행 ZIP/Source.zip/해시를 생성합니다. 개발용 Probes/WindowsChecks와 합성 fixture는 소스 ZIP에만 포함합니다. SDK, obj/bin, 사용자 DB, Office 잠금 파일은 소스 ZIP에서 제외합니다.

## 실제 연동

- 탐색기 현재 실제 폴더 캡처 및 합성 폴더 열기 요청을 확인했습니다. 파일/폴더 선택, 다중 탭 50회는 미완료입니다.
- 실제 Excel 합성 xlsx의 전체 경로·확정자!$D$127 캡처, 열린 문서를 $F$42로 이동한 뒤 재캡처를 확인했습니다.
- Excel을 정상 종료한 후 배포 worker가 파일을 한 번 열고 확정자!$F$42를 재검증했습니다. Windows가 전면 전환을 거절한 결과는 PositionRestoredFocusPending으로 분리했습니다. 파일 SHA-256은 전후 같았습니다. [증거](evidence/p0-closed-excel-resume.json)
- 서로 다른 두 Excel 프로세스의 동명 파일을 실제 화면에서 A→B→A→B로 활성화하여 **4/4 정확히 캡처**했습니다. [증거](evidence/excel-multi-ui-smoke.json)
- 별도 native 시험 실행기의 50회 전면 활성화 시도는 모두 ForegroundDenied였습니다. **제품 캡처 호출 0회, Gate 차단**입니다. 오대상 0건을 성공률로 해석할 수 없습니다. 같은 프로세스 여러 창 및 요구된 반복 수용시험은 여전히 미완료입니다. [증거](evidence/p0-b-50-separate-process.json)
- Ctrl+Alt+B로 실제 DB 커밋을 확인했고, Ctrl+Alt+J로 실제 최근 목록이 표시됐습니다. 자동화 도구가 toolwindow를 선택 가능한 창 목록에서 제외하여 실제 Enter 재개·메모 조작·한국어 IME 전체 흐름은 완료하지 못했습니다. 화면은 [실제 목록](evidence/recent-live-overlay.jpg)에서 확인할 수 있습니다. 로컬 사용자 경로가 포함된 별도 구성요소 렌더는 공개 자료에서 제외하고 로컬에 보관했습니다.
- 새 elevation 경계가 포함된 최종 배포 EXE의 첫 정상 권한 캡처는 3초 시간초과였습니다. 같은 foreground에서 명시적으로 요청한 수동 후속 1회는 정확한 A/확정자!$F$42를 반환했습니다. 제품이 자동 재시도한 것이 아닙니다. [최초 실패](evidence/final-published-capture.json), [후속 성공](evidence/final-published-capture-followup.json). 초기 지연 원인은 확정하지 않았으며 반복 성능·안정성 검증이 남습니다. 상승 권한·보호된 보기·DRM의 실제 거절 시험은 미실행입니다.

초기 실패/수정 과정의 로그도 보존했습니다. `*-corrected`, `*-final` 및 위에서 직접 연결한 결과를 최신 판정으로 사용합니다. 상세한 P0 경계는 [기술 검증](feasibility-report.md)에 있습니다.
