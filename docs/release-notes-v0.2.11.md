# WorkBookmark 0.2.11 · 책갈피 트리와 색상

관련 책갈피를 스티커와 목록에서 같은 트리로 정리하고, 항목마다 색상을 선택할 수 있습니다. 설치 파일은 [0.2.11 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.11)에서 받으세요.

## 새 기능

- **B를 A 위에 끌어 놓으면 A가 부모, B가 자식**이 됩니다. 하위 항목이 있는 책갈피도 가지 전체를 옮길 수 있습니다. 자기 자신이나 하위 항목 아래로는 옮길 수 없습니다.
- 목록은 전체 활성 책갈피를 들여쓰기로 표시하고 접기·펼치기를 지원합니다. 검색 결과에는 상위 경로도 함께 표시합니다. 빈 영역 또는 하단 안내줄에 놓거나 우클릭 **최상위로 꺼내기**를 선택해 분리합니다.
- 스티커는 부모 아래 자식을 들여써 배치하며 부모 이동 시 하위 스티커도 함께 이동합니다. 부모 후보를 강조 표시하고 **Alt**를 누른 이동은 관계를 바꾸지 않습니다. 크기 조절·일괄 정렬·드래그 취소는 부모 관계를 변경하지 않습니다.
- **우클릭 → 색상**에서 기본·노랑·초록·파랑·분홍·보라·회색을 선택합니다. 부모와 자식의 색상은 각각 유지되며, 목록과 스티커에 같은 색상이 표시됩니다.
- 관계와 색상은 재시작·삭제 복원·재캡처 후에도 유지합니다. 부모만 삭제해도 자식은 계속 접근할 수 있습니다. 저장에 실패하면 기존 관계와 색상을 유지합니다.
- 목록에서만 관계를 바꾼 뒤 종료해도 다음 스티커 표시에서 필요한 묶음을 다시 배치합니다. 관계가 바뀌지 않은 스티커의 사용자 배치는 보존합니다. 메모 초안·사용자 크기·숨김 상태도 유지합니다.

## 데이터 호환성

**DB v7**을 사용합니다. 배포된 0.2.0~0.2.10의 v5 DB와 트리 개발 단계의 v6 DB를 이전할 수 있습니다. 이전 전에 데이터 폴더에 `bookmarks.db.pre-migration-….bak`을 만들고, 트랜잭션으로 변경하므로 실패 시 원본 형식을 보존합니다. 기존 메모·대상 위치·삭제 기록·스티커 크기·배치는 유지합니다.

**0.2.10 이하 실행 파일은 v7 DB를 읽을 수 없습니다.** 구버전으로 돌아가려면 현재 데이터 폴더 전체를 보존한 뒤 이전 전 백업의 복사본을 복원하세요. 이후 추가·수정한 내용은 이전 백업에 포함되지 않습니다. 설정 파일 버전 1과 스티커 표시 규칙 버전 3은 유지합니다.

## 검증

2026년 10월 14일 전체 `scripts/build.ps1`을 실행했습니다. Release 솔루션 빌드 경고·오류 0개, 자동검사 **866개 통과**입니다. Desktop 456개에는 트리 51개, 색상 UI 12개, 색상 앱 연동 6개가 포함됩니다. Core 67개에는 트리 9개와 색상 6개가 포함됩니다. 이전 릴리스 결과를 합산하지 않았습니다.

색상별 스티커·목록, 트리 들여쓰기와 메모 편집 화면을 렌더링해 확인했습니다. **실제 마우스 드래그·색상 메뉴 입력은 Windows 잠금으로 미실행**입니다. 혼합 DPI·한글 IME, MSI 설치·업데이트·제거·재부팅 실기도 미실행이며 [검증 기록](evidence/tree-colors-2026-10-14/README.md)에 자동검사와 구분했습니다. Office·브라우저 실사용 전체를 이번 기능 검증으로 인증하지 않습니다.

## 배포 파일

기존과 같은 6종을 제공합니다. 패키지는 서명되지 않았습니다.

1. `WorkBookmark-0.2.11-win-x64.msi`
2. `WorkBookmark-0.2.11-win-x64.zip`
3. `Source.zip`
4. `SourceSnapshot.json`
5. `WorkBookmark-0.2.11-win-x64.validation.json`
6. `SHA256SUMS.txt`

최종 MSI 구조·관리 추출·파일 해시 검사는 동봉 검증 JSON을 기준으로 합니다. MSI 관리 추출은 실제 설치 시험과 다릅니다. 소스 기준은 SourceSnapshot.json, 파일 지문은 SHA256SUMS.txt에서 확인할 수 있습니다.
