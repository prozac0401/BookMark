# WorkBookmark 0.2.17 · 스티커 픽토그램과 버튼 디자인 개선

**[Windows x64 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.17/WorkBookmark-0.2.17-win-x64.msi)** · [전체 배포 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.17)

스티커 왼쪽 버튼을 역할이 명확한 픽토그램으로 바꾸고, 작은 크기에서도 배경과 아이콘의 가장자리가 매끄럽게 보이도록 다듬었습니다.

- **북마크 위치로 이동:** 청록색 버튼에 창 밖으로 나가는 화살표를 표시합니다. 단독 대각선 화살표 대신 열린 프레임과 화살표를 함께 사용합니다.
- **자식 스티커 펼치기·접기:** 차분한 남색 계열 버튼에 폴더와 오른쪽·아래 방향 꺾쇠를 표시합니다. 추가·삭제로 보일 수 있는 `+ / −`를 없앴으며, 닫힌 폴더와 열린 폴더의 모양도 구분합니다.
- 폴더 제목 옆에는 자식 개수를 표시합니다. 하위 스티커의 연결 표시는 글꼴 기호 대신 부드러운 선으로 그립니다.
- 버튼의 둥근 배경과 픽토그램에 안티앨리어싱을 적용했습니다. 마우스를 올림·누름·키보드 포커스·처리 중·접근 실패 상태도 같은 디자인을 사용합니다.
- 툴팁과 접근성 설명에 **북마크 위치로 이동 / 자식 스티커 펼치기 / 자식 스티커 접기**를 명시합니다. 접근 실패 상태에서도 이동 픽토그램을 유지하고 색상과 안내로 문제를 알립니다.

Microsoft Fluent System Icons의 Open·Folder·Folder Open 벡터를 사용하며 MIT 라이선스 고지를 패키지에 포함합니다. 100% 배율 기준 한 줄 높이 36픽셀·왼쪽 버튼 28픽셀과 0.2.16의 실선 테두리 없는 디자인을 유지합니다. 클릭·끌기·편집·Shift 폴더 묶기, 단축키와 DB v8에는 변경이 없습니다.

## 설치와 검증

이전 버전이 실행 중이면 트레이에서 종료한 뒤 MSI를 실행하거나 포터블 ZIP 전체를 새 폴더에 압축 해제해 실행하세요. 기존 책갈피·메모·설정은 이어서 사용합니다. [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

화면과 자동검사의 확인 범위는 [0.2.17 검증 기록](evidence/release-0.2.17-2026-10-20/README.md), 각 버튼 상태는 [픽토그램 비교 이미지](evidence/release-0.2.17-2026-10-20/ui/sticker-actions-design.png)에서 확인할 수 있습니다. 비교 이미지의 첫 열은 실제 96 DPI 크기이며 뒤의 두 열은 픽셀 확대입니다. 서로 다른 Windows 화면 배율의 실기 시험을 뜻하지 않습니다.

Release 빌드 경고·오류 0개, 기본 자동검사 1,027개와 별도 스티커 표시 포커스 구성요소 검사 8개, 합계 1,035개가 통과했습니다. 아이콘의 구분·가독성과 부드러운 모서리 검사도 포함합니다. 개발 중 집중검사는 중복 집계하지 않습니다.

배포 파일은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종입니다. 패키지는 미서명이며 최종 소스 커밋과 MSI 검사 결과는 첨부 메타데이터를 기준으로 합니다. 실제 MSI 설치·업데이트·제거·재부팅과 한글 IME 실입력, 다른 앱 Alt+Tab과 여러 배율의 모니터 간 조작은 이번 자동검사에 포함하지 않습니다. 이전 검증 기록은 [0.2.16 릴리스 안내](release-notes-v0.2.16.md)에 보존합니다.
