# WorkBookmark 0.2.2

스티커의 **메모 텍스트 영역을 한 번 클릭**하면 바로 같은 자리에서 편집합니다. 메모가 비어 있으면 안내 문구가 표시된 영역을 누르세요.

## 변경 사항

- 스티커의 별도 **메모 추가 / 메모 편집** 버튼을 없애고 메모 본문 클릭으로 편집을 시작합니다. **Ctrl+E**도 계속 사용할 수 있습니다.
- 메모를 누른 스티커 안에 입력칸이 열립니다. **저장 / Enter**로 저장하고 **취소 / Esc**로 편집을 취소합니다. 다른 창을 클릭해도 자동 저장하지 않으며, 저장에 실패하면 입력을 유지합니다.

기본 목록 모드의 메모 입력 방식은 유지합니다. 스티커 사용 설정과 단축키는 [빠른 시작](quick-start.ko.md)과 [사용 매뉴얼](user-manual.ko.md)을 참고하세요.

## 다운로드와 업데이트

[GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.2)에서 **WorkBookmark-0.2.2-win-x64.msi**를 받아 실행하세요. 이전 MSI 설치를 자동 교체하며 책갈피·메모·설정과 로그인 자동 실행 선택을 유지합니다. 기존 포터블 앱은 트레이에서 먼저 종료하세요.

설치 없이 사용하려면 **WorkBookmark-0.2.2-win-x64.zip**을 폴더 전체로 풀고 `WorkBookmark.exe`를 실행하세요.

0.2.0·0.2.1과 같은 **DB v5**를 사용하므로 새 스키마 이전은 없습니다. 스티커 위치·크기·접기 상태도 유지합니다. **0.1.7은 v5 DB를 읽을 수 없으므로** 구버전 복귀에는 이전 백업이 필요합니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 확인하세요.

## 검증 범위

Release 빌드와 Desktop 회귀검사 **197개**를 통과하고 합성 화면 **4개**를 확인했습니다. [이번 검증 기록과 화면](evidence/note-click-2026-09-22/README.md)에 확인 범위를 정리했습니다. 변경하지 않은 Core·어댑터·IPC 등의 검사군은 이번에 재실행하지 않았습니다. 이전 0.2.1의 자동검사 586개와 MSI 구조 검사 54개는 [이전 검증 이력](sticker-fixes-v0.2.1.ko.md)이며, 이번 결과와 합산하지 않습니다.

| 범위 | 0.2.2 결과 |
|---|---|
| Release 빌드 | 통과, 경고 0개·오류 0개 |
| Desktop 회귀검사 | 197개 통과. 빈 메모·저장된 메모의 왼쪽 클릭, 처리 중·오른쪽 클릭 보호, 기존 저장·취소·실패 보존 검사 포함 |
| MSI 구조·파일 해시 | 릴리스에 첨부한 [검증 JSON](https://github.com/prozac0401/BookMark/releases/download/v0.2.2/WorkBookmark-0.2.2-win-x64.validation.json)과 [SHA-256 목록](https://github.com/prozac0401/BookMark/releases/download/v0.2.2/SHA256SUMS.txt) 참조 |
| 합성 화면 확인 | 기본·빈 메모·최소 크기·인라인 메모 편집 4개 확인 |

설치 패키지는 **서명되지 않았습니다**. 실제 사용자 계정 설치·업데이트·제거·재부팅, 실제 마우스와 한글 IME 입력, 여러 모니터·혼합 화면 배율 실기는 미실행입니다. 기존 Office·브라우저·회사 인증의 환경별 확인 범위는 [호환성표](compatibility.md)를 참고하세요. 공개 배포와 전체 업무 환경에서의 검증 완료는 구분합니다.
