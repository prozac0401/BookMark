# WorkBookmark 0.2.1

포스트잇 모드의 표시와 메모 입력을 개선했습니다. 스티커는 시작할 때부터 다른 일반 창 위에 나타나며, 메모도 같은 스티커 안에서 작성합니다.

## 변경 사항

- **누른 스티커만 처리 표시:** 이어가기를 누르면 해당 스티커만 **처리 중…**으로 바뀝니다. 다른 스티커의 버튼과 배치는 그대로 유지합니다. 외부 문서 열기는 한 번에 하나씩 처리합니다.
- **시작 시 표시·항상 위 유지:** 스티커 모드로 실행하면 **Ctrl+Alt+J**를 누르기 전부터 저장된 스티커가 표시됩니다. 이전 버전에서 고정을 해제했던 스티커도 일반 창 위에 표시하며, 고정·해제 버튼은 제거했습니다. **× / Esc**와 **스티커 모두 숨기기**는 계속 사용할 수 있습니다.
- **스티커 안에서 메모 편집:** **메모 추가 / 메모 편집**으로 그 자리에서 입력하고 **저장 / Enter**, **취소 / Esc**로 마칩니다. 밖을 클릭해도 자동 저장하지 않으며, 저장에 실패하면 입력을 유지해 재시도할 수 있습니다. 스티커 모드에서 저장 알림이나 검색 목록의 메모를 선택해도 해당 스티커에서 입력합니다.
- **파일 종류 아이콘:** 스티커 왼쪽 위에 폴더·Office 문서·PDF·웹페이지 등 종류별 아이콘을 표시합니다. 파일 본문을 읽지 않고 Windows에 등록된 종류 아이콘이나 기본 아이콘을 사용합니다.
- **늦게 도착한 메모 조회 처리:** 메모를 여는 동안 책갈피를 삭제하거나 다시 기록한 경우, 이전 조회 결과가 최신 상태를 덮어쓰지 않도록 했습니다.

사용하려면 **트레이 → 설정 → 포스트잇 스티커로 보기 → 적용**을 선택하세요. 기본 표시 방식은 목록입니다. 숨긴 스티커는 **Ctrl+Alt+J**로 다시 표시하고, 검색은 **트레이 → 목록에서 찾기**를 사용합니다. [빠른 시작](quick-start.ko.md) · [설치 및 사용 매뉴얼](user-manual.ko.md)

## 다운로드와 업데이트

[GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.1)에서 **WorkBookmark-0.2.1-win-x64.msi**를 받아 실행하세요. 이전 MSI 설치를 자동 교체하며 책갈피·메모·설정과 로그인 자동 실행 선택을 유지합니다. 기존 포터블 앱은 트레이에서 먼저 종료하세요.

설치 없이 사용하려면 **WorkBookmark-0.2.1-win-x64.zip**을 폴더 전체로 풀고 `WorkBookmark.exe`를 실행하세요. 소스 ZIP, 소스 커밋 정보, MSI 구조 검사 JSON과 SHA-256 목록을 함께 제공합니다.

0.2.0과 같은 **DB v5**를 사용하므로 0.2.0에서 업데이트할 때 새 스키마 이전은 없습니다. 스티커 위치·크기·접기 상태도 유지합니다. 0.1.7 등 이전 버전에서 처음 업데이트하면 v5 이전과 변경 전 백업이 적용됩니다. **0.1.7은 v5 DB를 읽을 수 없으므로** 구버전 복귀에는 이전 백업이 필요합니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 확인하세요.

## 검증 범위

Release 빌드 경고 0개·오류 0개, 자동검사 **586개**, MSI 구조 검사 **54개**를 통과했습니다. 시작 시 자동 표시와 최상단 창 속성, 해당 스티커만 처리 표시, 메모 저장 실패·재시도와 늦은 조회 경합, 파일 종류 아이콘을 검사했습니다. 100% 배율의 합성 화면 **7개**도 확인했습니다. [수정·검증 기록](sticker-fixes-v0.2.1.ko.md)에 근거와 한계를 구분해 기록했습니다.

설치 패키지는 **서명되지 않았습니다**. 실제 사용자 계정 설치·업데이트·제거·재부팅, 실제 한글 IME 입력, 여러 모니터·혼합 화면 배율 실기는 미실행입니다. 기존 Office·브라우저·회사 인증의 환경별 확인 범위는 [호환성표](compatibility.md)를 참고하세요. 공개 배포와 전체 업무 환경에서의 검증 완료는 구분합니다.
