# WorkBookmark 0.2.13 · 제목으로 편집하고 이동하기

폴더와 일반 스티커의 제목 조작을 같은 방식으로 맞췄습니다. 폴더 이름도 메모처럼 해당 스티커 안에서 바로 편집하고, 제목을 잡아 이동할 수 있습니다. [0.2.13 릴리스 다운로드](https://github.com/prozac0401/BookMark/releases/tag/v0.2.13).

## 스티커 조작

| 조작 | 일반 책갈피 | 책갈피 폴더 |
|---|---|---|
| 제목 클릭 / Ctrl+E | 스티커 안에서 메모 편집, 최대 500자 | 스티커 안에서 폴더 이름 편집, 최대 100자 |
| 제목을 누른 채 일정 거리 이상 끌기 | 스티커 이동 | 폴더와 하위 스티커 이동 |
| 오른쪽 버튼 / Ctrl+Enter | 저장한 작업 열기 | 폴더 열기·닫기 |

제목을 짧게 누르면 편집을 시작하고, 이동을 시작한 뒤 놓으면 편집을 열지 않습니다. 배경 여백을 끌어 이동하는 방법도 계속 사용할 수 있습니다. 폴더의 제목 클릭은 이름 편집으로 바뀌었으므로, 자식을 펼치거나 숨길 때는 오른쪽 버튼을 사용하세요.

편집 중에는 **Enter / Ctrl+Enter** 또는 다른 창으로 이동해 저장하고, **취소 / Esc**로 되돌립니다. 한글 조합 중 Enter는 글자를 확정합니다. 폴더 이름은 비워 둘 수 없습니다. 저장에 실패하면 입력한 내용과 오류 안내를 유지하므로 다시 저장할 수 있습니다. 편집 성공·취소 후에는 편집 직전 크기·접힘 상태로 돌아갑니다.

폴더 이름은 **F2**로도 편집합니다. 취소 버튼에 키보드 초점이 있을 때 **Enter**를 누르면 저장하지 않고 취소합니다.

## 폴더와 목록

0.2.12의 묶기 규칙을 유지합니다. B를 폴더 A 위에 놓으면 A 안으로 이동하고, 일반 책갈피 A 위에 놓으면 A와 B를 담는 새 폴더를 만듭니다. 기존 폴더로 옮겨도 열림 상태는 유지하며 새 폴더는 닫힌 상태입니다. **Alt**를 누른 채 이동하면 관계를 바꾸지 않습니다.

목록의 조작은 그대로입니다. 폴더를 **클릭 / Enter / 왼쪽 표시**로 열고 닫고, 우클릭 **폴더 이름 바꾸기**로 이름을 편집합니다. 행을 끌어 폴더로 묶거나 목록 빈 영역에 놓아 최상위로 꺼냅니다. 닫힌 폴더 안까지 검색하며 상위 경로도 함께 표시합니다.

다른 폴더의 이름 편집창이 이미 열려 있더라도 요청한 폴더를 정확하게 편집합니다. 폴더별 초안과 저장 대상을 따로 유지하고, 같은 폴더를 다시 편집하면 해당 초안을 이어갑니다.

## 데이터와 업데이트

**0.2.13은 DB v8을 유지하며 스키마 변경이 없습니다.** 0.2.12에서 업데이트할 때 추가 DB 이전은 없습니다. 폴더 구조·열림 상태·이름·메모·색상·사용자 배치와 설정을 계속 사용합니다.

DB v8은 0.2.12에서 도입했습니다. 0.2.11 이하의 DB를 처음 열 때는 이전 직전 `.bak` 백업을 남깁니다. **0.2.11 이하 실행 파일은 v8 DB를 읽을 수 없습니다.** 그 버전으로 돌아가려면 현재 데이터 폴더를 보존한 뒤 이전 전 백업의 복사본을 복원해야 합니다. 자세한 내용은 [0.2.12의 이전 안내](release-notes-v0.2.12.md)와 [백업·복원 안내](user-manual.ko.md#maintenance)를 참고하세요.

## 검증과 배포

최종 Release 빌드 경고·오류 0개, 전체 자동검사 **970개 통과**입니다. Desktop 551개에는 이번 회귀검사 30개가 포함됩니다. 폴더 집중검사 94개와 폴더 이름 편집·중첩 폴더의 WinForms 렌더링도 확인했습니다. 집중검사는 전체 수치에 중복 합산하지 않았습니다.

제목 이동은 구성요소 이벤트·Windows 메시지로 상태 전환과 클릭 억제를 검사했습니다. 현재 입력 데스크톱의 대상 창 판정 제약으로 실제 마우스 클릭·드래그는 미검증입니다. 실제 설치·업데이트·제거·재부팅, 혼합 DPI·한글 IME 실기도 미실행입니다. 자세한 범위와 로그는 [검증 기록](evidence/folder-interaction-2026-10-14/README.md)을 참고하세요.

배포 파일은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종입니다. 최종 MSI 구조·관리 추출은 첨부 검증 JSON, 소스 커밋과 파일 지문은 SourceSnapshot.json·SHA256SUMS.txt를 따릅니다. 패키지는 미서명입니다.
