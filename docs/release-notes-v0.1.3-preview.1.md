# WorkBookmark 0.1.3 시험판 1

메모장 자동 보관과 Office·브라우저 연결 변경을 포함한 Windows x64 시험판입니다. 배포 태그는 `v0.1.3-preview.1`, 실행 파일 버전은 `0.1.3`, 브라우저 확장 버전은 `0.2.2`입니다.

## 포함된 변경

- 메모장의 새 문서·미저장 변경을 사용자 파일 저장이나 경로 선택 없이 본문과 커서/선택 범위로 보관합니다. 복원 시 앱이 별도 UTF-8 작업 사본을 만듭니다.
- SQLite 스키마 4 이관, 기존 기록 보존, 메모장 본문·선택 검증과 복원본 식별을 추가했습니다.
- Word 본문 위치와 PowerPoint 슬라이드의 캡처·재개 연결을 추가하고 실제 파일 식별 문제를 수정했습니다.
- Chrome·Edge 확장에서 현재 탭 제목·URL을 전달하는 native messaging 연결을 추가했습니다. 확장 팝업은 실제 배정된 단축키를 표시하며, 탭이나 URL이 바뀌면 저장을 거절합니다.
- 탐색기 대상 식별과 진단, 좌표·IPC·폼·브라우저 저장소 연동 검사를 보강했습니다. SumatraPDF 연결 코드는 실험 상태입니다.

## 실행과 업데이트

`WorkBookmark-0.1.3-win-x64.zip`을 새 폴더에 모두 압축 해제하고 `WorkBookmark.exe`를 실행하세요. .NET SDK 설치는 필요하지 않습니다. 기존 앱은 트레이에서 종료한 뒤 새 실행 파일을 사용합니다.

브라우저 연결은 압축에 포함된 [확장 설치 안내](https://github.com/prozac0401/BookMark/blob/v0.1.3-preview.1/browser-extension/README.md)를 따릅니다. 웹페이지 저장은 확장 버튼 또는 확장에 표시된 실제 단축키를 사용합니다.

`Source.zip`은 이 릴리스의 Git 커밋에서 생성합니다. `SHA256SUMS.txt`에는 실행 ZIP·소스 ZIP·실행 파일 해시가 포함됩니다. 메모장 본문은 사용자 로컬 DB에 보관되며, 복원 사본은 `%LOCALAPPDATA%/WorkBookmark/NotepadRecovery`에 만들어집니다.

## 검증 범위

현재 소스의 Release 빌드는 경고 0개·오류 0개로 완료했습니다. 배포 전 검사 13묶음 중 12묶음이 통과했습니다. 브라우저 native host 검사 1묶음은 취소/시간 초과로 실패했고, 동일한 제한으로 1회 재실행해도 실패했습니다. 이 검사는 전체 20초·요청별 4초 기한을 사용합니다. 제한값을 늘려 통과로 처리하지 않았습니다. 별도의 실제 native host→앱→SQLite 검사 15개와 확장 로직 검사 23개는 통과했습니다.

앞선 자동 검사 이력은 19묶음, 343개 검사입니다. 구성요소·API 대역·실제 프로그램 검사 단위가 섞여 있으므로 전체 사용자 시나리오 통과 수를 뜻하지 않습니다. 이번 배포 빌드와 재실행 검사의 결과는 릴리스에 첨부한 `VALIDATION.json`에 별도로 기록합니다.

설치된 메모장의 빈 문서와 한글·이모지·여러 줄 본문 복원에 대한 실제 앱 검사는 통과한 이력이 있습니다. Word·PowerPoint는 문서 초기화 후 일부 실제 검사가 통과했지만, 최초 캡처 시간 초과가 발생한 이력도 남아 있습니다.

## 남은 전체 흐름 검증

| ID | 대상 | 현재 판정 |
|---|---|---|
| H01 | 새 미저장 메모장 → 전역 저장 → 앱 재시작 → 복원 | 판정 보류 |
| H02 | 기존 파일의 미저장 변경·여러 메모장 탭 | 판정 보류 |
| H03 | Chrome 확장 버튼·단축키·URL 복원 | 판정 보류 |
| H04 | Edge 확장 버튼·단축키·URL 복원 | 판정 보류 |
| H05 | 탐색기 여러 창·활성 탭·선택 항목 | 판정 보류 |
| H06 | 실제 한국어 IME 조합·메모·Enter 처리 | 판정 보류 |

6건은 자동화 대상이며 사용자 직접 실행을 필수로 분류하지 않습니다. 초기 시도에서 H01~H03은 도중에, H04~H06은 시작 전에 차단됐습니다. 후속 재시도는 컴퓨터 제어 도구 연결 실패로 6건 모두 시작 전에 중단됐습니다. 당시 CPU 표본은 세 차례 모두 100%였고, 리소스 여유 조건의 검증은 성립하지 않았습니다. CPU 부하와 도구 장애의 인과관계는 확인하지 못했습니다.

전역 저장 후 시험 기록이 생성되지 않고 최근 목록이 표시되지 않는 관측도 있었습니다. 제품의 단축키 처리 문제와 자동화 입력·관측 문제를 아직 분리하지 못했습니다. 이번 릴리스는 이 상태를 공개한 시험판이며 정식 수용시험 완료판이 아닙니다.

탐색기·Excel의 장시간 반복, Office 비트수 차이, UNC·DRM·보호된 보기, 실제 PDF 연결 등 환경별 검증도 남아 있습니다. 자세한 범위는 [호환성표](https://github.com/prozac0401/BookMark/blob/v0.1.3-preview.1/docs/compatibility.md)와 [메모장 검증 기록](https://github.com/prozac0401/BookMark/blob/v0.1.3-preview.1/docs/notepad-snapshot-validation.ko.md)을 참고하세요.
