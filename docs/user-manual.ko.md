# 업무 책갈피 설치 및 사용 매뉴얼

이 안내는 **WorkBookmark 0.2.0**을 기준으로 작성했습니다. 작성일은 2026년 9월 22일입니다.

업무 책갈피는 다시 찾고 싶은 폴더, 문서의 위치, 웹페이지에 표시를 남기는 프로그램입니다. 예를 들어 Excel에서 확인하던 셀을 기록해 두고, 나중에 그 셀로 돌아갈 수 있습니다.

기본 사용법은 다음과 같습니다.

1. 기억할 위치에서 **Ctrl+Alt+B**를 누릅니다.
2. 다시 돌아가고 싶을 때 **Ctrl+Alt+J**를 누릅니다.
3. 목록에서 책갈피를 고르고 **Enter**를 누릅니다. 스티커 모드를 선택했다면 원하는 스티커의 **이어가기**를 누릅니다.

**트레이 → 설정**에서 **목록으로 보기** 또는 **포스트잇 스티커로 보기**를 선택할 수 있습니다. 기본값은 목록이며, 두 방식은 같은 책갈피와 메모를 사용합니다.

`Ctrl+Alt+B`는 Ctrl 키와 Alt 키를 누른 상태에서 B 키를 누르라는 뜻입니다. 아래 설명은 기본 단축키를 기준으로 합니다. 설정에서 바꿨다면 바꾼 키를 사용하세요.

회사 로그인 방식과 보안 설정에 따른 동작 조건은 [환경별 확인 결과](compatibility.md)에서 확인할 수 있습니다.

## 1. 설치 파일 받기

### 사용할 수 있는 PC

기본 대상은 **Windows 11, x64 방식의 64비트 PC**입니다. Windows의 **설정 → 시스템 → 정보 → 시스템 종류**에서 `x64 기반 프로세서`인지 확인할 수 있습니다. Windows 10과 ARM64 PC는 이번 버전의 기본 지원 대상에 포함하지 않습니다.

Excel·Word·PowerPoint의 작업 위치를 기록하려면 해당 프로그램이 PC에 설치되어 있어야 합니다. 웹페이지만 기록할 때는 Office가 필요하지 않습니다.

실행에 필요한 파일은 설치 파일에 모두 들어 있습니다. 별도의 보조 프로그램을 설치할 필요가 없습니다. 설치할 때 관리자 권한도 필요하지 않습니다. 회사 PC에서는 회사의 설치 규칙이 적용됩니다.

### 어떤 파일을 받아야 하나요?

[0.2.0 GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.0)에서 아래 파일 중 하나를 받으세요. 저장소에서 직접 빌드한 경우에는 `artifacts/releases/<빌드시각>/`에 생성됩니다.

| 파일 | 이런 경우에 사용하세요 |
|---|---|
| **`WorkBookmark-0.2.0-win-x64.msi`** | **처음 사용한다면 이 파일을 선택하세요.** 설치와 제거가 쉽고 시작 메뉴에 등록됩니다. 기존 MSI 설치를 업데이트할 때도 이 파일을 사용합니다. |
| `WorkBookmark-0.2.0-win-x64.zip` | 설치 과정 없이 폴더에서 실행하고 싶을 때 선택합니다. 이런 방식을 **포터블**이라고 합니다. |

`Source.zip`과 `Source code`는 프로그램을 만드는 사람을 위한 파일입니다. 일반 사용자는 위 표의 MSI나 ZIP을 받으면 됩니다.

## 2. 설치하고 실행하기

### 방법 A. MSI로 설치하기

1. 기존 포터블 ZIP판이 실행 중이면 먼저 종료합니다. 시계 옆 아이콘을 우클릭하고 **종료**를 누릅니다. 이전 MSI 설치는 설치 프로그램이 자동으로 교체합니다.
2. 받은 `WorkBookmark-0.2.0-win-x64.msi`를 더블클릭합니다. 이전 MSI 버전이 있으면 자동 제거한 뒤 새 버전을 설치합니다. 책갈피와 설정은 유지합니다.
3. 설치가 끝나면 완료 화면의 **업무 책갈피 실행** 체크박스를 확인합니다. 기본으로 선택되어 있습니다.
4. 바로 실행하려면 선택한 채 마칩니다. 나중에 실행하려면 체크를 해제한 뒤 마칩니다.
5. 나중에는 시작 메뉴에서 **WorkBookmark → WorkBookmark**를 선택해 실행합니다.
6. 화면 아래 작업 표시줄의 **시계 옆**에서 **청록색 책갈피 아이콘**을 찾습니다. 숨겨져 있다면 **숨겨진 아이콘 표시** 영역을 펼칩니다.

시계 옆에서 작은 프로그램 아이콘이 모여 있는 곳을 **트레이**라고 합니다. 이 매뉴얼의 “트레이 아이콘 우클릭”은 그곳에 있는 업무 책갈피 아이콘을 마우스 오른쪽 버튼으로 누르라는 뜻입니다.

처음 설치하면 Windows에 로그인할 때 업무 책갈피도 자동으로 실행됩니다. 이전에 자동 실행을 껐다면 그 선택을 유지합니다. 바꾸려면 [자동 실행 설정](#settings)을 참고하세요.

완료 화면의 **업무 책갈피 실행**은 설치 직후 한 번 실행할지만 정합니다. 체크를 해제해도 Windows 로그인 시 자동 실행 설정은 바뀌지 않습니다.

### 방법 B. ZIP으로 실행하기

1. 받은 ZIP 파일을 우클릭하고 **압축을 모두 풀기**를 선택합니다.
2. 압축을 푼 폴더를 계속 사용할 곳에 둡니다.
3. 기존 업무 책갈피가 실행 중이면 트레이에서 **종료**합니다.
4. 새 폴더 안의 **`WorkBookmark.exe`**를 더블클릭합니다.
5. 시계 옆 트레이에서 아이콘을 확인합니다.

ZIP 안에서 바로 실행하거나 `WorkBookmark.exe`만 따로 옮기지 마세요. **압축을 푼 폴더 전체**가 필요합니다. `browser-host` 폴더 안의 파일은 추가 기능용이므로, 평소에는 맨 위 폴더의 `WorkBookmark.exe`를 실행합니다.

포터블도 책갈피 기록은 PC의 사용자 폴더에 따로 저장합니다. 실행 폴더만 USB나 다른 PC로 옮겨도 기록이 함께 옮겨지지는 않습니다. 기록을 옮기는 방법은 [백업 안내](#backup)를 참고하세요.

### 실행 상태 확인하기

트레이 아이콘을 우클릭하고 **설정**을 엽니다. 두 단축키 옆에 **사용 중**이 보이면 준비가 끝났습니다. **등록 실패 · 비활성**이 보이면 [단축키 바꾸기](#settings)를 따라 다른 키를 정합니다.

## 3. 첫 책갈피 만들기와 다시 열기

### 폴더 하나로 연습하기

1. 탐색기에서 평소 사용하는 폴더 하나를 엽니다. **홈**이나 **검색 결과**가 아닌 실제 폴더를 엽니다.
2. 폴더 안의 빈 곳을 눌러 파일 선택을 해제합니다.
3. **Ctrl+Alt+B**를 누릅니다.
4. **책갈피를 남겼습니다**라는 알림이 나오는지 확인합니다.
5. 다른 폴더로 이동합니다.
6. 기본 목록 모드에서 **Ctrl+Alt+J**를 눌러 최근 책갈피 목록을 엽니다.
7. 방금 기록한 폴더가 선택되어 있으면 **Enter**를 누릅니다.
8. 원래 폴더가 다시 열리는지 확인합니다.

### 자주 쓰는 조작

| 하고 싶은 일 | 조작 방법 |
|---|---|
| 현재 위치 기록하기 | 기록할 프로그램을 앞에 띄우고 **Ctrl+Alt+B** |
| 선택한 방식으로 책갈피 보기 | **Ctrl+Alt+J**, 트레이 아이콘 더블클릭 또는 **트레이 → 책갈피 보기** |
| 목록에서 검색하기 | **트레이 → 목록에서 찾기** |
| 목록에서 위아래로 이동하기 | 키보드 **↑ / ↓** |
| 고른 책갈피 열기 | 목록은 **Enter** 또는 항목 한 번 클릭, 스티커는 **이어가기** |
| 목록 닫기 | **Esc** 또는 다른 창 클릭 |
| 메모·삭제 | 목록의 항목 우클릭, 스티커의 **메모 추가 / 메모 편집** 또는 **지우기** |
| 처리 중인 요청 멈추기 | 알림의 **요청 중단** 또는 트레이의 **진행 중 요청 중단** |
| 프로그램 끝내기 | 트레이의 **종료** |

목록 창을 닫아도 프로그램은 계속 실행됩니다. 완전히 끝내려면 트레이에서 **종료**를 누릅니다.

### 포스트잇 스티커 사용하기

**트레이 → 설정 → 포스트잇 스티커로 보기 → 적용**을 선택합니다. 지우지 않은 책갈피가 각각 작은 스티커 창으로 나타납니다. 스티커는 최근 20개로 제한되지 않으므로, 기록이 많을 때는 목록에서 검색하는 방법도 함께 사용할 수 있습니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 위치 옮기기 | 스티커 위쪽을 마우스로 끌어 이동 |
| 크기 바꾸기 | 창 가장자리 또는 모서리를 끌어 조절 |
| 저장한 작업 열기 | **이어가기** 클릭 |
| 작은 크기로 접기 | **접기** 클릭, 다시 보려면 **펼치기** |
| 다른 창 위에 두기 | **고정** 클릭, **고정됨**을 다시 누르면 해제 |
| 한 스티커 잠시 숨기기 | 창의 **×** 또는 **Esc** |
| 전체 스티커 숨기기 | **트레이 → 스티커 모두 숨기기** |
| 숨긴 스티커 다시 보기 | **Ctrl+Alt+J** 또는 **트레이 → 책갈피 보기** |
| 흩어진 위치 정리하기 | **트레이 → 스티커 위치 모으기** |
| 검색·설정·경로 복사 | 스티커의 **•••** 메뉴 |

위치, 펼쳤을 때의 크기, 접기와 고정 상태는 프로그램을 다시 실행해도 유지됩니다. **고정**은 위치를 잠그는 기능이 아니라 다른 프로그램 위에 표시하는 기능입니다.

**지우기**를 누르면 같은 책갈피가 스티커와 목록에서 함께 사라집니다. **× / Esc는 화면에서 숨길 뿐 책갈피를 지우지 않습니다.** 삭제 복원 방법은 [지우기와 되돌리기](#manage)를 참고하세요.

스티커를 선택한 상태에서 **Ctrl+Enter**는 이어가기, **Ctrl+E**는 메모 편집, **Ctrl+Space**는 접기·펼치기, **Ctrl+Shift+T**는 고정·해제입니다. **Ctrl+Delete**로 지우고 **Ctrl+Z**로 10초 이내 삭제를 되돌릴 수 있습니다.

위치를 기록하는 동안에는 완료 알림을 기다리세요. 책갈피로 문서를 열 때는 다른 창을 누르거나 글자를 입력해도 최초 문서 열기와 열림 확인을 계속합니다. 이때 이후의 위치 이동이나 창 활성화는 중단할 수 있으므로, 기록한 위치까지 돌아가려면 문서가 열린 뒤 책갈피를 다시 실행하세요. **요청 중단**을 눌러도 이미 전달된 파일 열기는 나중에 실행될 수 있습니다. 다시 시도하기 전에 대상 프로그램을 확인하세요.

### 알림의 뜻

| 알림 | 뜻 |
|---|---|
| **책갈피를 남겼습니다** | 기록이 PC에 저장되었습니다. |
| **열기를 요청했습니다** | 파일이나 페이지를 열도록 요청했습니다. 실제로 열렸는지는 대상 프로그램에서 확인하세요. |
| **기록한 위치로 이동했습니다** | 기록한 문서 위치로 이동한 것을 확인했습니다. |
| **기록한 위치로 이동했습니다. 문서는 대상 앱에 열려 있습니다** | 위치는 맞게 이동했습니다. 해당 프로그램의 창을 직접 선택하세요. |
| **파일은 열렸지만 기록한 위치로 이동하지 못했습니다** | 파일은 열렸습니다. 셀·본문·슬라이드가 바뀌었는지 확인하세요. |

문서 열기 확인이나 위치 이동 미완료에 대한 반복 알림은 표시하지 않습니다. 확인하지 못한 열기를 성공으로 안내하지는 않으며, 실제 접근 실패 등 조치가 필요한 알림은 계속 표시합니다.

## 4. 프로그램별 사용법

### 4.1 탐색기: 폴더나 파일 기록하기

**폴더 자체**를 기록하려면 폴더 안에서 아무 파일도 선택하지 않은 상태로 **Ctrl+Alt+B**를 누릅니다.

**파일이나 하위 폴더**를 기록하려면 원하는 항목 **하나만 선택**한 뒤 같은 단축키를 누릅니다.

책갈피를 다시 열면 폴더는 탐색기로 열립니다. 문서·사진 등 지원하는 파일은 평소 그 파일을 여는 프로그램으로 열립니다. 실행 파일이나 스크립트, 바로가기 등은 직접 실행하지 않고 파일이 있는 위치를 보여 줍니다.

**홈, 검색 결과, 휴지통, ZIP 내부, 여러 파일 동시 선택**은 지원하지 않습니다. 회사 공유 폴더는 연결되어 있고 사용 권한이 있어야 합니다.

탐색기에서 Excel 파일을 기록하면 **파일 자체**를 기억합니다. 특정 셀까지 기억하려면 Excel에서 그 셀을 선택한 뒤 기록하세요. Word와 PowerPoint도 같습니다.

### 4.2 Excel: 시트와 셀 기억하기

1. PC에 설치된 Excel로 파일을 엽니다. 새 파일이면 먼저 Excel에서 저장합니다.
2. 아래쪽 시트 탭에서 원하는 시트를 고릅니다.
3. 기억할 셀 하나를 선택합니다. 셀에 글자를 입력 중이라면 입력을 먼저 마칩니다.
4. **Ctrl+Alt+B**를 누릅니다.
5. 나중에 목록에서 책갈피를 열면 그 파일의 시트와 셀로 돌아갑니다.

예를 들어 목록에 `매출!D18`이 보이면 **매출 시트의 D18 셀**을 뜻합니다.

**책갈피 저장과 Excel 파일 저장은 다릅니다.** 책갈피는 파일 위치와 셀 주소를 기억합니다. 수정한 셀 내용은 Excel에서 따로 저장해야 합니다. 시트 이름을 바꾸거나 행·열을 추가하면 원하던 내용의 위치가 달라질 수 있으므로 책갈피를 다시 남기세요.

프로그램이 매크로를 직접 실행하지는 않습니다. 다만 파일을 열거나 셀을 선택할 때, 해당 Excel 파일에 원래 설정된 자동 동작이 일어날 수 있습니다.

### 4.3 Word: 읽거나 쓰던 위치 기억하기

1. PC에 설치된 Word로 저장된 문서를 엽니다. 새 문서는 먼저 저장합니다.
2. 본문에서 기억할 곳에 커서를 놓습니다.
3. **Ctrl+Alt+B**를 누릅니다.
4. 나중에 목록에서 책갈피를 열어 그 위치로 돌아갑니다.

글자를 선택한 상태라면 선택한 부분의 **시작 위치**를 기억합니다. 선택한 문장 전체를 다시 선택해 주는 기능은 아닙니다. 머리글·바닥글·주석 위치는 지원하지 않습니다.

문장의 뜻을 기억하는 것이 아니라 문서 안의 문자 위치를 기억합니다. 앞부분에 글을 넣거나 지우면 다른 내용이 나올 수 있습니다. 문서를 크게 고친 뒤에는 책갈피를 다시 남기세요.

### 4.4 PowerPoint: 슬라이드 기억하기

1. PC에 설치된 PowerPoint로 저장된 파일을 엽니다. 새 파일은 먼저 저장합니다.
2. 편집 화면에서 슬라이드 하나를 고릅니다.
3. **Ctrl+Alt+B**를 누릅니다.
4. 나중에 목록에서 책갈피를 열면 해당 슬라이드로 이동합니다.

슬라이드 순서를 바꿔도 같은 슬라이드를 찾습니다. 목록의 번호는 **기록했을 때의 슬라이드 번호**입니다. 슬라이드를 삭제하면 찾지 못할 수 있습니다. 슬라이드 안의 글자 선택이나 발표 진행 상태는 기억하지 않습니다.

Word와 PowerPoint도 수정한 문서 내용은 해당 프로그램에서 따로 저장해야 합니다. 목록에 **저장 당시 미저장 변경**이 보이면, 기록할 때 아직 저장하지 않은 수정 내용이 있었다는 뜻입니다. 그 수정 내용을 업무 책갈피가 보관했다는 뜻은 아닙니다.

### 4.5 메모장: 글 내용까지 보관하기

메모장은 **글 내용과 커서·선택 위치를 함께 보관**합니다. 파일로 저장하지 않은 새 글과 빈 탭도 기록할 수 있습니다.

1. Windows 메모장에서 글을 쓰거나 기존 글을 엽니다.
2. 원하는 위치에 커서를 놓거나 글 일부를 선택합니다.
3. **Ctrl+Alt+B**를 누릅니다. 파일명을 정할 필요는 없습니다.
4. 나중에 책갈피를 열면 **기록 당시 글을 복사한 새 파일**이 열립니다.

원래 파일이나 원래 탭을 덮어쓰지 않습니다. 책갈피를 남긴 뒤 고친 글은 이전 기록에 반영되지 않습니다. 바뀐 글도 보관하려면 **Ctrl+Alt+B**를 다시 누르세요.

같은 제목·내용·선택 위치를 다시 기록하면 기존 책갈피를 갱신합니다. 글 내용이나 선택 위치가 달라지면 새 책갈피를 만듭니다.

복원 파일은 책갈피를 열 때마다 새로 만듭니다. 계속 편집했다면 메모장에서 저장하거나 **다른 이름으로 저장**하세요. 이 파일들은 [데이터 폴더](#backup)의 `NotepadRecovery` 폴더에 있으며 자동으로 지워지지 않습니다.

예전 버전에서 만든 메모장 책갈피는 글 내용을 보관하지 않고 기존 파일만 여는 방식일 수 있습니다.

### 4.6 Edge·Chrome: 웹페이지 기억하기

**브라우저**는 Edge·Chrome처럼 인터넷 페이지를 여는 프로그램입니다. **기본 브라우저**는 웹 주소를 눌렀을 때 자동으로 열리도록 Windows에 정해 둔 프로그램입니다.

1. Edge나 Chrome에서 기억할 웹페이지를 엽니다.
2. 주소 입력과 페이지 이동이 끝나면 페이지 본문을 클릭합니다.
3. **Ctrl+Alt+B**를 누릅니다.
4. 나중에 책갈피를 열면 Windows의 기본 브라우저로 해당 주소를 엽니다.

**브라우저 확장 프로그램은 설치하지 않아도 됩니다.**

주소를 읽지 못한다는 안내가 나오면 직접 입력할 수 있습니다.

1. 브라우저 주소창에서 전체 주소를 복사합니다.
2. 트레이 아이콘 우클릭 → **웹페이지 URL로 추가…**를 누릅니다. URL은 웹페이지의 주소를 뜻합니다.
3. 복사한 주소를 붙여 넣습니다. 주소는 `http://` 또는 `https://`로 시작해야 합니다.
4. 필요하면 **제목 (선택)**을 입력하고 **저장**을 누릅니다.

주소 직접 입력은 다른 브라우저에서 복사한 주소에도 사용할 수 있습니다. 브라우저 설정 화면이나 PC 안의 파일 주소는 이 방법으로 저장할 수 없습니다.

기억하는 것은 **페이지 제목과 주소**입니다. 페이지에서 내려 보던 위치, 입력하던 글, 로그인 상태는 보관하지 않습니다. 주소에 검색 조건이나 `#` 뒤의 위치 정보가 있으면 함께 기록합니다. 다시 열 때 원래 탭이 재사용되거나 원래 브라우저가 열리는 것은 보장하지 않습니다.

### 4.7 회사 사이트의 Office 문서

브라우저 안에서 편집하는 Excel·Word·PowerPoint는 **웹페이지 주소**를 기록합니다. 셀·본문·슬라이드 위치를 기록하려면 문서를 **PC에 설치된 Office 프로그램**으로 열어야 합니다.

1. 회사 사이트에 로그인합니다.
2. 문서를 PC에 설치된 Excel·Word·PowerPoint로 엽니다.
3. 기억할 위치에서 **Ctrl+Alt+B**를 누릅니다.
4. 나중에 책갈피를 엽니다. 문서가 준비되는지 **최대 45초** 동안 확인합니다.
5. 로그인이 필요하다는 안내가 나오면 알림의 **사이트 로그인**을 누르고 로그인을 마칩니다.
6. 문서가 열린 뒤 **같은 책갈피를 다시 실행**하면 기록한 위치로 이동할 수 있습니다.

로그인 중에 클릭하거나 입력한 경우에는 문서가 열렸는지만 확인하고 위치 이동을 멈출 수 있습니다. 이때 별도 알림은 표시하지 않습니다. 기록한 위치로 돌아가려면 문서가 준비된 뒤 위 6번을 따르세요.

45초는 문서 준비를 확인하는 최대 시간입니다. 이 시간 동안 다른 작업을 할 수 있도록 입력 감시와 Office 응답 대기를 분리했습니다. 실제 회사 문서의 로그인과 마우스 반응은 사용 환경에서도 확인해야 합니다.

이 기능은 Office가 문서의 실제 웹 주소를 알려 주는 경우에 사용할 수 있습니다. 회사의 로그인 방식이나 보안 설정에 따라 직접 로그인이 필요할 수 있습니다. 문서 주소가 바뀌었다면 새 주소의 문서를 열어 책갈피를 다시 남깁니다.

### 4.8 PDF 파일

탐색기에서 PDF 파일 하나를 선택하고 **Ctrl+Alt+B**를 누릅니다. 책갈피를 열면 평소 사용하는 PDF 프로그램으로 파일을 엽니다.

PDF의 **페이지 번호까지 기억하는 기능**은 SumatraPDF라는 프로그램을 대상으로 시험 중입니다. Adobe Reader와 Edge PDF 화면의 페이지 위치 복원은 지원하지 않습니다.

## 5. 검색·메모·삭제·파일 위치 변경

### 예전 책갈피 찾기

**트레이 → 목록에서 찾기**를 누르고 위쪽 검색칸에 검색어를 입력합니다. 목록 모드에서는 **Ctrl+Alt+J**로도 엽니다. 파일 이름, 경로, 웹 주소, Excel 시트 이름, 메모에 들어 있는 말로 찾을 수 있습니다. 메모장에 보관한 글 전체를 검색하는 기능은 아닙니다.

기본 목록에는 최근 기록 **20개**가 나옵니다. 더 오래된 기록은 검색으로 찾습니다. 검색 결과는 최대 **100개**까지 나오므로 결과가 많으면 더 구체적인 말을 입력하세요. 한글 입력을 마친 뒤 Enter를 눌러 책갈피를 엽니다.

같은 위치를 다시 기록하면 최근 기록으로 올라오고 기존 메모는 유지됩니다. 책갈피를 열거나 메모만 바꾼 것으로는 목록 순서가 바뀌지 않습니다.

### 메모 붙이기

1. 저장 알림의 **메모**, 목록 항목 우클릭 → **메모**, 또는 스티커의 **메모 추가 / 메모 편집**을 누릅니다.
2. 나중에 할 일을 한 줄로 적습니다. 최대 500자까지 쓸 수 있습니다.
3. **저장** 또는 **Enter**를 누릅니다.

예: `D18부터 다시 확인`, `회의 전 검토`, `표 수정 필요`.

메모 창 밖을 클릭해도 저장됩니다. 쓰던 메모를 취소하려면 **취소** 또는 **Esc**를 누릅니다.

### 파일 경로나 웹 주소 복사하기

목록 항목 우클릭 또는 스티커 **•••** → **전체 경로/URL 복사**를 선택합니다. 메모장 글 보관 항목에는 **보관 ID 복사**가 보입니다. 이때는 파일 경로 대신, 보관한 글을 구분하는 문자와 숫자로 된 표시를 복사합니다.

### 지우기와 되돌리기

1. 목록의 항목을 우클릭하고 **목록에서 지우기**를 누르거나 스티커의 **지우기**를 누릅니다. 같은 책갈피가 두 화면에서 함께 사라집니다.
2. 실수로 지웠다면 **10초 안에** 알림의 **되돌리기 · 10초**를 누릅니다. 트레이의 **삭제 되돌리기**도 사용할 수 있습니다.

여러 개를 연달아 지웠다면 각 삭제 후 10초가 지나기 전까지 가장 최근 항목부터 차례대로 되돌릴 수 있습니다.

10초가 지났거나 프로그램을 다시 실행했다면 **트레이 → 최근 삭제…**를 엽니다. 최근 지운 책갈피 **100개**를 표시합니다. 항목을 고르고 **선택한 책갈피 복원**을 누르면 메모와 기존 스티커 배치도 함께 돌아옵니다.

원본 파일은 지우지 않습니다. 메모장 복원 파일도 그대로 남습니다. 목록·스티커에서 지우기는 저장된 내용을 완전히 삭제하는 기능은 아닙니다. 잠시 화면에서만 치우려면 스티커의 **× / Esc**나 **스티커 모두 숨기기**를 사용하세요.

### 옮긴 파일의 새 위치 알려 주기

파일이나 폴더를 옮기면 기존 책갈피가 열리지 않을 수 있습니다.

1. 기존 책갈피를 한 번 엽니다.
2. **저장한 대상에 접근할 수 없습니다**가 나오면 목록을 다시 엽니다.
3. 해당 항목을 우클릭하고 **위치 다시 지정**을 누릅니다.
4. 옮긴 파일 또는 폴더를 선택합니다.
5. **경로 변경 확인** 창에서 새 위치와 메모를 확인하고 **적용**을 누릅니다.

이 메뉴는 파일이나 폴더에 접근하지 못한 항목에만 보입니다. 웹페이지, 회사 웹 주소의 Office 문서, 메모장 글 보관 항목에는 나오지 않습니다. 새 문서에서 예전 위치를 확인하지 못한다면 원하는 곳을 열고 새 책갈피를 남기세요.

## 6. 표시 방식·단축키·자동 실행 바꾸기

### 목록과 포스트잇 중 선택하기

1. 트레이 아이콘 우클릭 → **설정**을 누릅니다.
2. **목록으로 보기** 또는 **포스트잇 스티커로 보기** 중 하나를 선택합니다.
3. **적용**을 누릅니다. 기존 책갈피와 메모를 선택한 방식으로 보여 줍니다.

기본값은 **목록으로 보기**입니다. **Ctrl+Alt+J**와 트레이 아이콘 더블클릭도 여기서 선택한 방식으로 동작합니다. 스티커 모드에서 잠시 검색하고 싶다면 설정을 바꾸지 않고 **트레이 → 목록에서 찾기**를 사용하세요.

### 단축키 바꾸기

1. 트레이 아이콘 우클릭 → **설정**을 누릅니다.
2. **현재 위치 남기기** 또는 **책갈피 보기**의 입력칸을 누릅니다.
3. 원하는 키 조합을 직접 누릅니다. **Ctrl 또는 Alt**가 포함되어야 합니다.
4. 두 기능에 서로 다른 키를 정합니다.
5. **적용**을 누릅니다.

다른 프로그램이 쓰는 단축키는 등록되지 않을 수 있습니다. 등록하지 못했다는 안내가 나오면 다른 조합을 선택하세요.

### Windows 로그인 때 자동으로 실행하기

**설정 → Windows 로그인 시 실행 · 이 사용자만**을 체크하고 **적용**합니다. 자동 실행을 끄려면 체크를 해제하고 적용합니다.

트레이의 **종료**는 현재 실행만 끝냅니다. 다음 로그인 때도 실행되지 않게 하려면 위 설정을 꺼야 합니다. 설정을 켰는데도 실행되지 않으면 Windows 작업 관리자의 시작 앱 설정도 확인하세요.

## 7. 기록 백업하고 되살리기

**백업**은 기록을 다른 곳에 복사해 두는 일입니다. **복원**은 그 복사본을 다시 가져오는 일입니다.

### 기록은 어디에 있나요?

트레이 아이콘 우클릭 → **설정 → 데이터 폴더**를 누릅니다. 데이터 폴더는 책갈피 기록과 설정을 모아 둔 폴더입니다.

직접 열려면 탐색기의 주소창에 아래 내용을 그대로 붙여 넣고 Enter를 누릅니다.

```text
%LOCALAPPDATA%\WorkBookmark
```

| 파일·폴더 | 들어 있는 내용 |
|---|---|
| `bookmarks.db` | 책갈피, 메모, 문서 위치, 웹 주소, 메모장에 보관한 글, 스티커 배치와 삭제 기록 |
| `settings.json` | 목록·스티커 표시 방식, 단축키 등 프로그램 설정 |
| `bookmarks.db.pre-migration-….bak` | 데이터 형식을 변경하기 직전의 자동 백업 |
| `NotepadRecovery` | 메모장 책갈피를 열 때 만든 복원 파일 |
| `diagnostic.log` 등 | 오류 원인을 찾는 데 쓰는 작업 기록 |

일부 파일과 폴더는 해당 기능을 사용한 뒤에 생깁니다. 다른 파일이 함께 있더라도 백업할 때는 **폴더 전체**를 복사하세요.

일반 문서 책갈피는 원본 문서까지 복사해 두지는 않습니다. 원본 Excel·Word·PowerPoint 파일은 따로 백업해야 합니다. 메모장 글 보관 기능은 글 내용도 함께 보관합니다.

### 백업 순서

1. **설정 → 데이터 폴더**를 열어 둡니다.
2. 메모장 복원 파일을 편집 중이라면 저장하고 닫습니다.
3. 트레이에서 업무 책갈피를 **종료**합니다. 백업 중에는 새 책갈피를 저장하지 않습니다.
4. 탐색기에서 한 단계 위로 이동합니다.
5. **WorkBookmark 폴더 전체**를 다른 위치에 복사합니다. 예를 들어 복사한 폴더 이름을 `WorkBookmark-백업-20260922`로 정합니다.
6. 복사가 끝나면 프로그램을 다시 실행합니다.

프로그램 설치 폴더와 기록 폴더는 다릅니다. 실행 파일이 있는 폴더만 복사하지 말고, 반드시 **설정 → 데이터 폴더**로 연 폴더를 백업하세요.

### 복원 순서

복원하면 목록이 **백업한 때의 상태**로 바뀝니다. 현재 목록과 자동으로 합쳐지지는 않습니다.

1. 업무 책갈피를 종료합니다. 열어 둔 메모장 복원 파일도 저장하고 닫습니다.
2. 현재 데이터 폴더를 먼저 백업합니다.
3. 현재 `WorkBookmark` 폴더의 이름을 `WorkBookmark-복원전-날짜`처럼 바꾸어 보관합니다.
4. 되살릴 백업 폴더를 원래 위치로 복사하고 이름을 **`WorkBookmark`**로 정합니다.
5. `%LOCALAPPDATA%\WorkBookmark` 바로 안에 `bookmarks.db`가 있는지 확인합니다. 같은 이름의 폴더가 두 겹으로 생기지 않게 합니다.
6. 프로그램을 실행해 책갈피와 메모가 돌아왔는지 확인합니다.
7. 설정에서 로그인 자동 실행 상태를 다시 확인합니다.

다른 PC로 옮겼다면 원본 문서의 위치와 접근 권한도 확인해야 합니다. 추가 브라우저 확장을 쓴다면 연결 설정을 다시 해야 할 수 있습니다.

### 백업 파일에 들어 있는 정보

기록을 외부 서비스에 자동으로 보내거나 다른 PC와 맞추는 기능은 없습니다. 웹페이지나 회사 웹 문서를 열 때는 해당 사이트에 연결합니다.

백업에는 메모장 글과 웹 주소가 들어 있습니다. 웹 주소에 로그인·공유용 정보가 들어 있다면 그것도 함께 기록됩니다. 백업은 업무 문서처럼 관리하세요. 오류 확인용 파일인 `diagnostic.log`에는 원본 경로·웹 주소·메모·문서 본문을 남기지 않습니다.

<a id="maintenance"></a>

## 8. 업데이트와 프로그램 제거

### 새 버전으로 바꾸기

먼저 기록을 백업하세요.

| 사용 중인 방식 | 업데이트 방법 |
|---|---|
| MSI 설치 | 더 높은 버전의 MSI를 실행합니다. 이전 MSI 설치를 자동 제거한 뒤 새 버전을 설치하고 책갈피와 설정을 유지합니다. 완료 화면에서 **업무 책갈피 실행** 여부를 고릅니다. |
| 포터블 ZIP | 새 ZIP을 새 폴더에 모두 풉니다. 기존 프로그램을 종료한 뒤 새 폴더의 `WorkBookmark.exe`를 실행합니다. |

포터블의 실행 위치를 바꿨다면 새 프로그램의 **설정**에서 자동 실행을 확인하고 **적용**합니다. 추가 브라우저 확장을 쓰는 경우에는 새 실행 위치에 맞게 연결 설정도 다시 합니다.

포터블에서 MSI로 바꿔도 같은 Windows 사용자 계정이면 기존 기록을 이어서 사용합니다. 먼저 포터블 프로그램을 종료하고 MSI를 설치하세요.

MSI 업데이트 전에 기존 MSI를 따로 제거할 필요는 없습니다. 포터블 ZIP을 풀었던 폴더는 자동 제거하지 않습니다.

MSI는 낮은 버전으로 덮어쓰는 설치를 막습니다. 같은 버전의 MSI를 다시 실행하면 Windows의 설치 관리 방식에 따라 처리됩니다.

### 0.2.0 데이터 갱신과 구버전 복귀

0.2.0을 처음 실행하면 스티커 배치를 저장할 수 있도록 DB 형식을 **v5**로 갱신합니다. 기존 책갈피·메모·삭제 기록은 유지하고, 갱신 직전 데이터는 데이터 폴더의 `bookmarks.db.pre-migration-….bak`에 보관합니다.

**0.1.7은 갱신된 v5 DB를 읽을 수 없습니다.** 실행 파일만 구버전으로 바꾸면 기록을 열 수 없습니다. 구버전으로 돌아가야 한다면 앱을 종료하고 현재 데이터 폴더 전체를 먼저 보존한 뒤, 업그레이드 전 백업을 복원해야 합니다. 자동 `.bak` 파일을 사용할 때도 원본을 보관하고 복사본을 `bookmarks.db`로 복원합니다. 업그레이드 이후에 저장한 책갈피와 메모는 그 이전 백업에 포함되지 않습니다.

### 프로그램 제거하기

| 사용 중인 방식 | 제거 방법 |
|---|---|
| MSI 설치 | Windows **설정 → 앱 → 설치된 앱 → WorkBookmark → 제거**를 선택합니다. 제어판의 **프로그램 및 기능**에서도 제거할 수 있습니다. |
| 포터블 ZIP | 업무 책갈피 설정에서 자동 실행을 끄고 **적용**합니다. 트레이에서 종료한 뒤 압축을 풀었던 실행 폴더를 삭제합니다. |

**프로그램을 제거해도 책갈피와 메모는 남습니다.** 같은 사용자 계정에 다시 설치하면 이어서 사용할 수 있습니다.

기록도 모두 지우려면 필요한 자료를 백업한 뒤, 프로그램을 제거·종료하고 `%LOCALAPPDATA%\WorkBookmark` 폴더를 별도로 삭제합니다. 메모장에 보관한 글과 복원 파일도 함께 없어집니다. 다른 곳에 만들어 둔 백업은 별도로 남습니다.

추가 브라우저 확장을 설치했다면 프로그램 파일을 지우기 전에 [확장 안내](../browser-extension/README.md)의 **등록 해제** 절차를 진행하고 브라우저에서도 확장을 제거합니다.

## 9. 문제가 생겼을 때

| 문제 | 해결 방법 |
|---|---|
| 실행했는데 큰 창이 안 나와요. | 시계 옆 트레이에서 실행되는 프로그램입니다. 숨겨진 아이콘을 확인하거나 Ctrl+Alt+J로 선택한 목록·스티커를 표시하세요. |
| 새 실행 파일을 눌렀는데 기존 화면만 떠요. | 이미 실행 중이면 그 프로그램의 선택된 표시 방식을 보여 줍니다. 기존 프로그램을 트레이에서 종료한 뒤 새 파일을 실행하세요. |
| 스티커 대신 목록이 나와요. | **설정 → 포스트잇 스티커로 보기 → 적용**을 선택하세요. 기본값은 목록입니다. |
| 스티커가 안 보여요. | **Ctrl+Alt+J**로 숨긴 스티커를 표시하세요. 위치를 정리하려면 **트레이 → 스티커 위치 모으기**를 사용하세요. |
| 스티커의 ×를 눌렀는데 목록에 남아 있어요. | ×와 Esc는 숨기기입니다. 책갈피를 지우려면 스티커의 **지우기**를 누르세요. |
| 실수로 지웠는데 되돌리기 알림이 사라졌어요. | **트레이 → 최근 삭제…**에서 항목을 고르고 **선택한 책갈피 복원**을 누르세요. |
| 단축키가 안 돼요. | 프로그램이 실행 중인지 확인하세요. **설정**에서 단축키 옆의 등록 상태를 보고 다른 키로 바꿔 보세요. |
| 현재 위치를 정확히 확인하지 못했다고 나와요. | 기록할 창을 앞에 띄우고 다시 누르세요. 확인하는 동안 다른 창이나 탭을 누르지 마세요. |
| 파일을 하나만 선택하라고 나와요. | 여러 파일의 선택을 풀고 하나만 고르세요. 폴더 자체를 기록하려면 파일 선택을 모두 해제하세요. |
| 파일로 저장한 뒤 기록하라고 나와요. | 새 Office 문서를 먼저 저장하세요. 메모장 글 보관은 파일 저장 없이 사용할 수 있습니다. |
| 편집이나 대화상자를 마치라고 나와요. | 셀 입력이나 안내 창의 처리를 마친 뒤 다시 시도하세요. |
| 웹페이지 주소를 읽지 못해요. | 주소 입력과 페이지 이동을 마친 뒤 본문에서 기록하세요. 계속 실패하면 **웹페이지 URL로 추가…**를 사용하세요. |
| 회사 웹 문서가 안 열려요. | 문서 준비를 최대 45초 기다립니다. **사이트 로그인**으로 로그인한 뒤 책갈피를 다시 실행하세요. |
| 파일이 없어졌거나 옮겨졌어요. | 파일이 실제로 있는지 확인하세요. 책갈피 실행에 실패한 뒤 **위치 다시 지정**으로 새 위치를 고르세요. |
| 파일은 열렸는데 위치가 달라요. | 시트 이름·본문·슬라이드가 바뀌었는지 확인하세요. 원하는 곳에서 새 책갈피를 남기세요. |
| 예전 책갈피가 목록에 없어요. | 기본 목록은 최근 20개입니다. 파일 이름이나 메모로 검색하세요. |
| 메모장 파일이 여러 개 생겼어요. | 책갈피를 열 때마다 새 복원 파일을 만듭니다. 필요한 수정 내용을 저장한 뒤 불필요한 파일만 정리하세요. |
| 자동 실행이 안 돼요. | 앱 설정의 자동 실행을 켜고 적용하세요. Windows 시작 앱 설정과 실행 파일 위치도 확인하세요. |
| 저장하지 못했거나 시작하지 못했다고 나와요. | PC의 남은 저장 공간과 데이터 폴더에 파일을 쓸 수 있는지 확인하세요. 기존 기록 폴더를 보존하고 오류 기록을 확인하세요. |
| 보호된 문서나 회사 PC에서 작동하지 않아요. | 문서 보호나 회사 보안 설정 때문에 제한될 수 있습니다. 해당 문서를 사용할 수 있는지 PC 담당자에게 확인하세요. |
| Windows가 설치 파일의 실행을 제한해요. | 현재 배포 파일에는 제작자를 확인하는 전자 서명이 없습니다. 다운로드 출처와 회사의 설치 허용 절차를 확인하세요. |

문제를 문의할 때는 **프로그램 버전, Windows 버전, 사용한 프로그램, 수행한 순서, 알림 문구, 발생 시각**을 함께 적어 주세요.

오류 기록은 **트레이 → 설정 → 진단 로그**를 누르면 나오는 폴더의 `diagnostic.log`에서 확인할 수 있습니다. 이 버튼은 로그가 있는 폴더를 엽니다. 책갈피 기록 파일이나 메모장 복원 파일에는 업무 내용이 들어 있을 수 있으므로 오류 기록과 구분하세요.

## 10. 추가 기능과 자세한 안내

### 선택 사항: 브라우저 확장

**확장 프로그램**은 브라우저에 버튼이나 기능을 더하는 도구입니다.

브라우저 도구 모음에서 **이 페이지 저장** 버튼을 쓰고 싶다면 확장 프로그램을 추가할 수 있습니다. 기본 단축키 **Ctrl+Alt+B**는 확장 설치 없이 사용할 수 있습니다.

확장을 설치하려면 [브라우저 확장 설치 안내](../browser-extension/README.md)를 따릅니다. 확장 설치와 PC 연결 설정이 모두 필요합니다. 회사 PC에서는 담당자에게 설치 가능 여부를 확인하세요.

확장 버튼의 단축키와 업무 책갈피의 단축키는 따로 정합니다. 확장의 새 설치 기본 제안은 **Ctrl+Shift+9**이며, 실제 사용할 키는 확장 창에 표시됩니다. 확장으로 저장할 때도 업무 책갈피 프로그램이 실행 중이어야 합니다.
