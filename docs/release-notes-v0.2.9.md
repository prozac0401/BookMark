# WorkBookmark 0.2.9 · 스티커 토글·정렬 로컬 릴리스 준비본

스티커 모드에서 **Ctrl+Alt+J로 전체 표시·숨기기를 전환**하고, 주변 스티커와 **자석처럼 행·열을 맞추거나 가로·세로·격자로 한꺼번에 정렬**할 수 있습니다.

**2026년 10월 6일 기준 로컬 릴리스 준비본이며 공개 배포 전입니다.** 이전 공개 버전은 [0.2.8](https://github.com/prozac0401/BookMark/releases/tag/v0.2.8)입니다. 이번 빌드·자동검사·패키지 확인 범위와 로컬 산출물 위치는 [검증 기록](evidence/sticker-alignment-2026-10-06/README.md)에 기록합니다.

## 변경 사항

### 표시·숨기기 단축키

- 스티커 모드에서 **Ctrl+Alt+J**를 누르면 스티커가 하나라도 보일 때 **모두 숨기고**, 모두 숨겨져 있을 때 **모두 표시**합니다. 일부만 숨겼다면 첫 입력으로 나머지도 숨기고, 다음 입력으로 전체를 표시합니다.
- **설정 → 책갈피 보기**에 지정한 사용자 단축키에도 같은 동작을 적용합니다. 목록 모드에서는 기존처럼 목록을 엽니다.
- **트레이 → 책갈피 보기**와 트레이 아이콘 더블클릭은 항상 전체 스티커를 표시합니다. 일부만 숨긴 상태에서도 이 동작으로 한 번에 모두 표시할 수 있습니다.
- 숨기기는 책갈피를 지우지 않습니다. 위치·크기·접힘·메모를 유지합니다.

### 자석 정렬

- 스티커의 배경 여백을 끌어 가까운 스티커의 왼쪽·오른쪽·위·아래 가장자리와 행·열을 맞추거나 일정한 간격으로 나란히 놓습니다. 보이는 주변 스티커만 정렬 대상입니다.
- 자석 정렬은 **기본으로 켜져 있습니다**. 100% 화면 배율에서 **12픽셀 이내**로 가까워지면 붙고, 나란히 둘 때 **8픽셀 간격**을 사용합니다. 이동 중인 스티커의 화면 배율에 따라 범위와 간격을 조절합니다.
- **Alt를 누른 채 이동**하면 일시적으로 자유 이동합니다. 계속 끄려면 **트레이 → 설정 → 스티커 자석 정렬**을 해제하고 적용합니다.
- 이동을 마친 위치는 기존 스티커 배치 저장 방식으로 보존합니다.

### 일괄 정렬

**트레이 → 스티커 위치 모으기**에서 다음 중 하나를 고릅니다. 마우스가 있는 모니터에 숨긴 스티커까지 모두 표시하고 최근 저장 순으로 배치합니다.

| 옵션 | 동작 |
|---|---|
| 격자로 정렬 | 가장 큰 스티커의 크기에 맞춰 일정한 행·열로 배치 |
| 가로로 정렬 | 왼쪽부터 배치하고 공간이 부족하면 다음 행으로 이동 |
| 세로로 정렬 | 위부터 배치하고 공간이 부족하면 다음 열로 이동 |

크기·메모·접힘 상태를 유지하고 새 위치를 저장합니다. 한 화면에 모두 들어가지 않으면 위치를 조금씩 어긋나게 겹쳐 놓습니다.

## 데이터와 설정 호환성

**DB v5, 설정 파일 버전 1, 스티커 표시 규칙 버전 3을 유지합니다.** 0.2.0~0.2.8에서 업데이트할 때 새 DB 스키마 이전은 없습니다. 기존 책갈피·메모·삭제 기록·사용자 크기·표시 모드·단축키·자동 실행 설정을 보존합니다. 일괄 정렬은 사용자가 실행할 때만 기존 배치를 바꿉니다.

설정에는 선택 항목 **`StickerSnapEnabled`**를 추가합니다. 기존 `settings.json`에 항목이 없으면 `true`로 읽고, 설정에서 끈 값은 저장·재실행 후에도 유지합니다. 0.2.7의 한 줄 스티커·편집 중 일시 확대, 0.2.8의 Whale 지원, 0.2.4의 사용자 지정 MSI 설치 경로 보존 수정도 유지합니다.

0.2.6 기본 크기에서 한 줄 크기로 바꾸는 기존 표시 규칙과 옛 설정 최초 적용 정책은 그대로입니다. 0.1.7은 DB v5를 읽을 수 없으므로 구버전 복귀에는 업그레이드 전 백업이 필요합니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 참고하세요.

## 검증 범위

버전 0.2.9에서 전체 `scripts/build.ps1` 실행이 성공했습니다. 이후 표시 취소 회귀 검사를 추가한 최종 Desktop Release 빌드도 **경고 0개·오류 0개**, Desktop 검사 **351/351개 통과**를 확인했습니다. 전체 자동검사는 **746개 통과**이며, 앞선 Desktop 345개를 최종 351개 결과로 교체해 집계했습니다. 반복 실행 수를 중복 합산하지 않았습니다.

| 자동검사 범위 | 통과 수 |
|---|---:|
| Core·Storage | 52 |
| IPC | 17 |
| Desktop | 351 |
| Adapter | 10 |
| Excel evidence | 13 |
| Capture session | 14 |
| Word | 24 |
| Office URL | 103 |
| Browser | 34 |
| Notepad | 28 |
| PDF | 28 |
| BrowserHost | 27 |
| Browser SQLite | 15 |
| 브라우저 확장 JavaScript | 23 |
| Ownership | 7 |
| **합계** | **746** |

소스 커밋 전 검증용 self-contained 빌드의 `WorkBookmark.dll`로 격리한 실제 앱 컨텍스트를 실행하고, 사용자 지정 보기 단축키 **Ctrl+Alt+Shift+F16**을 Windows `SendInput`으로 입력했습니다. 스티커 **2개 표시 → 모두 숨김 → 2개 표시**와 같은 위치·메모 유지, 정상 종료 코드 **0**을 확인했습니다. 검증용 빌드의 96 DPI 설정 화면도 렌더링해 확인했습니다. 이후 Commit 모드 패키지는 Git 메타데이터가 달라질 수 있으며, 해당 패키지의 네이티브 단축키 실기는 별도로 수행하지 않았습니다.

**기본 Ctrl+Alt+J 직접 입력, 실제 마우스 드래그·Alt 드래그·혼합 화면 배율의 모니터 간 이동·한글 입력기 조합과 이번 MSI 설치·업데이트 실기는 아직 미검증입니다.** 사용자 지정 단축키 실기는 같은 설정 경로의 토글 동작을 확인한 범위입니다. 자동검사는 실제 마우스 입력이나 설치 실기를 대신하지 않습니다. 이전 Whale 일반 창에서의 접근성 API 저장·재열기도 미검증 상태입니다. 상세 로그와 패키지 확인 범위는 [검증 기록](evidence/sticker-alignment-2026-10-06/README.md)을 참고하세요.

## 로컬 배포 준비

기존과 같은 아래 **6종**을 `artifacts/releases/<빌드시각>/`에 준비합니다. 공개 릴리스 업로드는 아직 수행하지 않았습니다.

1. `WorkBookmark-0.2.9-win-x64.msi`
2. `WorkBookmark-0.2.9-win-x64.zip`
3. `Source.zip`
4. `SourceSnapshot.json`
5. `WorkBookmark-0.2.9-win-x64.validation.json`
6. `SHA256SUMS.txt`

소스 기준과 포함 방식은 `SourceSnapshot.json`, 패키지 검사는 검증 JSON, 파일 해시는 `SHA256SUMS.txt`에서 확인합니다. 최종 패키지 위치와 결과는 [검증 기록](evidence/sticker-alignment-2026-10-06/README.md)을 참고하세요. 패키지는 서명되지 않았습니다. 0.2.3 이하의 사용자 지정 설치 경로는 [기존 MSI 이행 안내](windows-installer.ko.md)를 따르세요.
