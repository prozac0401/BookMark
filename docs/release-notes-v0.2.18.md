# WorkBookmark 0.2.18 · 자석 드래그와 트리 확장 공간 개선

**[Windows x64 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.18/WorkBookmark-0.2.18-win-x64.msi)** · [전체 배포 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.18)

자석 정렬을 켠 채 스티커를 조금씩 끌면 제자리에 붙잡히던 현상을 수정했습니다. 또한 폴더를 펼칠 때 주변 스티커가 자식들과 겹치지 않도록 공간을 확보합니다.

- **자석에서 자연스럽게 이동:** 드래그 시작점과 실제 마우스 위치를 기준으로 이동량을 누적합니다. 작은 움직임을 이어 가도 붙는 범위에서 빠져나오며, Alt 자유 이동과 기존 자석 간격·붙는 범위는 유지합니다.
- **트리 전체 바운딩박스 확보:** 펼친 트리 전체를 감싸는 사각형을 확장 영역으로 사용합니다. 자식 사이의 빈 공간에 있던 스티커까지 영역 밖으로 이동합니다. 다른 트리에 속한 스티커는 숨겨진 자식까지 같은 거리로 함께 이동합니다.
- **임시 이동과 원위치 복구:** 폴더를 접으면 주변 트리가 원래 위치로 돌아갑니다. 여러 폴더를 동시에 펼치거나 중첩 폴더를 열고 닫아도 남아 있는 확장 영역을 피합니다. 임시 이동은 저장된 배치를 덮어쓰지 않으며, 다시 시작할 때 펼침 상태에 맞춰 계산합니다.
- **직접 정한 위치 유지:** 임시 이동된 스티커를 직접 끌어 놓으면 새 위치를 저장합니다. 이동을 취소하면 원래 복구 지점을 유지합니다. 임시 이동된 대상에 스티커를 묶어 새 폴더를 만들 때는 대상이 화면에 보이던 위치를 사용합니다.
- **필요한 공간 재계산:** 펼친 트리를 옮기거나 메모 편집·크기 조절로 차지하는 공간이 달라지면 주변 위치도 갱신합니다. 모니터 경계를 넘는 확장 영역은 주변 트리가 있는 모니터의 작업 영역을 기준으로 피합니다.

화면에 트리 전체를 옮길 빈자리가 부족하면 해당 트리는 기존 위치를 유지합니다. 이때는 일부 폴더를 접거나 위치를 정리해 공간을 확보하세요. 기존 Fluent 픽토그램·한 줄 스티커·단축키·Shift 폴더 묶기와 DB v8에는 변경이 없습니다.

## 설치와 데이터

이전 버전이 실행 중이면 트레이에서 종료한 뒤 MSI를 실행하거나 포터블 ZIP 전체를 새 폴더에 압축 해제해 실행하세요. 기존 책갈피·메모·설정은 이어서 사용하며, 0.2.12~0.2.17에서 업데이트할 때 DB를 다시 이전하지 않습니다. [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

배포 파일은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종입니다. 패키지는 미서명입니다. 소스 기준은 `SourceSnapshot.json`, MSI 검사 결과는 `WorkBookmark-0.2.18-win-x64.validation.json`, 파일 지문은 `SHA256SUMS.txt`에서 확인합니다.

## 검증 범위

Release 빌드 **경고·오류 0개**, 기본 자동검사 **1,091개**와 별도 스티커 표시 포커스 구성요소 검사 **8개**, 합계 **1,099개**가 통과했습니다. 실행 명령과 범위별 결과는 [0.2.18 검증 기록](evidence/release-0.2.18-2026-11-02/README.md)에서 확인할 수 있습니다. 드래그 누적 이동, 전체 바운딩박스 회피, 중첩·다중 확장, 임시 위치 저장 방지, 재시작·수동 이동·새 폴더 위치 보존을 포함합니다.

개발 중 이동·배치 집중 검사 117개, 스티커 검사 349개, 트리 검사 126개, 폴더 검사 101개도 각각 통과했습니다. 이 검사들은 기본 자동검사와 겹치므로 위 합계에 다시 더하지 않습니다. 표시 포커스 검사는 동일 스레드의 구성요소 검사이며 실제 다른 앱 Alt+Tab 시험을 뜻하지 않습니다.

검사는 구성요소·메시지·기하 배치 기반입니다. 실제 마우스·키보드 입력, 한글 IME, 다른 앱 Alt+Tab, 서로 다른 배율의 실제 다중 모니터 조작과 MSI 설치·업데이트·제거·재부팅은 이번 검사의 범위에 포함하지 않습니다. 관리 추출을 통한 파일 대조도 실제 설치 시험과 구분합니다. 이전 검증 기록은 [0.2.17 릴리스 안내](release-notes-v0.2.17.md)에 보존합니다.
