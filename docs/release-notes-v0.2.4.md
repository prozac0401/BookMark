# WorkBookmark 0.2.4 · 설치 경로 수정 평가판

사용자 지정 폴더에 설치한 뒤 복구·제거가 기본 폴더를 사용하던 문제를 수정했습니다. 실제 설치 경로를 사용자 HKCU에 기록하고 유지 관리·후속 업데이트에서 재사용합니다. 유지 관리 중 INSTALLFOLDER를 다르게 지정해도 기존 경로를 유지합니다.

Assets의 `WorkBookmark-0.2.4-win-x64.msi`를 받으세요. Windows x64·현재 사용자 설치이며 .NET 런타임을 포함합니다. 코드 서명은 없습니다. 이번 릴리스는 검증한 MSI를 그대로 제공하며 포터블 ZIP을 새로 제작하지 않았습니다. 기존 0.2.3 ZIP은 이전 릴리스에서 받을 수 있습니다.

**기존 0.2.3 이하를 사용자 지정 경로에 설치했다면:** 데이터를 백업하고 앱을 종료한 뒤, 기존 버전 MSI에 원래 INSTALLFOLDER를 명시하여 제거하세요. 제거 성공을 확인한 후 0.2.4를 새로 설치하세요. 구버전은 경로를 기록하지 않아 새 MSI로 바로 교체하면 원래 폴더에 파일이 남을 수 있습니다. 원래 경로를 추측하거나 폴더를 일괄 삭제하지 마세요. 기본 경로의 0.2.3에서 일반 업데이트는 확인했습니다.

DB v5·책갈피·메모·설정·스티커 제품 동작은 유지합니다. 0.2.0~0.2.3에서 추가 데이터 형식 변환은 없습니다. 0.1.7 복귀에는 갱신 전 DB 백업이 필요합니다.

검증: 자동600·MSI 구조50·일반 사용자 설치 수명주기118검사(14 MSI 작업) PASS. 합성 저장소 호스트에서 패키지 DLL 일치·두 스티커 표시·정상 종료·기존 사용자 DB 해시 보존을 확인했습니다.

**미실행:** 실제 스티커 마우스 입력·한글 IME·창 전환 자동 저장·실패 초안·작업 재개, 재로그인·재부팅·추가 PC·혼합 배율·조직 인증/배포 승인. 자동시험과 화면 표시 확인을 실제 입력 시험으로 분류하지 않습니다.
