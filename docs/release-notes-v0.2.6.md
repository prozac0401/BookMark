# WorkBookmark 0.2.6 · 평가판

평상시 스티커에는 **메모 텍스트와 이어가기만** 남겨 높이를 더 줄입니다. 메모를 편집할 때 필요한 공간을 잠시 확보하고, 편집을 마치면 이전 크기로 돌아갑니다. 기본 폭은 유지하며 내용 영역을 260×88로 줄였습니다.

## 사용 방법

- 기본 내용 영역은 100% 배율 기준 **260×88**, 최소 **240×88**입니다. 네이티브 제목줄·종류 아이콘·접기·지우기 버튼은 기본 화면에서 제거하고 크기 조절 테두리는 유지합니다.
- 배경 여백을 끌어 이동하고 테두리를 끌어 크기를 조절합니다. 우클릭 메뉴의 **스티커 이동**도 사용할 수 있습니다.
- 접기·펼치기, **책갈피 지우기**, **이 스티커 숨기기**, 경로 복사·설정은 우클릭 메뉴에 있습니다. Esc는 스티커 숨기기이며 편집 중에는 먼저 편집을 취소합니다.
- 메모가 있으면 메모를, 없으면 URL·폴더 주소·파일명을 표시하는 제목 규칙은 유지합니다. 메모장 보관본은 기존 보관 제목을 사용합니다.

## 메모 편집과 크기 복귀

제목을 클릭하거나 **Ctrl+E** 또는 우클릭 **메모 편집**으로 입력합니다. **폭은 그대로 유지**하고 내용 높이가 160보다 작을 때만 170으로 펼칩니다. 이미 내용 높이가 160 이상이면 크기를 바꾸지 않습니다.

저장 성공·취소·창 전환 자동 저장 성공 후에는 편집 직전 크기·접힘 상태로 복귀합니다. 편집을 위해 화면 안쪽으로 자동 보정한 위치는 원래대로 돌아가며, 사용자가 직접 이동한 위치는 유지합니다. 편집 중 임시 크기와 자동 위치 보정은 배치에 저장하지 않습니다.

저장 실패 시 **초안·오류 안내와 펼친 편집 영역을 유지**합니다. Enter 또는 다음 창 전환으로 재시도하세요. 기존 Enter 저장, Esc 취소, 한글 조합 중 제출 방지와 최대 500자 규칙은 유지합니다.

## 업데이트와 기존 설정

0.2.5에서 **기본 크기였던 항목만** 새 기본 크기로 줄입니다. 사용자가 조절한 외곽 크기와 선택한 목록/스티커 모드는 유지합니다. 위치·모니터·접힘 상태와 삭제 항목의 배치도 보존하며, 삭제 항목을 화면에 다시 표시하지 않습니다.

표시 규칙을 한 번도 적용하지 않은 이전 설정에는 기존 최초 적용 정책대로 새 기본 크기와 스티커 모드를 적용합니다. 적용 완료는 배치 저장 후에 기록하고, 실패해 재시도해도 사용자 크기가 반복해서 줄어들지 않도록 처리합니다.

**DB v5와 설정 파일 버전 1**은 유지합니다. 별도 표시 규칙 적용 버전은 2입니다. 0.2.4의 사용자 지정 MSI 설치 경로 보존 수정도 유지합니다. 이전 MSI의 사용자 지정 경로 이행은 [기존 설치 안내](windows-installer.ko.md)를 따르세요.

## 배포 형식

[0.2.6 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.6)에 기존과 같은 6종을 제공합니다: **WorkBookmark-0.2.6-win-x64.msi**, **WorkBookmark-0.2.6-win-x64.zip**, **Source.zip**, **SourceSnapshot.json**, **WorkBookmark-0.2.6-win-x64.validation.json**, **SHA256SUMS.txt**.

이 문서의 빌드·UI 검증 결과와 패키징 검증은 별도입니다. 소스 커밋 이후 생성하는 패키지 구조·추출 파일 결과는 첨부 검증 JSON, 소스 커밋은 SourceSnapshot.json, 배포 파일 해시는 SHA256SUMS.txt에서 확인합니다. MSI 검증 JSON은 UI 동작 검증을 대신하지 않습니다. 패키지는 서명되지 않았습니다.
