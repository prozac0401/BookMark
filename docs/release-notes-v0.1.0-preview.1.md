# 업무 책갈피 0.1.0 시험판 1

Windows 탐색기와 설치형 Excel의 작업 위치를 저장하고 다시 여는 트레이 도구의 첫 프리릴리스입니다. **정식 v1 수용시험은 미완료**입니다.

## 포함 기능

- Ctrl+Alt+B: 탐색기의 실제 폴더/단일 선택 항목 또는 Excel의 경로·시트·활성 셀 저장
- Ctrl+Alt+J: 최근 목록 열기, Enter 또는 클릭으로 재개
- 전체 기록 검색, 선택 메모, 삭제·되돌리기, 접근 실패 항목의 경로 재지정
- 사용자별 로컬 SQLite, 작업마다 격리된 STA worker와 시간 제한

## 설치와 실행

첨부한 `WorkBookmark-0.1.0-win-x64.zip`을 새 폴더에 **전부** 압축 해제하고 `WorkBookmark.exe`를 실행하세요. .NET SDK 설치는 필요하지 않습니다. 시작프로그램 등록은 기본 꺼짐입니다.

`Source.zip`은 소스·합성 시험 자료·검증 보고서를 포함합니다. `SHA256SUMS.txt`로 첨부 ZIP과 실행 파일의 SHA-256을 확인할 수 있습니다.

## 확인한 결과

- Release 빌드: 경고 0개, 오류 0개
- 자동시험: Core/Storage 13개 + IPC 12개 + Desktop 구성요소 16개, 총 41개 통과
- 실제 Excel 경로·시트·셀 캡처, 열린 문서 및 종료 후 문서의 셀 이동 확인
- 별도 Excel 두 프로세스의 동명 파일 교대 캡처 4/4 성공
- 명세 수용시험 58개: 통과 8개, 차단 2개, 미실행 48개. 일부 자동 하위 규칙의 성공을 전체 실기 통과로 집계하지 않았습니다.

## 남은 검증과 알려진 한계

- 실제 한국어 IME, 탐색기 다중 탭, Excel 다중 창·50회 반복, 100회 연동 누수/성능 검증이 남아 있습니다.
- native 50회 시험은 Windows의 전면 활성화 거절로 제품 캡처에 진입하지 못했습니다.
- 최종 배포본의 첫 캡처는 3초 시간초과였고, 같은 창의 별도 수동 후속 요청은 성공했습니다. 초기 지연 원인은 아직 확정하지 않았습니다.
- 실제 시험 머신은 Windows 11 Pro 23H2 build 22631, Excel x64 16.0.20326.20144입니다. 해당 Windows 빌드는 지원이 종료되어 지원 중인 Windows 11에서 재검증이 필요합니다.
- Office 32비트, Excel 미설치, UNC·DRM·보호된 보기 등 환경별 검증은 미완료입니다.
- 문서 저장/닫기·셀 내용 쓰기·매크로 직접 실행을 하지 않지만, 파일 열기/셀 이동은 기존 Excel 이벤트·추가 기능·자동저장을 유발할 수 있습니다.
- 경로·메모는 사용자 로컬 DB에 평문 저장됩니다. 시간초과 이후 이미 전달된 외부 작업의 취소를 보장하지 않으며 자동 재실행하지 않습니다.

이번 릴리스는 처음 빌드한 시험판 실행 코드와 동일합니다. 게시를 위해 안내 문서와 릴리스 노트를 갱신했습니다.
