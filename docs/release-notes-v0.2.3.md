# WorkBookmark 0.2.3

스티커에서 메모를 편집하다가 **다른 창이나 스티커로 이동하면 자동 저장**합니다. 별도의 저장 버튼은 표시하지 않습니다.

## 변경 사항

- 메모 본문이나 빈 안내 영역을 한 번 클릭하면 같은 자리에서 편집합니다. **Ctrl+E**도 사용할 수 있습니다.
- 다른 창으로 이동하면 입력한 메모를 저장합니다. 저장이 끝나도 이동한 창에서 계속 작업할 수 있습니다.
- **Enter / Ctrl+Enter**로 바로 저장할 수 있습니다. 저장하기 전에 **취소 / Esc**를 누르면 현재 편집을 취소합니다. 한글 조합 중 Enter는 글자 확정만 합니다.
- 저장하지 못하면 입력한 글과 오류 안내가 남습니다. 스티커로 돌아와 **Enter**를 누르거나 다른 창으로 다시 이동해 재시도하세요.

메모는 기존처럼 한 줄, 최대 500자입니다. 기본 목록 모드의 별도 메모 창은 유지합니다. [빠른 시작](quick-start.ko.md)과 [사용 매뉴얼](user-manual.ko.md)에 사용 방법을 정리했습니다.

## 다운로드와 업데이트

[GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.3)에서 **WorkBookmark-0.2.3-win-x64.msi**를 받아 실행하세요. 이전 MSI 설치를 자동 교체하며 책갈피·메모·설정과 로그인 자동 실행 선택을 유지합니다. 기존 포터블 앱은 트레이에서 먼저 종료하세요.

설치 없이 사용하려면 **WorkBookmark-0.2.3-win-x64.zip**을 폴더 전체로 풀고 `WorkBookmark.exe`를 실행하세요.

0.2.0~0.2.2와 같은 **DB v5**를 사용하므로 새 스키마 이전은 없습니다. 스티커 위치·크기·접기 상태도 유지합니다. **0.1.7은 v5 DB를 읽을 수 없으므로** 구버전 복귀에는 이전 백업이 필요합니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 확인하세요.

## 검증 범위

Release 빌드와 Desktop 회귀검사 **209개**를 통과하고 합성 화면 **4개**를 확인했습니다. [이번 검증 기록과 화면](evidence/note-autosave-2026-09-22/README.md)에 확인 범위를 정리했습니다. 0.2.2의 197개 검사에서 창 전환·저장 실패·재시도·입력 조합·포커스 보호 검사 12개를 추가했습니다. 변경하지 않은 Core·어댑터·IPC 검사군은 이번에 재실행하지 않았으며 이전 결과와 합산하지 않습니다.

| 범위 | 0.2.3 결과 |
|---|---|
| Release 빌드 | 통과, 경고 0개·오류 0개 |
| Desktop 회귀검사 | 209개 통과. 다른 창·스티커로 이동할 때 자동 저장, 실패한 초안 보존과 재시도, 저장 전 취소, 중복 저장 방지, 합성 IME 입력과 포커스 보호 포함 |
| MSI 구조·파일 해시 | 릴리스에 첨부한 [검증 JSON](https://github.com/prozac0401/BookMark/releases/download/v0.2.3/WorkBookmark-0.2.3-win-x64.validation.json)과 [SHA-256 목록](https://github.com/prozac0401/BookMark/releases/download/v0.2.3/SHA256SUMS.txt) 참조 |
| 합성 화면 확인 | 100% 배율의 기본·인라인 메모 편집·저장 실패·최소 크기 편집 4개 확인 |

설치 패키지는 **서명되지 않았습니다**. 실제 사용자 계정 설치·업데이트·제거·재부팅, 실제 마우스와 한글 IME 입력, 여러 모니터·혼합 화면 배율 실기는 미실행입니다. 기존 Office·브라우저·회사 인증의 환경별 확인 범위는 [호환성표](compatibility.md)를 참고하세요. 공개 배포와 전체 업무 환경에서의 검증 완료는 구분합니다.
