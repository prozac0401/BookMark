# 목록 검색·설정 닫기 수정 (2026-10-14)

검색은 처음에 일치 항목의 상위 경로를 임시로 펼친다. 폴더를 조작하면 화면에 보이는 상태의 반대 상태를 명시적으로 요청하고, 저장 후 목록과 스티커에 동일하게 반영한다. 검색어 변경 시 임시 표시 상태는 초기화하며 DB의 폴더 상태는 보존한다. 검색은 계속 일치 항목과 상위 경로만 표시한다.

목록은 활성화를 잃어도 유지한다. Escape·창 닫기·일반 책갈피 재개는 기존처럼 숨긴다. 이는 활성화 변화로 인한 의도치 않은 숨김 경로를 제거하는 수정이며, 사용자 PC에서 원래 현상을 재현했다는 뜻은 아니다.

설정 닫기 버튼은 명시적으로 Close()를 호출하여 미적용 입력을 버린다. 적용은 기존 비동기 저장·실패 표시·재시도·성공 시 닫기를 유지한다.
