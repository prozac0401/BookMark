# 0.1.1 상태 저장 수정 — 2026-09-19

사용자가 저장한 `WorkBookmark_간단_점검표.xlsx`는 읽기 전용으로 확인했습니다. 원본 응답은 성공 14건, 실패 4건이며 Word·PowerPoint·Chrome·Edge에 같은 “이 화면의 작업위치는 아직 지원하지 않습니다” 메시지가 기록되어 있었습니다. 메모장에서 직접 상태를 저장할 수 없다는 메모도 반영했습니다.

## 수정

- **Word·PowerPoint:** Office 컬렉션의 `Item`은 메서드인데 속성으로 호출해 COM 오류가 발생했습니다. 해당 앱의 창·문서·슬라이드 조회를 메서드 호출로 수정했습니다. Excel 호출은 유지했습니다.
- **브라우저:** 보고된 문구는 앱의 전역 Ctrl+Alt+B 처리에서 나옵니다. Chrome·Edge 확장 ID, 호스트 등록, 실행 파일과 연결 채널은 정상입니다. 브라우저에서 전역 단축키를 누르면 **Ctrl+Shift+Y 또는 확장의 ‘이 페이지 저장’**을 안내합니다. 확장 v0.2.1에는 실제 단축키 표시와 호스트 누락·권한·실행 실패별 안내를 추가했습니다. 결과 미확인에 자동 재시도하지 않습니다.
- **메모장:** 저장 단축키 후 원본 파일을 직접 선택하면 파일명·내용 일치와 선택 전후의 내용 지문·커서 위치를 확인하고 문자 위치를 저장합니다. 탭 제목만으로 디스크 경로를 추측하지 않습니다. 재개는 지정한 경로를 메모장에 전달해 파일 열기를 요청합니다. 자동 커서 이동은 제공하지 않습니다.
- **기록 보존:** 스키마 1·2에서 3으로 변경할 때 일관된 백업을 만들고 트랜잭션으로 이관합니다. 이전 종류의 기록·메모·저장 순서를 유지합니다. 파일 선택 중 취소하거나 위치가 바뀌면 저장하지 않습니다. 문서 본문은 영구 저장하지 않습니다.
- **진단·배포:** 캡처 결과 코드를 진단 로그에 남깁니다. 제목·경로·본문은 로그에 추가하지 않습니다. 실행 파일 버전은 0.1.1이고 ZIP도 실제 버전을 사용합니다. 사용자 작성 점검표가 있는 `outputs`는 소스 ZIP에서 제외합니다.

## 메모장 사용과 한계

1. 메모장 문서를 파일로 저장하고 원하는 위치에 커서를 둡니다.
2. **Ctrl+Alt+B**를 누르고 현재 탭의 원본 파일을 선택합니다. 내용이 다르거나 미저장 변경이 있으면 거절합니다.
3. **Ctrl+Alt+J → Enter**로 메모장 파일 열기를 요청합니다. 저장한 문자 위치는 최근 목록에 표시되며, 자동으로 커서를 옮기지는 않습니다.

한글/영문 Windows 메모장의 로컬 파일을 지원합니다. UTF-8 및 BOM이 있는 UTF-16/32, 최대 2Mi UTF-16 문자·8MiB 파일을 받습니다. UNC, 다른 언어의 제목 형식, BOM 없는 레거시 인코딩, 새 미저장 문서, 문서 편집 후 같은 문장 추적은 지원하지 않습니다. 줄바꿈은 문자 위치에서 한 문자로 정규화합니다. 경로 선택을 생략할 수 없는 이유는 현재 Windows 11 메모장의 UIA/MSAA가 전체 파일 경로를 제공하지 않기 때문입니다. 새 편집 영역이라도 이전 세션의 동명·동일 내용 탭일 수 있으므로, 자동 커서 복원 시도는 최종 검토에서 제외했습니다. 초기 복원 프로토타입의 통과 증거는 최종 기능 지원을 뜻하지 않습니다.

## 검증

- 실제 Word: 본문 위치 37 저장·복원, 잘못된 위치 거절, 원본 바이트·Saved 상태 보존 — 4개 통과.
- 실제 PowerPoint: SlideID 257 저장·복원, 없는 ID 거절, 원본 바이트·Saved 상태 보존 — 4개 통과.
- Core/Storage: 기존 13개 및 확장 13개 검사 통과. 이전 스키마 7종 기록 이관·백업·실패 롤백, 메모장 위치별 중복·메모·삭제·재시작·재연결을 포함합니다.
- 브라우저 확장: 17개 자동검사 통과. 설치된 호스트의 프레임 응답도 확인했습니다.
