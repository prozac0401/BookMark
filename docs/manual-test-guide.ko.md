# 현재 구현 실사용 시험 안내

> 최신 변경(0.1.3): 메모장 새 문서·미저장 본문은 파일 선택 없이 자동 보관하고 복원합니다. 이전의 원본 선택/미저장 거절 설명보다 [새 보관 계약](notepad-snapshot-and-test-plan.ko.md)이 우선합니다.

작성 기준: 2026-09-19 현재 소스. **제한된 시험판**이며, 이 문서는 실제 시험을 완료했다는 보고서가 아닙니다. 자동시험과 실제 Windows·Office·브라우저 조작 시험은 별도로 판정합니다.

현재 패키지·설치 경로는 [이번 설치·검증 결과](user-testing-report.ko.md)를 우선합니다. [결과 회신 양식](manual-test-results.ko.md)을 사용할 수 있습니다. 공통 실행법은 [빠른 시작](quick-start.ko.md), 브라우저 설치는 [브라우저 안내](../browser-extension/README.md)를 참고하세요. 공개된 v0.1.0-preview.1은 확장 기능 이전 빌드이므로 아래 전체 시험에는 현재 소스로 만든 패키지를 사용해야 합니다.

## 시험 시작 전

1. ZIP을 새 폴더에 **전체 압축 해제**한 뒤 WorkBookmark.exe를 일반 사용자 권한으로 실행합니다. self-contained 패키지는 SDK를 요구하지 않습니다. 앱과 런타임 파일을 함께 유지합니다.
2. 아래 시험은 실제 업무 파일 대신 합성 파일의 **시험용 복사본**으로 진행합니다. 파일 이동·삭제·시트 삭제·문서 편집은 시험용 복사본에만 합니다.
3. 기존 앱이 실행 중이면 트레이의 **종료**로 먼저 종료합니다. 다른 위치에서 실행한 앱도 같은 사용자 DB를 사용할 수 있습니다.
4. 기존 기록을 지우지 않습니다. 기본 DB는 **%LOCALAPPDATA%\WorkBookmark\bookmarks.db**이고 설정·진단 로그도 같은 폴더에 있습니다. 새 버전은 기존 DB를 이관할 수 있으므로 원래 기록이 중요하면 종료 상태에서 데이터 폴더를 별도로 복사해 보관합니다. 이 문서는 기존 DB 삭제·초기화를 요구하지 않습니다.
5. 각 시험에서 결과를 **통과 / 실패 / 미실행 / 차단**으로 기록합니다. 프로그램이 없으면 미실행, 실행을 시도했지만 정책·전경 활성화 등으로 막혔으면 차단입니다.
6. 캡처 직후에는 결과 알림이 나올 때까지 새 클릭·키 입력을 잠깐 멈춥니다. 캡처 중 대상이 바뀌면 보수적으로 저장을 거절하는 것이 정상입니다. 입력 경쟁 시험은 M23에서 따로 합니다.
7. 모든 항목을 한 번에 끝낼 필요는 없습니다. 우선 M01~M17, M18~M21, M28~M29, M35~M36을 수행하고 결과를 보내도 됩니다. 그 뒤 다중 창·예외·확장 기능을 진행합니다.

Excel A/B에는 **확정자**, **대기자** 시트가 있습니다. 시험 시 Excel 이름 상자에 **D127**, **F42**를 입력하면 해당 셀로 쉽게 이동할 수 있습니다. Word fixture의 두 번째 문단 시작은 저장 메타데이터 기준 오프셋 37이며 앱 표시 예상은 **본문 문자 위치 38**입니다. 실제 Office에서 본문 구조가 달라지면 관찰한 위치를 따로 기록합니다. PPT fixture는 세 슬라이드이며 두 번째 슬라이드 ID는 257입니다.

### 공통 화면·결과 읽는 법

- 저장: **Ctrl+Alt+B**. 최근 목록: **Ctrl+Alt+J**. 브라우저 저장: 확장 버튼의 **이 페이지 저장** 또는 기본 **Ctrl+Shift+Y**.
- 트레이 메뉴: **최근 책갈피 / 삭제 되돌리기 / 진행 중 요청 중단 / 설정 / 종료**. 삭제 되돌리기는 삭제 후 10초 동안만 보입니다.
- 최근 목록 우클릭: **메모 / 전체 경로/URL 복사 / 목록에서 지우기 / 위치 다시 지정**.
- **위치 다시 지정**은 직전 재개 결과가 대상 접근 실패인 파일·폴더·문서 항목에서만 보입니다. 웹페이지에는 보이지 않습니다.
- **열기를 요청했습니다.**는 연결 프로그램에 열기를 요청했다는 뜻입니다. 문서 내부 위치나 웹페이지 로딩까지 확인했다는 뜻은 아닙니다.
- **기록한 위치로 이동했습니다.**는 내부 위치 확인 성공입니다. **기록한 위치로 이동했습니다. 대상 앱 창을 선택해 주세요.**는 위치는 확인했지만 전면 전환이 완료되지 않은 경우입니다.
- **처리 결과를 확인하지 못했습니다. 대상 앱을 확인해 주세요.**는 실패로 확정한 것이 아닙니다. 이미 보낸 열기·이동이 뒤늦게 완료될 수 있습니다. 자동 재시도하지 않는지 확인합니다.
- 최근 순서는 **마지막 캡처 순서**입니다. 단순 재개·목록 열기·메모 수정은 최근 순서를 바꾸지 않아야 합니다.

## M01~M17: 기본 사용·목록·설정

각 항목은 독립적인 회신 ID입니다. 한 항목에 a/b가 있으면 하위 결과도 각각 적습니다.

### M01 — 첫 실행과 안내
수용시험: U01, D09.

**절차:** 기존 트레이 앱을 종료한 뒤 현재 패키지 WorkBookmark.exe를 실행합니다. 트레이 아이콘과 첫 안내를 확인하고 원래 업무 창을 클릭합니다.

**기대:** 관리자 권한 없이 트레이에 상주합니다. 사전 업무 등록을 요구하지 않습니다. 최초 설정의 기본 단축키는 Ctrl+Alt+B / Ctrl+Alt+J입니다. 이미 첫 실행 안내를 본 데이터 폴더라면 안내가 다시 나오지 않아도 정상입니다. 단축키 충돌은 비활성 상태로 안내되어야 합니다.

### M02 — 두 번 실행
수용시험: U14.

**절차:** M01 앱 실행 상태에서 같은 EXE를 다시 실행합니다.

**기대:** 별도 트레이 앱이 중복 상주하지 않고 기존 앱의 최근 목록이 열립니다. 기존 기록을 유지합니다.

### M03 — 메모 없는 기본 중단·재개
수용시험: U02, U03, U04.

**절차:** 탐색기에서 R을 열고 파일 선택을 모두 해제합니다. Ctrl+Alt+B를 한 번 누릅니다. 저장 알림을 기다린 후 탐색기로 다른 폴더에 이동합니다. Ctrl+Alt+J → Enter를 누릅니다.

**기대:** 저장할 때 제목·확인·메모 입력이 없습니다. 저장 알림이 원래 작업 창을 빼앗지 않습니다. 가장 최근 R 폴더 항목이 기본 선택되고 해당 폴더 열기를 요청합니다.

### M04 — 목록 키보드·클릭·닫기
수용시험: U03, U08, U09.

**준비:** 서로 다른 위치의 책갈피 3개 이상.
**절차:** a. Ctrl+Alt+J → 아래/위 방향키 → Enter. b. 다시 목록을 열어 다른 항목을 한 번 클릭. c. 다시 열어 Esc. d. 다시 열어 목록 밖 클릭.

**기대:** Enter/한 번 클릭으로 선택 항목을 재개합니다. Esc/외부 클릭은 목록만 닫습니다. 목록이 닫힌 상태에서 다시 열면 검색어가 비워지고 최근 목록의 첫 항목이 선택됩니다.

### M05 — 메모 저장·길이 제한
수용시험: U05, U08.

**절차:** 항목 우클릭 → **메모** → “한글 시험 메모 01” 입력 → Enter. 다시 열어 확인합니다. 다른 문구로 바꾸고 외부 클릭하여 저장합니다. 마지막으로 500자를 넘는 합성 문구를 붙여 넣습니다.

**기대:** Enter/외부 클릭 저장이 반영됩니다. 메모는 한 줄·최대 500자입니다. 메모를 바꿔도 최근 저장 순서는 바뀌지 않습니다. 저장 실패가 보이면 입력을 남기고 성공으로 표시하지 않아야 합니다. 실패 주입은 자동시험에서 별도로 담당합니다.

### M06 — 메모 취소
수용시험: U05.

**절차:** M05 항목의 메모를 열고 “취소할 문구”로 바꾼 뒤 Esc 또는 **취소**를 누릅니다. 같은 항목을 다시 엽니다.

**기대:** 기존 메모 유지. 책갈피 자체도 유지됩니다. 사용자가 원한 취소를 저장으로 처리하지 않습니다.

### M07 — 실제 한국어 IME
수용시험: U09.

**절차:** a. 최근 목록 검색창에서 한글 조합 중 Enter로 조합을 확정합니다. b. 메모 창에서도 한글 조합 중 Enter로 확정합니다. c. 조합을 마친 후 별도 Enter를 누릅니다. d. 한글 조합 중 외부 클릭도 확인합니다.

**기대:** 조합 확정 Enter 하나가 항목 재개/메모 제출까지 중복 실행하지 않습니다. 조합이 끝난 뒤의 명시적인 Enter는 정상 작동합니다. 외부 클릭 시 완성된 문자가 메모에서 누락되지 않아야 합니다. 사용한 한국어 IME 이름도 회신합니다.

### M08 — 같은 위치 재저장
수용시험: U06.

**절차:** 메모가 있는 항목을 재개합니다. 위치를 바꾸지 않고 다시 Ctrl+Alt+B를 누릅니다. 최근 목록에서 검색합니다.

**기대:** 항목은 한 개입니다. 캡처 시각·최근 순서만 갱신되고 이전 메모를 유지합니다. 알림의 **이전 메모 유지**도 확인합니다.

### M09 — 전체 기록 검색·경로 복사
수용시험: U13, E06.

**절차:** 최근 목록 검색창에 a. 파일명 일부, b. 한글 경로 일부, c. Excel 시트명, d. 메모 일부를 각각 입력합니다. 각 검색 결과를 우클릭 → **전체 경로/URL 복사** → 메모장에 붙여 넣습니다.

**기대:** 해당 문자열이 들어 있는 기록을 찾습니다. 동명 파일 A/B를 전체 경로로 구별할 수 있습니다. 복사 내용은 저장된 전체 경로/URL입니다. 검색은 현재 표시 20개에만 한정되지 않습니다. URL 검색은 M46 이후 추가 확인합니다.

### M10 — 최근 20개·순서·선택 유지
수용시험: U08, U13.

**절차:** R/기록01~기록21을 차례로 열어 각각 저장합니다. 목록에서 21이 먼저 보이는지 확인합니다. 오래된 기록01을 검색하여 메모 수정·재개한 뒤 검색을 지워 순서를 확인합니다. 목록에서 중간 항목을 선택한 채 메모 편집 후 목록을 다시 확인합니다.

**기대:** 빈 검색은 최근 20개, 검색은 전체 기록에서 최대 100개입니다. 메모/재개만으로 캡처 순서가 바뀌지 않습니다. 목록 갱신 중 보이는 선택이 엉뚱한 항목으로 바뀌면 실패로 기록합니다. **21개 이상 상태 문구에는 아래 알려진 표시 문제가 있으므로 화면 문구와 실제 개수를 별도로 적습니다.**

### M11 — 삭제 후 10초 안 되돌리기
수용시험: U10.

**절차:** 메모가 있는 시험 항목 우클릭 → **목록에서 지우기** → 10초 안 알림 **되돌리기 · 10초**를 누릅니다. 같은 시험을 트레이 **삭제 되돌리기**로 한 번 더 수행합니다.

**기대:** 삭제는 목록에서 숨기기만 합니다. 실제 파일·폴더가 그대로 있고, 되돌린 항목의 메모도 유지됩니다. 두 경로 모두 복구해야 합니다.

### M12 — 되돌리기 만료·지웠던 위치 재캡처
수용시험: U10, U06.

**절차:** 시험 항목을 목록에서 지우고 10초 넘게 기다립니다. 트레이 메뉴를 확인합니다. 원래 파일/폴더를 사용자가 다시 열어 같은 위치를 Ctrl+Alt+B로 저장합니다.

**기대:** 정확한 파일에 열기 요청 한 번 후 시트·셀을 확인합니다. **기록한 위치로 이동했습니다.** 또는 위치 확인 성공과 전면 전환 대기를 구분한 안내가 나옵니다. 단지 파일만 열렸으면 셀 성공으로 표시하면 안 됩니다. 사용자가 업무 Excel까지 닫아야 하는 상황이면 시험을 미뤄도 됩니다.

**기대:** 없는/숨긴 시트를 다른 시트나 A1로 대체해 성공 처리하지 않습니다. 시트를 자동 생성·표시하지 않습니다. a/b/c 결과를 별도로 적습니다.

### M38 — 숨김 행·열·필터·선택 보호

**기대:** 행/열 숨김·필터·보호를 자동 변경하지 않습니다. 보이는 기록 위치로 재개하지 못하면 그 한계를 안내합니다. 실제 업무 문서의 보호를 해제하지 않습니다.

### M39 — 셀 편집·모달 창 중 캡처/재개

**기대:** **편집이나 대화상자를 마친 뒤 다시 눌러 주세요.** 등 안내 또는 기한 내 보수적 실패. Enter/Esc 키를 앱이 대신 눌러 업무 대화상자를 처리하지 않습니다. WorkBookmark가 멈추거나 Excel을 강제 종료하지 않습니다.

### M40 — 형식·차트 시트·좌표 의미

**기대:** a는 형식별 결과를 따로 기록하고 지원 형식이면 정확한 위치를 재개합니다. b는 셀 없는 화면을 거절합니다. c는 저장된 **좌표**로 이동하며 원래 사람/데이터/행을 추적하지 않습니다. 매크로 실행이나 전역 보안 설정 변경은 하지 않아야 합니다. 매크로 이벤트가 있는 문서는 C05로 분리합니다.

## M41~M44: Word·PowerPoint

### M41 — Word 본문 위치, 열린/닫힌 파일 재개

**기대:** 같은 문서 본문의 저장 문자 위치로 이동합니다. fixture 기준 예상 표시는 **본문 문자 위치 38**입니다. 저장 당시 실제 Word 오프셋이 달랐다면 숫자와 이유를 기록합니다. 앱이 문서에 Word 책갈피를 삽입하거나 문서 내용을 저장/수정하지 않습니다.

### M42 — Word 편집 후 좌표·지원 밖 위치
수용시험: 확장 W01.

**절차:** 변경시험 Word 사본에서 a. 기록 위치 앞에 합성 문장을 넣은 후 재개, b. 문서가 기록 좌표보다 짧아지게 줄인 후 재개, c. 새 미저장 문서, d. 머리글/각주/도형/분할 보기, e. 다중창에서 각각 캡처합니다. 보호 보기는 승인된 샘플이 있을 때 C05로 시험합니다.

**기대:** a는 원래 문장 추적이 아니라 저장 문자 오프셋 기준입니다. b는 범위 밖을 임의 위치로 성공 처리하지 않습니다. c는 저장 요청. d는 본문 밖/지원 밖 위치 거절. e는 전경 문서를 확실히 식별할 때만 정확히 기록합니다. 하위 결과를 구분합니다.

### M43 — PowerPoint 슬라이드 재개·재정렬
수용시험: 확장 P01.

**절차:** PPT fixture를 일반 편집 보기로 열고 두 번째 슬라이드를 선택하여 저장합니다. 세 번째로 이동한 후 재개합니다. 변경시험 사본에서는 기록한 슬라이드를 다른 순서로 옮긴 뒤 재개합니다. 정상 종료 후 재개도 확인합니다.

**기대:** 저장한 SlideID의 슬라이드로 이동합니다. 순서가 바뀌어도 같은 슬라이드를 찾아야 합니다. 목록 번호는 **슬라이드 2 (저장 당시)**처럼 과거 번호임을 표시합니다. 앱이 슬라이드 내용을 저장/수정하지 않습니다.

### M44 — PowerPoint 슬라이드 삭제·지원 밖 보기
수용시험: 확장 P01.

**절차:** 변경시험 사본에서 a. 기록한 슬라이드 삭제 후 재개, b. 슬라이드 쇼 중 캡처, c. 새 미저장 발표 파일 캡처, d. 여러 발표 창을 번갈아 캡처합니다.

**기대:** a는 다른 번호 슬라이드를 임의 대체하지 않습니다. b는 일반 편집 외 화면 거절. c는 저장 요청. d는 실제 전경 문서·슬라이드를 정확히 기록하거나 모호함을 안내합니다. 업무 발표를 중단시키지 말고 시험용 발표만 사용합니다.

## M45~M50: Chrome·Edge

브라우저별로 동일 시험을 반복하고 **M46-Chrome**, **M46-Edge**처럼 구분해 회신합니다. 원래 브라우저·프로필·기존 탭 재사용, 스크롤·입력 폼·로그인 복원은 현재 저장 계약이 아닙니다.

### M45 — 브라우저 설치·호스트 등록 확인
수용시험: 확장 B01, B05.

**준비/Confirm:** 확장 로드와 현재 사용자 HKCU native host 등록 변경에 동의한 뒤, 별도 설치 안내의 실제 폴더·확장 ID로 진행합니다. 이 문서를 읽기만 해서는 설치가 수행되지 않습니다.
**절차:** 각 브라우저 확장 관리 화면에서 WorkBookmark 확장 이름·실제 ID를 확인합니다. **-WhatIf** 등록 검사 후 실제 등록을 수행하고 앱을 실행합니다. 확장 팝업의 배정 단축키를 확인합니다.

**기대:** 해당 브라우저 실제 ID 하나가 허용됩니다. 시스템 범위/다른 설치를 덮어쓰지 않습니다. 팝업은 실제 단축키 또는 미배정 상태를 보여 줍니다. 등록/설치 오류 원문을 기록합니다. 자세한 명령은 [설치 안내](../browser-extension/README.md)를 따릅니다.

### M46 — 버튼·단축키 저장과 URL 재개
수용시험: 확장 B01.

**절차:** 합성 주소 A를 완전히 로드 → 확장 버튼 → **이 페이지 저장**. 앱 최근 목록의 제목·전체 URL을 확인합니다. B 주소에서 Ctrl+Shift+Y 또는 실제 배정 조합으로 저장합니다. 목록에서 A 선택 → Enter.

**기대:** DB 커밋 확인 후 성공 안내. A/B의 제목과 URL이 올바릅니다. Enter는 Windows 기본 브라우저에 저장 URL 열기를 요청합니다. 저장한 브라우저와 기본 브라우저가 달라도 그 자체는 실패가 아닙니다. 페이지 로드/로그인 완료까지 성공했다고 표시하지 않습니다.

### M47 — URL 동일성·메모·query/fragment 보존
수용시험: 확장 B02.

**절차:** A 항목에 메모를 씁니다. 같은 A를 다시 저장합니다. 이어 A-fragment와 B를 각각 저장합니다. 각 항목을 우클릭해 **전체 경로/URL 복사**로 원문을 비교합니다.

**기대:** 동일 원문 A는 한 항목으로 갱신되며 메모 유지. query/fragment가 다른 주소는 별도 항목. 주소 원문을 임의로 줄이거나 query/fragment를 제거하지 않습니다. 같은 URL의 제목만 변하는 시험 페이지가 따로 있으면 제목 갱신도 추가 확인합니다.

### M48 — 브라우저 여러 창·탭·전환 중 캡처
수용시험: 확장 B03.

**절차:** A/B를 두 창·여러 탭에 나눠 열고 번갈아 활성화한 뒤 저장합니다. 팝업을 연 뒤 탭을 바꾸는 등 저장 순간 대상이 달라지는 경우도 시험합니다.

**기대:** 명시적으로 선택한 현재 일반 탭만 기록합니다. 저장 직전 탭/URL이 달라졌으면 거절·재입력 안내이며 앞 탭 제목과 뒤 탭 URL을 섞지 않습니다. 팝업이 자동으로 닫혀 시도 자체가 불가능하면 해당 전환 방식은 미실행으로 기록합니다.

### M49 — 금지 페이지·이동 중 페이지 거절
수용시험: 확장 B03.

**절차:** a. chrome://extensions 또는 edge://extensions, b. 로컬 file:// 페이지, c. 비공개 창에서 확장이 사용 가능하게 이미 설정된 시험 환경, d. 로딩 중인 합성 페이지에서 각각 저장을 시도합니다.

**기대:** 내부 페이지·로컬 파일·비공개 창·이동 중 탭은 저장 거절. 비공개 창에 확장 접근이 원래 허용되지 않았다면 “버튼 사용 불가”로 기록하고 시험만을 위해 추가 권한을 켤 필요는 없습니다. 자격증명 포함 URL·초과 길이·변조 프레임은 자동시험에서 다룹니다.

### M50 — 앱 미실행·등록 해제·실패 표시
수용시험: 확장 B04, B05.

**절차:** a. 트레이에서 앱 종료 → 일반 합성 페이지 저장 → 오류 확인 → 앱 재실행. b. 설치 변경을 승인한 경우에만 본 설치의 호스트 등록을 해제 → 다시 저장 → 이후 필요하면 같은 ID/경로로 복원합니다.

**기대:** a/b 모두 성공으로 표시하지 않습니다. 기존 앱 책갈피는 그대로 유지합니다. 응답 유실·제한시간 초과에서는 결과 미확인과 최근 목록 확인 안내이며 자동 반복하지 않습니다. 실제 사용자 DB에 쓰기 실패를 일부러 만들지 않습니다. DB 실패/변조 응답은 격리 자동시험 결과로 보완합니다.

## 현재 알려진 표시 문제·실기 한계

1. **최근 기록 21개 이상 상태 문구:** 저장소의 빈 검색은 최근 20개를 반환하지만 RecentForm은 HasMore일 때 검색 여부와 무관하게 **검색 결과 100개 · 검색어를 좁혀 주세요.**를 표시합니다. M10에서 이 문구가 나오면 알려진 표시 결함으로 기록합니다. 실제 반환 개수와 기능 결과는 별도 확인합니다. 이 문서 작성에서 코드를 수정하지 않았습니다.
2. **설정 설명 누락:** 설정 상단 설명은 탐색기·Excel만 적혀 있습니다. 현재 소스에는 Word·PowerPoint·브라우저 확장 경로도 구현되어 있습니다.
3. **이전 안내 문구:** 빠른 시작의 “기록한 셀로 이동했습니다”와 달리 현재 소스 알림은 **기록한 위치로 이동했습니다.**입니다.
4. **확장 실기 상태:** 기존 기록에서 Word/PPT E2E는 전경 활성화 등으로 차단됐으며 Chrome/Edge 실제 확장 설치부터 DB·재개까지, 실제 SumatraPDF는 미실행입니다. 구현 또는 mock 통과가 실제 연동 통과를 뜻하지 않습니다.
5. **핵심 잔여:** 탐색기/Excel의 요구된 50회, 실제 한국어 IME, Office 편집/모달 상태, 첫 캡처 지연, 장시간 누수, 환경별 지원 시험이 남아 있습니다. 현재 시험의 관찰로만 상태를 갱신합니다.
6. **문서 내 위치 의미:** Excel은 셀 좌표, Word는 본문 문자 오프셋, PPT는 SlideID입니다. 파일 열기·이동은 기존 Office 이벤트/추가 기능/자동저장을 유발할 수 있습니다. 문서 내용을 추적·저장하는 복원 기능으로 해석하지 않습니다.
7. **웹 재개 범위:** 원문 URL을 기본 브라우저에 열기 요청합니다. 원래 브라우저·프로필·기존 탭·스크롤·폼 입력·로그인 상태 복원은 보장하지 않습니다.
