# WorkBookmark 0.2.22 · 책갈피의 파일 위치와 웹 주소 수정

파일이나 작업 폴더를 옮겼거나 웹페이지의 주소가 바뀌었을 때 기존 책갈피를 다시 연결할 수 있습니다. 책갈피에 적어 둔 메모와 색상, 폴더 소속은 유지됩니다.

## 옮긴 파일·폴더 다시 연결하기

1. 책갈피를 열었을 때 저장한 위치에 접근할 수 없다는 알림이 뜨면 **위치 다시 지정…**을 누릅니다. 알림이 사라졌다면 스티커나 목록에서 해당 책갈피를 우클릭해 **위치 다시 지정**을 선택합니다.
2. 옮긴 파일 또는 폴더를 선택합니다. **경로 변경 확인**에서 기존 경로와 새 경로를 비교한 뒤 **적용**을 누릅니다.

## 웹페이지 주소 수정하기

브라우저에서 404를 확인했거나 새 주소를 이미 알고 있다면, **스티커 또는 목록 항목을 우클릭 → 웹 주소 수정…**을 선택합니다. 새 주소를 입력하고 **수정 적용**을 누르면 다음에 책갈피를 열 때 그 주소를 사용합니다. 주소 수정은 앱 안에서만 이루어집니다. 잘못 바꾼 직후에는 **Ctrl+Z**로 원래 주소를 복원할 수 있습니다.
