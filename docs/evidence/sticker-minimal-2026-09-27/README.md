# 0.2.6 최소 스티커·편집 확대 검증 기록

2026-09-27 · Windows x64

평상시 260×88의 메모·이어가기 화면과 편집 중 일시 확대, 저장·취소 후 복귀, 배치와 이전 사용자 설정 보존을 확인했습니다. 이번 변경과 관련된 자동검사와 화면 검증만 실행했습니다.

| 확인 범위 | 결과·근거 |

핵심 확인 사항은 다음과 같습니다.

- 평상시 메모 텍스트와 이어가기만 표시하며 작은 기본/최소 크기에 맞음.
- 편집 시 폭을 유지하고 내용 높이가 160 미만인 경우에만 170으로 확대.
- 저장·취소·자동 저장 성공 후 기존 크기와 접힘 복귀, 자동 위치 보정은 저장하지 않고 사용자 이동은 유지.
- 실패 시 초안과 펼친 편집 영역을 유지하며 종료 중에도 임시 크기를 저장하지 않음.
- 0.2.5 기본 크기는 축소하고 사용자 외곽 크기·모드는 보존. 부분 저장 또는 설정 저장 실패 후 재시도해도 같은 결과.

150% 합성 검사는 네이티브 96 DPI 환경에서 컨트롤과 글꼴을 144 DPI로 설정하고 기본·최소 긴 메모·최소 URL·편집 실패·접힘의 5개 화면을 확인했습니다. 내용 영역을 맞추기 위한 검사용 프레임 보정을 적용했으며 보정 전후 크기를 metrics.json에 기록했습니다. 이미지 확대 처리에 의한 검사는 아닙니다. 이 결과는 실제 Windows 150% 창 테두리·최소/최대 크기 제약·모니터 전환 검증을 대신하지 않습니다.

합성 컨트롤·입력 검사와 실제 마우스·한글 IME 입력은 구분합니다. 이번 114개 검사에 0.2.5의 93개 또는 이전 검사 결과를 합산하지 않았습니다. 독립적인 Office·브라우저·IPC와 설치·제거·재부팅 검사는 반복하지 않았습니다.

제품은 DB v5를 유지하고 0.2.4 설치 경로 보존 수정을 포함합니다. 기존 6종의 배포 파일은 [0.2.6 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.6)에서 제공합니다. 위 UI 검사와 별도로 소스 커밋 이후 수행하는 패키징의 결과는 **WorkBookmark-0.2.6-win-x64.validation.json**, 소스 커밋은 **SourceSnapshot.json**, 해시는 **SHA256SUMS.txt**에서 확인합니다. [릴리스 안내](../../release-notes-v0.2.6.md)에 사용 방법과 배포 범위를 정리했습니다.
