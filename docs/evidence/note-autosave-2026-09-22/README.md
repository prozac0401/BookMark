# 0.2.3 스티커 메모 자동 저장 검증

2026-09-22 · Windows x64 · 스티커 메모 편집 후 창 전환 시 자동 저장

스티커 메모를 편집하다 다른 창이나 스티커로 이동하면 저장합니다. 저장 버튼을 제거했으며, 메모 영역 클릭과 Ctrl+E 편집 시작, Enter 저장, 저장 전 취소 / Esc는 유지합니다. 데이터 형식은 DB v5로 유지합니다.

창 비활성화 뒤 입력 조합과 메뉴 종료를 기다려 저장하며, 저장이 시작되기 전에 같은 스티커로 돌아오면 편집을 이어 갑니다. 같은 스티커 안에서 컨트롤을 옮기거나 자체 메뉴를 열 때는 저장하지 않습니다. 저장 중에는 입력·취소와 중복 저장을 막으며, 완료나 오류 안내가 다른 창에서 입력 중인 포커스를 가져오지 않게 합니다.

## 이번에 확인한 범위

Release 빌드와 Desktop 회귀검사 **209개**를 통과했습니다. 0.2.2의 197개 검사에서 창 전환 저장과 포커스 보호 검사 12개를 추가했습니다.

| 검사 | 결과 |
|---|---|
| Release 빌드 | 통과, 경고 0개·오류 0개 |
| Desktop 회귀검사 | 209개 통과 |
| 다른 창·스티커로 전환 시 저장, 중복 저장 방지 | STN16·17·24·25와 SO11·12 통과. 보조 창으로 이동한 후 저장하고 두 스티커의 서로 다른 초안을 각각 저장 |
| 취소, 저장 실패 후 입력 보존·재시도 | STN18~20 및 SO07·08 통과. 실패한 저장은 DB 값을 바꾸지 않으며 다음 창 전환에서 재시도 |
| 한글 조합과 포커스 이동 보호 | STN21~23 합성 IME 검사 통과. 조합 완료까지 저장을 기다리고 돌아온 경우 편집 유지. 실제 IME 입력은 미실행 |
| 저장 버튼 없는 편집 화면 | 실제 WinForms 컨트롤의 100% 배율 합성 화면 4개 확인 |

[0.2.2의 Desktop 회귀검사 197개와 합성 화면 4개](../note-click-2026-09-22/README.md)는 이전 검증 이력으로 유지하며 이번 결과에 합산하지 않습니다. 변경하지 않은 Core·어댑터·IPC 등 나머지 검사군은 이번에 재실행하지 않았습니다.

## 패키지와 미실행 범위

최종 패키지 구조·추출 파일 검사 결과는 [0.2.3 릴리스의 검증 JSON](https://github.com/prozac0401/BookMark/releases/download/v0.2.3/WorkBookmark-0.2.3-win-x64.validation.json), 배포 파일 해시는 [SHA256SUMS.txt](https://github.com/prozac0401/BookMark/releases/download/v0.2.3/SHA256SUMS.txt)에서 확인합니다. 패키지는 **서명되지 않았습니다**.

창 전환·클릭 회귀검사는 실제 WinForms 컨트롤과 합성 이벤트 경로를 검사하는 범위입니다. 실제 마우스 조작·한글 IME 입력·여러 모니터·혼합 화면 배율, 실제 사용자 설치·업데이트·제거·재부팅은 미실행입니다. 기존 [Office·브라우저·회사 인증의 확인 범위](../../compatibility.md)를 이번 UI 검사로 확대하지 않습니다.
