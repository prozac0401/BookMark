# 0.2.1 스티커 수정 후보 검증 기록

> 공개 배포 전 후보의 검증 이력입니다. 아래 패키지 경로·해시·배포 여부는 당시 로컬 후보를 가리킵니다. 공개 파일의 최종 결과는 [0.2.1 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.1)의 검증 JSON과 SHA-256 목록을 따릅니다.

2026-09-22 · Windows x64 · .NET SDK 10.0.401 · 로컬 수정 후보

스티커별 처리 표시, 스티커 모드의 자동·최상단 표시, 같은 스티커에서 메모 입력, 왼쪽 위 파일 종류 아이콘을 확인했습니다. 요구사항과 표시·메모·데이터 계약은 [0.2.1 수정 기록](../../sticker-fixes-v0.2.1.ko.md)을 참고하세요. **현재 공개 다운로드는 0.2.0**이며, 이 기록은 공개 배포 또는 실제 사용자 계정의 설치 완료를 뜻하지 않습니다.

실행 출력과 로그는 로컬 `artifacts/sticker-fixes-021/`에 보관합니다. 이 폴더의 진단·실행 로그는 검증 문서에 복사하지 않았습니다. 새로 보관한 이미지는 합성 책갈피로 만든 화면이며 사용자 책갈피 DB나 업무 문서 화면을 포함하지 않습니다.

이번 회귀검사는 다음 동작을 포함합니다.

- 저장된 스티커 모드로 시작할 때 단축키 없이 활성 책갈피 표시, 기존 비고정 배치의 native 최상단 상태, 접기 복원, 새 저장 표시와 명시적 전체 숨김 유지
- 누른 스티커의 진행 표시, 다른 스티커의 문구·활성 상태·위치 유지, 외부 요청 중복 거절, 새 스티커에 진행 표시가 전파되지 않음
- 같은 스티커의 메모 입력, 저장·취소, 쓰기 실패 후 입력 보존과 재시도, 비동기 저장 중 중복 방지, 갱신·숨김·재표시 중 입력 유지, 오래된 읽기 응답 차단
- 합성 IME 메시지의 Enter·Esc 처리, 메모 입력 중 책갈피 삭제·복원 단축키 차단
- 원본 파일이 없는 대상의 종류별 아이콘, 합성 확장자 조회, 지연·실패 시 대체 아이콘, 배율별 이미지 크기와 이미지 자원 소유권
- 기존 삭제·복원, 설정, 배치 저장·실패·종료 경합과 Core·외부 연동 판정 회귀

### 검사 실행 중 관찰한 제한

새로 빌드한 **Core·Integration·WindowsChecks** 검사 실행 파일의 첫 실행에서 **접근 거부**가 발생했습니다. 같은 출력 파일과 실행 명령을 변경하지 않고 정상 재시도했을 때 각 검사가 완료됐습니다. 원인은 확인하지 못했습니다. 이를 제품 결함 또는 특정 보안 제품의 동작으로 단정하지 않으며, 재시도를 위해 보안 설정을 변경하지 않았습니다.

## 패키지와 남은 확인

**0.2.1 로컬 MSI·ZIP 후보 제작과 MSI 자동검사 54/54를 완료**했습니다. 제품을 설치하지 않고 관리 이미지를 추출해 전체 파일 목록과 SHA-256이 publish 결과와 일치함을 확인했습니다. MSI는 미서명이며, 실제 사용자 계정 설치, 기존 설치의 업데이트·제거·재부팅, 공개 GitHub 릴리스와 GitHub Pages 배포는 미실행입니다.

결과는 로컬 `artifacts/releases/20260922-083744-111/`의 MSI·ZIP, `Source.zip`, `SourceSnapshot.json`, `SHA256SUMS.txt`, `WorkBookmark-0.2.1-win-x64.validation.json`에 있습니다. 소스 스냅샷은 코드가 검증된 작업 트리를 담으며, 패키지 내부 문서는 제작 직전의 검증 기록입니다. 이 단락의 패키지 완료 결과는 제작 후 추가했습니다. MSI SHA-256: `3638fa3e5924b4787ccaaa399f028d3c147a2273cf7cebedd63f7b317e434dd9`.

자동검사와 화면 렌더는 실제 한글 IME로 입력하기, 마우스로 스티커 이동·크기 변경·메모 편집하기, 여러 모니터와 서로 다른 배율에서 사용하기, 업무 앱과 입력 포커스를 주고받는 실기 확인을 대신하지 않습니다. 해당 실기 항목은 미검증입니다. 이전 [호환성 기록](../../compatibility.md)의 미확인 환경도 이번 자동검사로 통과 처리하지 않습니다.
