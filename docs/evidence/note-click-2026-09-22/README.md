# 0.2.2 메모 영역 클릭 편집 검증

2026-09-22 · Windows x64 · 스티커 메모 편집 진입 방식 변경

스티커의 메모 본문이나 빈 메모 안내 영역을 한 번 클릭하면 같은 스티커에서 편집합니다. 별도 메모 추가·편집 버튼을 제거했으며 Ctrl+E와 기존 저장·취소 동작은 유지합니다. 데이터 형식은 DB v5로 유지합니다.

## 이번에 확인한 범위

- Release 빌드: 경고 0개·오류 0개.
- Desktop 회귀검사: **197개 통과**. SO06은 빈 메모의 왼쪽 클릭부터 인라인 편집까지, SO09는 처리 중이거나 오른쪽 클릭인 경우 편집 진입 방지, SO10은 저장된 메모 본문 왼쪽 클릭을 확인합니다. 기존 인라인 메모 저장·취소·저장 실패 후 입력 보존 및 재시도 검사도 함께 실행했습니다.
- 합성 화면: 기본·빈 메모·최소 크기·인라인 메모 편집의 실제 WinForms 컨트롤 렌더링 **4개**를 확인했습니다.

이번 변경은 스티커 UI와 관련 회귀검사에 한정됩니다. 변경하지 않은 Core·어댑터·IPC 등 나머지 검사군은 다시 실행하지 않았습니다. [0.2.1의 자동검사 586개와 MSI 구조 검사 54개](../../sticker-fixes-v0.2.1.ko.md)는 이전 검증 이력으로 유지하며 이번 197개와 합산하지 않습니다.

## 패키지와 미실행 범위

최종 패키지 구조·추출 파일 검사 결과는 [0.2.2 릴리스의 검증 JSON](https://github.com/prozac0401/BookMark/releases/download/v0.2.2/WorkBookmark-0.2.2-win-x64.validation.json), 배포 파일 해시는 [SHA256SUMS.txt](https://github.com/prozac0401/BookMark/releases/download/v0.2.2/SHA256SUMS.txt)에서 확인합니다. 패키지는 **서명되지 않았습니다**.

위 클릭 회귀검사는 합성 입력으로 컨트롤의 이벤트 경로를 검사한 결과입니다. 실제 마우스 조작·한글 IME 입력·여러 모니터·혼합 화면 배율, 실제 사용자 설치·업데이트·제거·재부팅은 미실행입니다. 기존 [Office·브라우저·회사 인증의 확인 범위](../../compatibility.md)를 이번 UI 검사로 확대하지 않습니다.
