# 0.2.20 폴더 스티커 검증

검증 데이터는 저장소 아래 격리된 합성 자료입니다. 자동화 도구에 노출하려는 목적으로 제품 창의 스타일이나 소유 관계를 바꾸지 않았으며, 도구가 노출하지 않는 스티커의 드래그와 한국어 IME 입력은 사용자가 수행했습니다. 500ms 상태 기록으로 저장소·좌표·DPI·편집 상태를 대조했습니다. 합성 원본 파일은 보존됐습니다.

## 실제 입력 확인

| 항목 | 결과와 범위 |
| --- | --- |
| 폴더 생성·이동·접기·펼치기 | B→A 그룹 생성, A→B 순서, 루트와 자식 동반 이동, 다른 C 위치 유지 확인 |
| 자식 꺼내기·실행 취소 | 마지막 분리 미리보기와 확정 위치 일치, 실행 취소로 관계·순서 복원 확인 |
| 혼합 DPI 왕복 | 수정 후 96→120→96 DPI에서 루트·패널·행 크기 일치. 정지 후 놓은 세 사례의 미리보기·확정 좌표 일치 |
| 최상위 한글 입력 | 첫 Enter는 조합 확정·편집 유지, 두 번째 Enter는 정확한 저장. 초안 취소는 기존 값 유지 |
| 창 전환 자동저장 | 마지막 음절 누락을 발견해 수정. 재검증에서 `마지막 글자 보존` 전체 저장 확인 |
| 자식 한글 입력 | 실제 입력 `자식 한글 입력`의 Enter 저장과 취소, 형제 선택 시 `자식 자동저장 보존` 전체 저장 확인 |
| 자식 편집 크기 | 패널 높이 82→142→82 복원, 루트·C 위치와 계층·순서 유지 |
| 정상 종료 | 저장 완료 뒤 종료 기록과 프로세스 종료 확인 |
| 저장 실패 드래그 | 관계 저장 실패 주입 후 실제 B 분리 시도 1회가 거부됐고, 직전·직후 책갈피와 저장 배치가 동일함을 확인 |

각 판단의 시점과 수치는 이 디렉터리의 `native-*-checks.json`에 보존합니다. 최초 실패와 수정 후 결과를 함께 남깁니다. 첫 Esc의 조합 취소 중간 상태는 사용자 확인이며, 500ms 기록에서 독립적으로 포착하지 못했습니다. 정지 후 놓은 사례 이외의 마지막 포인터 좌표는 추정하지 않습니다.

## 최종 카드 외형과 후속 검증

저장 실패를 주입한 실제 드래그와 목록 접근성 정리 회귀검사는 통과했습니다. 첫 외형 확인에서는 사각형 공통 배경과 루트보다 넓어 보이는 자식이 지적돼 실패로 기록했습니다. 사용자가 개별 카드만 보이고 틈은 배경이 보이는 방식을 선택했으며, 실제 루트 카드 폭에 정렬하고 사각 배경을 제거한 수정본을 직접 확인했습니다. 기본 상태에서 96 DPI의 루트 본체와 자식은 260px, 120 DPI에서는 326px로 일치했고, 카드 중심은 포함하되 모서리와 간격은 제외하는 네이티브 영역을 확인했습니다. 사용자의 추가 크기 조절·묶기·분리·되돌리기를 거친 뒤 같은 루트 안의 A→B 순서와 메모가 보존됐고 정상 종료했습니다. 중간 크기 조절 프레임이나 모든 정수 순서값의 초기값 일치까지 주장하지 않습니다. 자세한 범위는 `native-transparent-card-checks.json`, 집중검사는 `transparent-card-checks.json`에 기록합니다.

고정 소스의 전체 자동검사·배포용 worker·MSI 구조·관리 추출·게시 자산 검증의 최종 결과는 [0.2.20 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20) 본문과 첨부 자료를 기준으로 합니다. 앞선 실제 입력 결과가 후속 빌드의 모든 변경을 대신한다고 주장하지 않습니다.

목록 종료 중 발견한 WinForms 접근성 예외의 원래 증거는 `dpi-sticker-retry-reason.json`입니다. 예외로 중단된 실행은 통과로 집계하지 않습니다.

## 범위 구분

모니터를 사용하는 자동 패널 배치 검사와 합성 IME 메시지 검사는 실제 포인터·한글 조합 입력과 별도입니다. MSI 관리 추출·구조·파일 해시 검사는 실제 설치·업데이트·제거·재로그인 전주기를 대신하지 않습니다. Office·탐색기 50회 실기 행렬과 운영 환경 전체 호환성은 이번 변경 범위에 포함하지 않습니다.




## 공개 배포 결과

[0.2.20](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20)을 공개하고 최신 릴리스로 확인했습니다. 소스 기준은 `9baa74ff2abffb2bcbacad47ecf7214f6cecc66a`이며 깨끗한 커밋에서 패키징했습니다. 전체 자동검사 1,164개(Core/Storage 97, IPC 17, Desktop 724, 기타 326), MSI 검사 54개와 관리 추출·전체 파일 해시, ZIP의 1,381개 파일 대조가 통과했습니다. 집중검사 수는 전체에 더하지 않았습니다.

최종 게시 worker의 지원하지 않는 합성 요청 6/6이 통과했습니다. 별도 시험 호스트에 최종 게시 DLL 네 개를 그대로 사용하여 한글 메모·폴더 관계·배치의 재시작 보존과 정상 종료를 확인했습니다. 전체 검사 빌드 DLL과 게시 DLL의 지문은 구분합니다. 일반 설치 앱의 UI 진입점이나 실제 Office 작업 검증으로 확대하지 않습니다.

GitHub 자산 6종의 서버 SHA-256·크기를 로컬 파일과 대조했고, 공개된 `SHA256SUMS.txt`와 `SourceSnapshot.json`을 비인증 다운로드해 다시 대조했습니다. 릴리스 태그는 빌드 커밋과 일치합니다. 세부 결과·파일 지문·미실행 범위는 [최종 배포 검증](release-verification.json)에 기록합니다. 이 단락과 최종 검증 파일은 패키징 이후의 문서 기록이며 릴리스 태그·Source.zip의 기준 커밋을 바꾸지 않습니다.
전체 실행 출력은 [빌드·검사·패키징 로그](release-build-package.log), 최종 worker 출력은 [worker 로그](production-worker.log)에 보존합니다.
