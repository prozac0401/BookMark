# 0.2.7 한 줄 스티커 검증 기록

2026-09-27 · Windows x64

기본 내용 영역 260×36, 최소 240×36 안에 9.5pt 메모 한 줄과 28×28 바로가기 화살표 버튼을 배치하는 변경을 확인했습니다. 편집 중 일시 확대와 저장·취소 후 복귀, 사용자 크기와 표시 모드 보존도 관련 검사에 포함했습니다.

핵심 확인 사항은 다음과 같습니다.

- 메모와 바로가기 화살표가 한 줄에 배치되고 긴 내용은 말줄임표로 표시됨.
- 작은 기본·최소 크기에서 텍스트와 버튼이 겹치거나 잘리지 않음.
- 기본 버튼을 그린 뒤 남은 그리기 영역 제한 때문에 화살표가 사라질 수 있던 문제를 수정. STK22에서 일반·마우스 올림·누름·포커스의 각 상태에 흰색 아이콘 픽셀 36개가 그려짐을 확인.
- 편집 시 폭 유지, 내용 높이 160 미만인 경우에만 170으로 확대.
- 저장·취소·자동 저장 성공 후 원래 크기·접힘 복귀, 실패 시 초안과 편집 영역 유지.
- 임시 편집 크기·자동 위치 보정은 배치에서 제외하고 사용자의 직접 이동은 유지.
- 0.2.6 기본 크기만 새 기본값으로 줄이고 사용자 외곽 크기·선택 모드는 보존. 배율별 외곽 크기를 96 DPI로 정규화한 저장 값의 반올림 차이도 기본 크기 판별에 반영. 실패 재시도에서도 반복 축소하지 않음.

100% 화면은 일반 표시 8개, 처리 중 1개, 편집 3개로 총 12개입니다. 150% 합성 검사는 네이티브 96 DPI 환경에서 컨트롤과 글꼴을 144 DPI로 설정하고 기본·최소 긴 메모·최소 URL·편집 실패·접힘의 5개 화면을 확인했습니다. 내용 영역을 맞추기 위한 검사용 프레임 보정을 적용했으며 보정 전후 크기를 metrics.json에 기록했습니다. 이미지 확대 처리에 의한 검사는 아닙니다. 이 결과는 실제 Windows 150% 창 테두리·최소/최대 크기 제약·모니터 전환 검증을 대신하지 않습니다.

합성 컨트롤·입력 검사와 실제 마우스·한글 IME 입력은 구분합니다. 이번 121개 검사에 0.2.6의 114개 또는 이전 결과를 합산하지 않았습니다. 독립적인 Office·브라우저·IPC와 설치·제거·재부팅 검사는 반복하지 않았습니다.

제품은 DB v5와 0.2.4 설치 경로 보존 수정을 유지합니다. 기존 6종 배포 파일은 [0.2.7 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.7)에 제공합니다. 위 UI 검사와 별도로 소스 커밋 이후 기존 패키징의 구조·파일 추출 검사 54개를 한 차례 수행합니다. 그 결과는 **WorkBookmark-0.2.7-win-x64.validation.json**, 소스 커밋은 **SourceSnapshot.json**, 해시는 **SHA256SUMS.txt**에서 확인합니다. 사용 방법과 배포 범위는 [릴리스 안내](../../release-notes-v0.2.7.md)를 참고하세요.
