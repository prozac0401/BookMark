# WorkBookmark 0.2.12 · 폴더로 정리하는 책갈피

링크가 없는 **책갈피 폴더**를 추가했습니다. 스티커와 목록에서 같은 폴더 구조를 사용합니다. [0.2.12 릴리스 다운로드](https://github.com/prozac0401/BookMark/releases/tag/v0.2.12).

## 드래그 규칙

| B를 놓는 대상 A | 결과 |
|---|---|
| 책갈피 폴더 | B가 A 안으로 이동합니다. B는 일반 책갈피 또는 폴더일 수 있습니다. |
| 일반 책갈피 스티커 | A가 있던 위치의 계층에 **새 폴더**를 만들고 A와 B를 함께 담습니다. |
| 목록의 빈 영역·하단 안내줄 | B를 최상위로 꺼냅니다. |

자기 자신 또는 자신의 하위 항목 위로는 옮길 수 없습니다. 새 폴더 생성과 두 항목 이동은 한 번에 저장하며, 실패하면 기존 상태를 유지합니다. 원래 책갈피의 링크·메모·색상·저장 이력은 유지됩니다.

## 폴더 사용

- **폴더 제목 또는 열기 버튼을 클릭**하면 자식 스티커가 아래로 펼쳐집니다. 다시 닫으면 하위 스티커를 숨깁니다. 목록에서도 폴더를 클릭하거나 Enter로 열고 닫습니다.
- 하위 폴더는 각각 열림 상태를 가집니다. 상위 폴더를 다시 열어도 닫혀 있던 하위 폴더는 계속 닫혀 있습니다. 상태는 재시작 후에도 유지합니다.
- 새 폴더는 닫힌 상태로 만들며, 기존 폴더 안으로 옮길 때는 그 폴더의 열림 상태를 유지합니다. 폴더 열기·닫기는 저장된 스티커 배치를 바꾸지 않습니다.
- 트레이 또는 목록의 **새 폴더**에서 빈 폴더를 만들 수 있습니다. 폴더 우클릭에서 스티커는 **새 폴더**, 목록은 **하위 폴더 만들기**로 하위 폴더를 만듭니다. **이름 변경 / 폴더 이름 바꾸기**로 이름을 바꾸며 최대 100자입니다.
- 폴더와 자식의 색상은 각각 **우클릭 → 색상**에서 바꿉니다. 기존 7가지 색상을 유지합니다.
- 폴더만 삭제하면 그 안의 항목은 최상위에서 계속 접근할 수 있습니다. 폴더를 복원하면 원래 소속과 열림 상태가 돌아옵니다.
- 목록 검색은 닫힌 폴더 안까지 검색하고 상위 경로를 표시합니다. 검색 표시가 폴더의 저장된 열림 상태를 바꾸지는 않습니다.

이 폴더는 실제 디스크 폴더와 다릅니다. 디스크 폴더를 가리키는 기존 책갈피는 계속 해당 경로를 여는 일반 책갈피입니다.

## 기존 데이터 이전

**DB v8**로 이전하기 전에 데이터 폴더에 `bookmarks.db.pre-migration-….bak` 백업을 만듭니다. 0.2.11의 일반 스티커가 자식을 가진 구조는 그 스티커와 기존 자식을 함께 담는 책갈피 폴더로 바꿉니다. 중첩 관계·삭제 기록·링크·메모·색상·저장 이력·스티커 크기를 보존합니다. 관계가 바뀐 묶음은 다음 스티커 표시에서 정리됩니다.

**0.2.11 이하 실행 파일은 DB v8을 읽을 수 없습니다.** 구버전으로 돌아가려면 현재 데이터 폴더 전체를 보존하고 이전 전 백업의 복사본을 복원하세요. 그 백업 이후의 변경 사항은 포함되지 않습니다.

## 검증과 배포

최종 Release 빌드 경고·오류 0개, 전체 자동검사 **940개 통과**입니다. Core/Storage 76개에는 새 폴더 9개가, Desktop 521개에는 폴더 목록·스티커·이름·앱 연동 65개가 포함됩니다. 닫힌 폴더·열린 폴더·중첩 폴더의 화면 렌더링을 직접 확인했습니다.

자동검사와 실제 조작의 확인 범위는 [검증 기록](evidence/folders-2026-10-14/README.md)에 구분합니다. MSI 실제 설치·업데이트·제거·재부팅, 혼합 DPI·한글 IME 및 실제 마우스 드래그는 이번 자동검사의 통과로 간주하지 않습니다.

배포 파일은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종입니다. 최종 MSI 구조·관리 추출은 첨부 검증 JSON, 소스 커밋과 파일 지문은 SourceSnapshot.json·SHA256SUMS.txt를 따릅니다. 패키지는 미서명입니다.
