# WorkBookmark 0.2.15 · 스티커 선택·이동·편집 개선

**[Windows x64 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.15/WorkBookmark-0.2.15-win-x64.msi)** · [전체 배포 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.15)

스티커의 바로가기·폴더 펼침 버튼을 왼쪽으로 옮기고, 선택·이동·편집·크기 조절 동작을 정리한 정식 릴리스입니다. .NET 런타임을 포함한 사용자별 MSI로 설치할 수 있으며 관리자 권한이나 별도 SDK 설치가 필요하지 않습니다.

## 변경 사항

- 일반 스티커의 **바로가기**와 폴더의 **열기·닫기** 버튼을 왼쪽에 배치했습니다.
- **제목 한 번 클릭은 선택**, **제목·배경 여백을 끌면 이동**, **제목 더블클릭 또는 F2 / Ctrl+E는 편집**으로 구분했습니다. 선택한 스티커에는 강조 테두리를 표시합니다.
- 오른쪽 아래에 **크기 조절 손잡이**를 추가했습니다. 창 가장자리·모서리도 계속 사용할 수 있으며, 접힌 스티커의 손잡이는 가로 폭만 바꿉니다.
- 편집할 때 기존 폭을 유지하고 필요한 경우 내용 높이만 100% 배율 기준 **96픽셀**까지 잠시 늘립니다. 저장·취소 후에는 편집 전 크기·접힘 상태로 돌아가며, 편집 중 직접 조절한 폭은 유지합니다. 높이도 직접 바꿨다면 새 높이와 펼침 상태를 유지합니다.
- **자석 ON**은 주변 스티커의 가장자리와 행·열을 맞추고, **자석 OFF**는 자유롭게 이동합니다. 두 모드 모두 일반 이동은 위치만 바꾸며, 겹쳐 놓아도 폴더 관계를 바꾸지 않습니다.
- 폴더에 넣거나 새 폴더로 묶으려면 **Shift를 누른 채 대상 위로 끌어 놓습니다.** 대상에 강조 표시가 나타난 것을 확인하고 놓으세요. **Alt**를 누른 동안에는 자유 이동하며, Shift를 함께 눌러도 묶지 않습니다.

다른 창으로 이동하면 메모·폴더 이름을 자동 저장하며, **Enter**로 바로 저장하거나 **취소 / Esc**로 되돌릴 수 있습니다. 0.2.14의 목록 유지·설정 닫기·검색 중 임시 펼침 수정과 기존 폴더·색상·표시 토글·정렬 기능도 포함합니다. [사용 매뉴얼](user-manual.ko.md)에서 자세한 조작을 확인하세요.

## MSI로 설치·업데이트

1. **0.2.14-test.2 등 포터블 버전이 실행 중이면 트레이 → 종료로 완전히 종료합니다.**
2. `%LOCALAPPDATA%\WorkBookmark` 폴더 전체를 별도 위치에 백업합니다.
3. `WorkBookmark-0.2.15-win-x64.msi`를 실행합니다. 이전 MSI 설치는 자동 교체하며, 포터블 실행 폴더는 자동 제거하지 않습니다.
4. 완료 화면에서 기본 선택된 **업무 책갈피 실행**을 선택한 채 마치면 바로 실행됩니다. 이후에는 시작 메뉴에서 실행할 수 있습니다.

같은 Windows 사용자 계정에서는 기존 책갈피·메모·설정·배치를 이어서 사용합니다. **DB v8을 유지하며 스키마 변경은 없습니다.** 0.2.12·0.2.13·0.2.14-test.2·0.2.14에서 업데이트할 때 추가 DB 이전이 없습니다. 0.2.11 이하의 DB는 자동 백업 후 v8로 이전하며, 그 버전으로 복귀하려면 이전 전 백업을 복원해야 합니다.

0.2.3 이하를 사용자 지정 경로에 설치했다면 기존 MSI와 원래 `INSTALLFOLDER`로 먼저 제거한 뒤 설치하세요. [MSI 상세 안내](windows-installer.ko.md)와 [백업·복원 안내](user-manual.ko.md#maintenance)를 참고하세요.

## 검증과 배포

이번 0.2.15 소스로 Release 빌드 경고·오류 0개, 전체 자동검사 **1,024개 통과**(Desktop 605개), 별도 스티커 표시 포커스 구성요소 검사 **8개 통과**를 확인했습니다. 합계 **1,032개**이며 이전 릴리스 결과나 개발 중 집중검사를 중복 합산하지 않았습니다. 실행 로그와 자동검사·패키지 검증 범위는 [0.2.15 검증 기록](evidence/release-0.2.15-2026-10-19/README.md)에 정리했습니다. 최종 배포 MSI의 구조·관리 추출 및 파일 해시 대조 결과는 첨부 검증 JSON을 기준으로 합니다.

스티커 화면 배치는 렌더링으로 확인했습니다. 실제 마우스·키보드 입력은 Windows 도구의 캡처한 창 활성화 실패로 검증을 완료하지 못했습니다. 실제 한글 IME 입력·서로 다른 배율의 모니터 간 조작과 MSI 설치·업데이트·제거·재부팅도 미실행입니다. 자동검사와 렌더링 확인, MSI 구조 검사·관리 이미지 추출은 이러한 실기 시험을 대신하지 않습니다.

배포 파일은 **MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종**입니다. 패키지는 **미서명**입니다. 최종 MSI 검사 결과는 첨부 검증 JSON, 소스 커밋과 소스 모드는 SourceSnapshot.json, 파일 지문은 SHA256SUMS.txt를 따릅니다. 이전 릴리스 검증은 [0.2.14 기록](release-notes-v0.2.14.md)에 보존합니다.
