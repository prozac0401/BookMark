# WorkBookmark 0.2.16 · 스티커 테두리와 버튼 모서리 정리

**[Windows x64 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.16/WorkBookmark-0.2.16-win-x64.msi)** · [전체 배포 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.16)

스티커의 네모난 실선 테두리를 없애고 왼쪽 버튼의 모서리를 스티커와 같은 곡률로 둥글게 다듬었습니다.

- 선택하거나 폴더로 묶을 대상을 가리킬 때 사각 실선 테두리를 그리지 않습니다. Shift+드래그 대상은 배경색으로 구분합니다.
- Windows 11에서는 창의 외곽선도 숨기고 둥근 모서리를 사용합니다. 창 가장자리와 오른쪽 아래 손잡이로 크기를 조절할 수 있습니다.
- 왼쪽 바로가기·폴더 열기/닫기 버튼을 스티커 창과 같은 **8 DIP 반경**으로 둥글게 잘랐습니다. 화면 배율에 맞춰 조절하며 마우스를 올리거나 누를 때도 둥근 모양을 유지합니다.

0.2.15의 클릭 선택·끌기 이동·더블클릭/F2/Ctrl+E 편집과 Shift+드래그 폴더 묶기 동작을 유지합니다. DB v8과 설치·데이터 형식에는 변경이 없습니다.

## 설치

`WorkBookmark-0.2.16-win-x64.msi`로 이전 MSI를 업데이트하거나 포터블 ZIP의 전체 폴더를 압축 해제해 실행합니다. 실행 중인 포터블 버전은 트레이에서 종료한 뒤 업데이트하세요. 기존 책갈피·메모·설정은 이어서 사용합니다. [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

## 검증과 배포

이번 소스의 자동검사·화면 확인 결과와 미실행 범위는 [0.2.16 검증 기록](evidence/release-0.2.16-2026-10-20/README.md)에 기록합니다. 최종 배포 MSI의 구조·관리 추출 및 파일 해시 대조 결과는 첨부 검증 JSON, 소스 커밋은 SourceSnapshot.json, 파일 지문은 SHA256SUMS.txt를 기준으로 합니다.

기본 자동검사 1,024개와 별도 포커스 구성요소 검사 8개가 통과했습니다. 최초 브라우저/SQLite 검사의 시간 초과와 단독 재실행 통과 기록을 함께 보존했습니다. 최종 버튼 페인트 보완 후 스티커 집중 검사 282개도 통과했으며 중복 합산하지 않습니다. 화면은 구성요소 렌더링으로 확인했고, 실제 창 조작과 DWM 합성 화면 확인은 화면 도구의 창 활성화 오류로 완료하지 못했습니다.

배포 파일은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종이며 패키지는 미서명입니다. 실제 MSI 설치·업데이트·제거와 여러 배율의 모니터 간 이동은 이번 변경의 검증 범위에 포함하지 않습니다. 이전 기록은 [0.2.15 릴리스 안내](release-notes-v0.2.15.md)에 보존합니다.
