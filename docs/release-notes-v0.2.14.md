# WorkBookmark 0.2.14 · 목록 유지와 설정 닫기 수정

**[Windows x64 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.14/WorkBookmark-0.2.14-win-x64.msi)** · [전체 배포 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.14)

0.2.14-test.2의 목록·검색·설정 수정 사항을 포함하는 정식 릴리스입니다. .NET 런타임을 포함한 사용자별 MSI로 설치할 수 있으며 관리자 권한이나 별도 SDK 설치가 필요하지 않습니다.

## 변경 사항

- 목록에서 폴더를 펼칠 때 새 스티커가 초점을 빼앗아 목록이 닫히는 경로를 수정했습니다.
- 설정의 **닫기 / Esc**는 미적용 변경을 저장하지 않고 창을 닫습니다. **적용**으로 저장한 내용은 유지하며, 적용 실패 후 재시도도 가능합니다.
- 검색은 일치 항목의 상위 경로를 임시로 펼칩니다. 검색 중의 펼침 조작은 저장하지 않으며, 검색어를 지우면 저장된 폴더 상태로 돌아갑니다. 목록과 스티커의 폴더 상태 공유를 유지합니다.
- 다른 앱으로 이동하면 목록은 기존처럼 숨겨집니다. 스티커를 표시한 뒤 명시적으로 클릭해 메모·폴더 이름을 편집하는 동작도 유지합니다.

0.2.13의 제목 클릭·끌기, 폴더와 색상, 스티커 표시 토글·정렬 기능은 계속 사용할 수 있습니다. [사용 매뉴얼](user-manual.ko.md)에서 자세한 조작을 확인하세요.

## MSI로 설치·업데이트

1. **0.2.14-test.2 등 포터블 시험판이 실행 중이면 트레이 → 종료로 완전히 종료합니다.**
2. `%LOCALAPPDATA%\WorkBookmark` 폴더 전체를 별도 위치에 백업합니다.
3. `WorkBookmark-0.2.14-win-x64.msi`를 실행합니다. 이전 MSI 설치는 자동 교체하며, 포터블 실행 폴더는 자동 제거하지 않습니다.
4. 완료 화면에서 기본 선택된 **업무 책갈피 실행**을 선택한 채 마치면 바로 실행됩니다. 이후에는 시작 메뉴에서 실행할 수 있습니다.

같은 Windows 사용자 계정에서는 기존 책갈피·메모·설정·배치를 이어서 사용합니다. **DB v8을 유지하며 스키마 변경은 없습니다.** 0.2.12·0.2.13·0.2.14-test.2에서 업데이트할 때 추가 DB 이전이 없습니다. 0.2.11 이하의 DB는 자동 백업 후 v8로 이전하며, 그 버전으로 복귀하려면 이전 전 백업을 복원해야 합니다.

0.2.3 이하를 사용자 지정 경로에 설치했다면 기존 MSI와 원래 `INSTALLFOLDER`로 먼저 제거한 뒤 설치하세요. [MSI 상세 안내](windows-installer.ko.md)와 [백업·복원 안내](user-manual.ko.md#maintenance)를 참고하세요.

## 검증과 배포

이번 0.2.14 소스로 Release 빌드 경고·오류 0개, 전체 자동검사 **981개 통과**(Desktop 562개), 별도 스티커 표시 포커스 구성요소 검사 **8개 통과**를 확인했습니다. 합계 **989개**이며 이전 시험판 결과를 재사용하거나 중복 합산하지 않았습니다. 실제 전경 조건 검사 6개는 사전조건을 충족하지 못해 **NOT RUN**입니다. 실행 로그와 범위는 [0.2.14 검증 기록](evidence/release-0.2.14-2026-10-15/README.md)에 정리했습니다. 최종 배포 MSI의 구조·관리 추출 및 파일 해시 대조 결과는 첨부 검증 JSON을 기준으로 합니다.

실제 마우스·키보드 입력, 다른 앱 Alt+Tab과 전경 목록·스티커의 실제 창 순서는 이번 릴리스에서 미검증입니다. 실제 MSI 설치·업데이트·제거·재부팅도 미실행입니다. MSI 구조 검사와 관리 이미지 추출은 실제 설치 시험을 대신하지 않습니다. 시험판의 재현·수정과 구성요소 검사 이력은 [0.2.14-test.2 검증 기록](list-search-settings-close-checks.ko.md)에 보존합니다.

배포 파일은 **MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종**입니다. 패키지는 **미서명**입니다. 최종 MSI 검사 결과는 첨부 검증 JSON, 소스 커밋과 소스 모드는 SourceSnapshot.json, 파일 지문은 SHA256SUMS.txt를 따릅니다.
