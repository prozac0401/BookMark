# WorkBookmark 0.2.8

## 2026-10-05 정식 릴리스 채널 전환

사용자 요청으로 기존 v0.2.8을 정식 채널로 전환했습니다. 태그·소스·첨부 MSI/ZIP은 그대로 유지합니다. 사용자가 실제 Whale에서 저장·재열기가 정상 동작함을 확인했습니다(USER_CONFIRMED). Windows·Whale build와 원시 로그가 있는 통제 시험은 아니므로 모든 환경 검증으로 확대하지 않습니다. [동일 파일 확인·재사용한 근거·남은 미검증 범위](stable-release-20261005.md)를 참고하세요. 기존 설치·DB v5·설정·사용자 표시 모드와 크기를 변경하지 않았으며 재설치할 필요가 없습니다.

## 2026-09-27 Whale 지원 제작·검증 이력

아래는 당시 결과이며 미검증 표기를 소급해서 PASS로 바꾸지 않습니다.

네이버 **Whale을 확장 없는 웹페이지 저장 대상에 추가**했습니다. 일반 HTTP/HTTPS 페이지 본문에서 **Ctrl+Alt+B**를 누르면 Edge·Chrome과 같은 방식으로 제목과 URL을 확인해 저장합니다. 저장한 웹페이지는 Windows 기본 브라우저로 엽니다.

## 변경 범위

- 브라우저 프로세스 판별에 `whale`을 추가했습니다. 기존 `msedge`·`chrome`과 같이 대소문자를 구분하지 않는 정확한 이름 비교를 사용합니다.
- Windows 접근성 API(UI Automation)로 URL·제목을 확인하는 규칙, 탭 전환·주소 입력 중 거부, HTTP/HTTPS 제한과 기본 브라우저 열기 동작은 유지합니다.
- 시작 안내와 사용자 문서의 확장 없는 저장 대상에 Whale을 추가했습니다. 주소 자동 확인이 어려우면 기존 **트레이 → 웹페이지 URL로 추가…**를 사용할 수 있습니다.
- 기존 **Edge·Chrome 확장 프로그램**은 선택 사항으로 유지합니다. **Whale 확장의 Native Messaging 연결 등록은 이번 범위에 포함하지 않습니다.**

Whale에서 저장하더라도 다시 열 때 Whale·원래 프로필·원래 탭이 선택되는 것은 보장하지 않습니다. 스크롤·입력 내용·로그인 상태도 저장하지 않습니다. [확장 없는 사용법](browser-without-extension.ko.md)을 참고하세요.

## 유지하는 동작

0.2.7의 한 줄 메모·바로가기 화살표, 작은 기본 크기와 편집 중 일시 확대, 사용자 크기·표시 모드 보존을 유지합니다. 스티커 관련 코드는 이번 변경 범위에 포함하지 않습니다. DB v5·설정 파일 버전 1·스티커 표시 규칙 버전 3, 0.2.4의 사용자 지정 MSI 설치 경로 보존 수정도 유지합니다.

## 검증 결과와 한계

| 범위 | 결과 |
|---|---|
| WindowsChecks·앱 등 관련 Release 빌드 | 경고 0개·오류 0개 |
| 브라우저 어댑터 자동검사 | **34개 통과** |
| 실제 Whale 일반 창에서 UI Automation으로 제목·URL 저장 후 재열기 | 미검증 |
| Office·스티커·전체 통합 검사 | 변경 범위와 독립적이므로 재실행하지 않음 |
| 패키지 구조·파일 추출 검사 | 소스 커밋 후 기존 방식으로 54개를 한 차례 검사하고 결과를 릴리스 검증 JSON으로 제공 |

브라우저 검사는 메타데이터를 주입하는 자동검사입니다. 실제 Whale의 접근성 노출·탭·주소 표시줄이나 UI를 통한 저장·재열기 검증을 대신하지 않습니다. WindowsChecks 실행 파일의 직접 실행이 OS 접근 거부로 제한되어 같은 빌드의 DLL을 dotnet으로 실행했습니다. [이번 검증 근거](evidence/whale-support-2026-09-27/README.md)에 빌드·검사·실행 경로 기록을 보관합니다. 이전 버전의 검사 수를 합산하지 않았습니다.

## 배포 형식

[0.2.8 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.8)에서 기존과 같은 6종을 제공합니다: **WorkBookmark-0.2.8-win-x64.msi**, **WorkBookmark-0.2.8-win-x64.zip**, **Source.zip**, **SourceSnapshot.json**, **WorkBookmark-0.2.8-win-x64.validation.json**, **SHA256SUMS.txt**.

소스 커밋 이후 한 차례 수행하는 패키징의 결과는 첨부 검증 JSON, 소스 커밋은 SourceSnapshot.json, 배포 파일 해시는 SHA256SUMS.txt에서 확인합니다. 패키지 검사는 실제 브라우저 동작 검증을 대신하지 않습니다. 패키지는 서명되지 않았습니다. 이전 사용자 지정 설치 경로는 [기존 MSI 이행 안내](windows-installer.ko.md)를 따르세요.
