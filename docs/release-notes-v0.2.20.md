# WorkBookmark 0.2.20 · 정렬된 폴더 패널과 변경 되돌리기

**0.2.20은 폴더 안의 카드를 정렬하고, 변경 되돌리기와 혼합 화면 배율·한글 입력을 보완합니다.** 다운로드 파일과 전체 자동검사·패키지 검사·게시 자산 대조의 최종 결과는 [0.2.20 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20)의 본문과 첨부 검증 자료를 기준으로 합니다. 실제 조작으로 확인한 범위와 외형 변경 후 재확인 상태는 아래에 구분합니다.

폴더를 펼치거나 메모를 편집해도 주변 스티커의 위치가 바뀌지 않습니다. 최상위 스티커가 트리의 기준점이 되고, 하위 항목은 저장한 순서에 따라 같은 패널 안에 배치됩니다.

## 변경 내용

- **위치가 일정한 하위 항목:** 루트의 위치와 트리 폭을 조절하며, 자식은 부모 관계·형제 순서·펼침 상태에 따라 표시합니다. 접힌 자식은 공간을 차지하지 않습니다. 폴더 전체를 옮겨도 내부 관계와 순서를 유지합니다.
- **배경이 보이는 개별 둥근 카드:** 하위 항목은 공통 영역에 정렬하되 개별 카드만 표시합니다. 카드 사이와 둥근 모서리 바깥은 배경이 보이고, 실제 카드와 스크롤바만 뒤를 가립니다. 클릭·드롭 범위도 실제 보이는 영역과 일치하며 투명한 여백에서는 뒤에 보이는 대상을 따릅니다. 화면에 다 들어가지 않으면 함께 스크롤합니다. 자식 카드 폭은 루트의 보이는 내용 폭에 맞춰 기본 100% 배율에서 260픽셀로 표시하며, 보이지 않는 창 외곽을 포함한 274픽셀을 기준으로 삼지 않습니다.
- **드래그 안내에 따른 순서·소속 변경:** 삽입선은 그 위치로 이동, 폴더 가운데는 안으로 넣기, 일반 항목 가운데는 새 폴더로 묶기입니다. 자식을 빈 바탕화면에 놓으면 새 루트로 꺼냅니다. Alt는 루트의 자석·묶기를 끄고 자식 드래그는 취소합니다. 놓을 때 대상을 다시 확인하고 미리 본 변경을 저장한 뒤 화면에 적용합니다.
- **저장되는 형제 순서:** 수동 순서는 다시 캡처하거나 메모를 고쳐도 유지합니다. 폴더 우클릭의 원본 이름순 정렬·최근 저장순 정렬은 선택한 때 한 번만 적용합니다. 원본 이름은 메모로 바뀐 스티커 제목과 다를 수 있습니다.
- **현재 세션의 마지막 변경 되돌리기:** 편집을 마친 뒤 Ctrl+Z 또는 마지막 변경 되돌리기로 생성·재캡처, 내용·색상·경로, 묶기·소속·순서·정렬, 루트 배치·폭, 삭제·복원을 역순으로 되돌립니다. 펼침·숨김·스크롤·앞뒤 순서는 대상이 아닙니다. 앱 재시작 시 이력은 초기화되며, 편집기 안의 Ctrl+Z는 글자 편집에 사용합니다.
- **루트가 움직이지 않는 편집:** 루트 편집은 한 줄 헤더 안에서 처리하고, 자식 편집은 해당 행과 그 아래 행만 재배치합니다. 저장·취소 시 행 높이를 되돌립니다. 구조 변경·숨김·종료 전에 편집을 저장하며, 실패하면 입력을 유지하고 해당 작업을 중단합니다.
- **서로 다른 화면 배율의 이동:** 도착 모니터에 맞춘 루트·패널·행 크기를 계산하고, 패널에 배율이 중복 적용되던 문제를 수정했습니다. 도착 배치는 미리보기와 일치하도록 적용합니다.
- **한글 조합 후 저장:** 조합 중 Enter는 글자 확정, 다음 Enter는 저장입니다. 다른 창이나 형제 항목으로 이동해 자동저장할 때 마지막 음절이 빠지던 문제를 수정했습니다. 조합 결과가 반영될 시간을 기다리고 입력창 상태를 바꾸기 전에 초안을 확보합니다.

폴더 안에서 항목이 줄어든 뒤 불필요한 스크롤바 폭이 남던 문제도 수정했습니다. 기존 책갈피 표시·숨김 단축키, 검색, 색상과 원본 위치 재개는 유지합니다. 자세한 조작은 [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

## 설치와 DB v9 이전

설치 형식은 `WorkBookmark-0.2.20-win-x64.msi`와 .NET 런타임을 포함한 포터블 ZIP입니다. 배포 파일 구성은 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt의 6종입니다. 패키지는 미서명입니다.

**0.2.20은 기존 DB를 처음 열 때 v9로 이전합니다.** 0.2.12~0.2.19가 사용한 v8 DB도 이번에는 이전 대상입니다. 변경 전에 데이터 폴더에 `bookmarks.db.pre-migration-….bak`을 남기고 기존 표시 순서를 형제 순서로 저장합니다. 책갈피·메모·관계·색상·열림 상태와 기존 배치 기록은 보존합니다. 루트 위치·폭과 선택한 목록/스티커 모드는 유지하며, 루트 높이는 한 줄 헤더로 표시합니다. 과거 자식 좌표 대신 공통 패널의 행 배치를 사용합니다.

**0.2.19는 v9 DB를 읽을 수 없습니다. 이전 전 백업 없이는 복귀할 수 없습니다.** 복귀하려면 앱을 종료하고 현재 데이터 폴더를 별도로 보존한 뒤 이전 전 백업의 복사본을 복원해야 합니다. 복원한 백업 이후에 추가·수정한 기록은 포함되지 않습니다. [업데이트·백업·복귀 안내](user-manual.ko.md#maintenance)를 먼저 확인하세요. 실행 중인 포터블 버전은 MSI 설치 전에 트레이에서 종료합니다.

## 검증 범위와 확인 결과

사람이 격리된 합성 자료의 실제 제품 창을 직접 조작했고, 저장소와 창의 화면 좌표를 함께 관찰했습니다. 이는 자동으로 private handler를 호출한 검사와 구분합니다. 초기 실패와 수정 후 재검증 기록은 [결정·검증 기록](decisions.md)에 남깁니다.

| 범위 | 현재 확인 결과 |
|---|---|
| 폴더 조작 | 일반 항목 묶기, 루트 이동, 접기·펼치기, 자식 분리와 되돌리기를 확인했습니다. 관계·순서와 주변 스티커 위치를 대조했습니다. |
| 혼합 화면 배율 | 100%↔125% 모니터 왕복을 확인했습니다. 멈춘 뒤 놓은 사례에서 루트와 패널 미리보기·확정 좌표가 일치했고, 행 크기와 주변 위치가 유지됐습니다. 기록 간격 사이에 포인터가 계속 움직인 사례까지 정확한 최종 미리보기 일치로 주장하지 않습니다. |
| 루트 한글 입력 | Enter의 조합 확정·저장 구분, 초안 취소, 창 전환 후 마지막 음절을 포함한 자동저장을 확인했습니다. |
| 자식 한글 입력 | Enter 저장·취소·형제 선택 후 자동저장을 확인했습니다. 편집 중 패널이 늘고 종료 후 줄었으며, 루트·주변 스티커의 위치와 계층·순서가 유지됐습니다. |
| 드래그 저장 실패 실기 | 저장 실패를 주입한 실제 드래그에서 `folder-drop` 거부 1회를 확인했습니다. 실패 직전 안정 상태와 직후의 책갈피·배치 데이터가 정확히 같았으며, 사용자도 실패 후 기존 상태 유지를 확인했습니다. 이후 의도적으로 옮긴 결과는 이 비교에 섞지 않았습니다. |
| 외형 수정 후 집중검사 | 빌드 경고·오류 0개, 패널 30개·드래그 정책 33개·실제 모니터 DPI 10개 검사를 통과했습니다. 기본 행·루트/자식 편집·스크롤·위로 펼침 렌더를 확인했습니다. [집중검사 기록](evidence/tree-policy-2026-11-06/transparent-card-checks.json)의 DPI 검사는 프로그램이 이동시킨 창의 결과이며, 렌더는 실제 창 영역을 반영한 구성요소 이미지입니다. 사람의 포인터 조작이나 바탕화면 캡처와 구분하고 전체 자동검사 수에 합산하지 않습니다. |
| 최종 외형의 사용자 재확인 | 최초 시각 확인에서 발견한 사각 배경과 루트보다 넓은 자식 카드를 수정한 뒤 사용자가 외형을 확인했습니다. 실제 100%↔125% 모니터 이동 기록에서 루트와 자식의 보이는 폭 정렬을 확인했고, 창 영역에는 카드 면이 포함되고 간격·모서리 바깥은 제외됐습니다. 사용자가 여러 차례 분리·묶기·되돌리기를 수행한 뒤 두 자식이 같은 루트로 복원됐습니다. 중간에 사용자가 폭을 조절한 기록이 있으므로 모든 샘플의 폭이 고정돼 있었다는 의미는 아닙니다. |
| 전체 자동검사 | 실행 소스·환경·검사 수와 최종 결과는 [0.2.20 릴리스 본문](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20)과 연결된 검증 기록을 기준으로 합니다. 위 집중검사와 이전 실행 결과를 합산하지 않습니다. |
| 패키지·게시 자산 | 게시 바이너리, MSI 구조·관리 추출·파일 해시와 업로드 자산 대조 결과는 [0.2.20 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20)의 첨부 검증 JSON 및 본문을 기준으로 합니다. 소스 기준은 `SourceSnapshot.json`, 배포 파일 지문은 `SHA256SUMS.txt`에 기록합니다. |

초기 혼합 배율 실기에서 패널의 크기가 다시 확대·축소되는 문제를, 초기 한글 자동저장 실기에서 마지막 음절 누락을 확인했습니다. 두 문제를 수정한 뒤 위의 직접 입력 재검증을 통과했습니다. 수정 전 사용자 응답만으로 성공을 판정하지 않았습니다. 최종 외형과 이후 수정까지 모든 기능 실기를 반복했다는 뜻은 아닙니다.

초기 설계는 카드 사이 여백까지 불투명한 패널이었습니다. 이후 사용자가 **개별 둥근 스티커만 보이고 카드 사이와 모서리 바깥은 배경이 보이는 방식**으로 변경을 승인했습니다. 공통 배치·순서·스크롤과 루트 기준점은 유지하며, 이전 정책에서 확인한 실기를 새 투명 영역과 클릭·드롭 동작의 검증으로 대신하지 않습니다.

**실제 MSI 설치·업데이트·제거·재로그인 전주기와 Office/탐색기 50회 실기 행렬은 이번 버전에서 실행하지 않았습니다.** MSI 관리 추출은 실제 설치 시험을 대신하지 않으며, 시험 호스트의 제품 창 확인은 설치된 앱의 정상 UI 진입점 검증을 뜻하지 않습니다. 이 항목들은 [MSI 운영·검증 절차](windows-installer.ko.md)에서 별도 범위로 관리합니다.
