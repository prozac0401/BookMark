# WorkBookmark 0.1.6 Preview 1

문서를 연 뒤 다른 창을 클릭할 때 반복되던 확인 실패 알림과 웹 Office 응답 대기 중 입력 지연을 수정했습니다. MSI 업데이트는 이전 설치를 자동 제거한 뒤 진행하며, 완료 화면에서 프로그램을 바로 실행할지 선택할 수 있습니다.

## 변경 사항

- 책갈피 실행 후 다른 창을 클릭해도 최초 문서 열기와 열림 확인을 계속합니다. 이후의 위치 이동·창 활성화·자동 재시도는 새 입력이 있으면 중단합니다.
- **처리 결과를 확인하지 못했습니다** 알림은 표시하지 않습니다. 확인하지 못한 결과를 성공으로 바꾸지 않으며, 실제 접근 실패 안내는 유지합니다.
- 마우스·키보드 입력 감시와 Office 응답 대기를 분리했습니다. 문서가 준비되는지 확인하는 최대 45초 동안 다른 작업을 할 수 있도록 조정하고, 반복 문서 조회 빈도를 줄였습니다.
- 0.1.6 MSI는 같은 사용자의 이전 MSI 설치를 자동 제거하고 새 버전을 설치합니다. 책갈피·메모·설정과 Windows 로그인 자동 실행 선택을 보존합니다.
- 설치 완료 화면의 **업무 책갈피 실행** 체크박스는 기본 선택되어 있습니다. 바로 실행하지 않으려면 선택을 해제한 뒤 마칩니다. 무인 설치(`/qn`)에서는 앱을 자동 실행하지 않습니다.

## 설치

로컬 배포 폴더 `artifacts/releases/<빌드시각>/`의 `WorkBookmark-0.1.6-win-x64.msi`를 실행하세요. 기존 MSI는 미리 제거할 필요가 없습니다. 포터블 ZIP판이 실행 중이면 먼저 트레이에서 종료하세요. 포터블 실행 폴더는 MSI가 자동 제거하지 않습니다.

설치 직후 실행 체크박스는 Windows 로그인 자동 실행 설정과 별개입니다. 체크를 해제한 경우에도 시작 메뉴의 **WorkBookmark → WorkBookmark**에서 실행할 수 있습니다.

포터블 패키지는 `WorkBookmark-0.1.6-win-x64.zip`입니다. `Source.zip`, `SourceSnapshot.json`, `SHA256SUMS.txt`, MSI 검증 JSON을 함께 제공합니다. 이번 패키지는 `-SourceMode WorkingTree`로 현재 수정 사항을 포함합니다. GitHub 릴리스는 아직 게시하지 않았습니다.

## 검증과 제한

MSI 검증 JSON에는 패키지 구조 검사와 관리 이미지 추출 후 게시 파일 해시 대조 결과를 기록합니다. 관리 이미지 추출은 실제 사용자에게 설치하거나 기존 앱을 제거하는 검증이 아닙니다.

실제 MSI 업그레이드·제거·완료 화면의 체크박스 조작·Windows 재로그인, 사내 AD 인증과 Office 대기 중 마우스 반응은 별도 사용자 계정 또는 VM 및 실제 업무 환경에서 확인해야 합니다. 자동검사 통과를 이 실기검증의 완료로 표시하지 않습니다.

자세한 동작과 수동 확인 절차는 [문서 열기·입력 지연 수정](resume-input-fix.ko.md), [MSI 설치·검증 안내](windows-installer.ko.md), [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.
