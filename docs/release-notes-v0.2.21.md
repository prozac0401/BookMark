# WorkBookmark 0.2.21 릴리스 안내

2026년 11월 13일

**0.2.21을 2026-11-13 07:38:31 UTC에 정식 공개했습니다.** [릴리스와 설치 파일](https://github.com/prozac0401/BookMark/releases/tag/v0.2.21)에서 받을 수 있습니다. 배포 소스·태그는 `45502523a0f06ee6565b7e4d0778343a6ef85a6c`에 고정되어 있으며, 이 문서의 최종 검증 기록은 공개 후 보강했습니다.

목록과 스티커에서 **Ctrl+클릭으로 여러 책갈피를 선택하고 함께 이동**할 수 있습니다. 선택한 항목 하나를 끌면 선택 전체를 옮기며, **Ctrl+Z 한 번**으로 전체 이동을 되돌립니다.

## 여러 책갈피 함께 옮기기

1. **Ctrl을 누른 채 제목을 차례로 클릭**해 옮길 책갈피를 선택합니다. 이미 선택한 항목을 Ctrl+클릭하면 선택에서 빠집니다.
2. Ctrl을 놓고 선택한 항목 하나를 끕니다. 스티커에는 선택 테두리와 이동할 위치의 미리보기를 표시하고, 목록에는 선택 배경과 이동 안내를 표시합니다.
3. 폴더 가운데에 놓으면 선택 전체를 폴더에 넣고, 삽입선에 놓으면 그 위치로 옮깁니다. 일반 항목의 묶기 영역에 놓으면 대상과 선택 항목들을 하나의 새 폴더로 묶습니다. 빈 영역에 놓으면 최상위로 꺼냅니다.

여러 최상위 스티커를 바탕화면에서 옮기면 화면 안에서 간격을 유지하며 함께 이동합니다. 폴더와 그 자식을 함께 선택했으면 폴더를 한 번만 옮기고 자식 관계를 유지합니다. 폴더 안으로 옮기는 항목의 순서는 화면의 트리 순서를 따릅니다.

스티커에서 일반 클릭은 한 항목만 선택합니다. 선택한 여러 항목 중 하나를 누른 채 드래그하면 다중 선택을 유지하고, 끌지 않고 놓으면 그 항목만 선택합니다. **Esc**는 선택을 먼저 해제하며, 선택이 없으면 해당 트리를 숨깁니다. 드래그 중 Esc는 이동을 취소하고, 편집 중 Esc는 편집을 취소합니다.

## 이동과 실행 취소

- 여러 항목의 관계·순서·위치를 한 작업으로 저장합니다. 저장에 실패하면 전체 이동을 취소하고 기존 상태를 유지합니다.
- 부모와 자식의 중복 이동, 자기 자신이나 선택한 폴더의 하위 항목으로 옮기기를 막습니다.
- 접히거나 숨겨지거나 검색에서 제외된 항목은 선택에서 빠집니다. 드래그 중 대상이 삭제되거나 선택이 바뀌면 일부만 옮기지 않고 해당 작업을 취소합니다.
- Ctrl 선택 직후 Ctrl을 놓고 빠르게 드래그해도 제목 편집으로 처리하지 않습니다.
- **Ctrl+Z 한 번**으로 전체 이동을 되돌립니다. 실행 취소 이력은 현재 실행 세션에서만 유지됩니다.

## 설치와 데이터

설치 파일은 `WorkBookmark-0.2.21-win-x64.msi`이며, 설치 없이 실행할 수 있는 포터블 ZIP도 제공합니다. MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt를 릴리스에 함께 제공합니다. 패키지는 서명되지 않았습니다.

**DB 형식은 v9로 유지합니다.** 0.2.20에서 업데이트하면 추가 DB 이전이 없습니다. 0.2.19 이하의 오래된 DB는 기존 절차에 따라 백업한 뒤 v9로 이전합니다. 0.2.19는 v9 DB를 읽을 수 없으므로 그 버전으로 복귀하려면 이전 전 백업이 필요합니다. [설치·업데이트·백업 안내](user-manual.ko.md#maintenance)를 참고하세요.

## 검증 범위

최종 릴리스 빌드 경고·오류 **0개**, 전체 자동검사 **1,218개**를 통과했습니다(Core 106 · IPC 17 · Desktop 769 · 기타 326). 최종 게시 DLL의 다중 선택 검사 **45개**와 게시 실행 파일의 합성 worker 검사 **6/6**도 통과했으며, 이 집중검사는 전체 합계에 다시 더하지 않습니다. MSI 구조·관리 추출 **54개** 검사, 포터블 ZIP **1,385개 파일**과 소스 아카이브 **936개 파일**의 전체 대조를 통과했습니다. 업로드 자산 6종의 서버 해시와 비인증 공개 다운로드한 MSI·체크섬·소스 기준 파일도 일치했습니다. [최종 검증 기록](evidence/release-0.2.21-2026-11-13/release-verification.json)과 [로그·렌더 안내](evidence/release-0.2.21-2026-11-13/README.md)에서 범위를 확인할 수 있습니다.

구현 단계에서 Release 빌드 **경고·오류 0개**, Core **106개**와 Desktop **769개**, 합계 **875개** 자동검사를 통과했습니다. Core 결과에는 다중 이동의 원자적 저장·실행 취소·재시작 보존 등을 확인하는 새 검사 9개가 포함되며, Desktop 결과에는 다중 선택·드래그 검사 45개가 포함됩니다. 이 집중검사 수는 합계에 다시 더하지 않습니다. 선택된 폴더·루트·하위 항목과 미선택 항목은 전체 폼 렌더로 확인했습니다.

배포 소스를 고정한 전체 빌드·자동검사, MSI·포터블 패키지와 게시 자산 대조의 최종 결과는 [0.2.21 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.21)의 본문과 첨부 검증 자료를 기준으로 합니다. `SourceSnapshot.json`에서 소스 기준을, `SHA256SUMS.txt`에서 배포 파일의 지문을 확인할 수 있습니다.

이번 기능의 **사람이 직접 수행한 Ctrl 다중 선택·드래그, 실제 한글 IME, 혼합 배율 모니터 간 이동, 실제 MSI 설치·업데이트·제거 전주기는 아직 실행하지 않았습니다.** 합성 네이티브 메시지·구성요소 검사와 렌더는 이러한 실기를 대신하지 않습니다. 이전 버전에서 수행한 직접 조작·한글 입력·혼합 배율 확인은 [0.2.20 릴리스 안내](release-notes-v0.2.20.md)에 별도로 보존합니다.
