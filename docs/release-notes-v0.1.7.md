# WorkBookmark 0.1.7

설치부터 매일 쓰는 트레이까지 청록색 책갈피 디자인으로 통일했습니다. 문서가 열린 뒤 반복되던 위치 이동 미완료 안내를 제거하고, 앱과 현재 사용 안내의 시험판·제한 버전 표기를 정리했습니다.

## 변경 사항

- 설치 마법사의 기본 붉은 이미지를 WorkBookmark 전용 책갈피 이미지로 교체했습니다.
- 실행 파일, 시작 메뉴, 설치된 앱 목록, 프로그램 창에 전용 아이콘을 적용했습니다. 트레이는 작은 크기와 밝고 어두운 배경에 맞춘 별도 아이콘을 사용합니다.
- 문서가 열렸지만 이후 위치 이동이 중단된 경우 반복 알림을 표시하지 않습니다. 실제 저장 위치 이동을 확인한 경우에만 이동 성공으로 기록하며, 파일 접근 실패와 로그인 등 필요한 안내는 유지합니다.
- 트레이 툴팁, 첫 실행 안내, 최근 목록과 설정 창에서 제품 이름을 간결하게 표시합니다.
- 여러 줄 알림은 내용에 맞춰 높이를 조절하며 파일 이름과 URL의 `&` 문자를 그대로 표시합니다.

## 다운로드와 업데이트

[GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.1.7)에서 **WorkBookmark-0.1.7-win-x64.msi**를 받아 실행하세요. 이전 MSI 설치는 자동 교체하며 책갈피·메모·설정과 로그인 자동 실행 선택을 유지합니다. 설치 완료 화면에서 **업무 책갈피 실행**을 선택할 수 있습니다.

설치 없이 사용하려면 **WorkBookmark-0.1.7-win-x64.zip**을 폴더 전체로 풀어 실행하세요. 기존 포터블 앱이 실행 중이면 트레이에서 먼저 종료하세요.

소스 ZIP, 소스 커밋 정보, MSI 검증 JSON과 SHA-256 목록을 함께 제공합니다. 자세한 사용법은 [설치 및 사용 매뉴얼](user-manual.ko.md)을 참고하세요.

Release 빌드 경고·오류 0개, 자동검사 **470개 통과**, 실제 폼 렌더링 4종을 확인했습니다. [이번 버전 검증 기록](evidence/branding-2026-09-22/README.md)과 배포에 첨부된 MSI 검증 JSON에서 근거를 확인할 수 있습니다. 환경별 Office·브라우저 동작과 실제 MSI 업그레이드·Windows 재로그인 검증은 이 자동검사와 구분하며, 기존 상태는 [호환성표](compatibility.md)에 유지합니다.
