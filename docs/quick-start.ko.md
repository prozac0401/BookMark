# 업무 책갈피 빠른 시작

**제한된 시험판 · Windows/Office 전체 수용시험 미완료**

1. ZIP을 새 폴더에 모두 풀고 `WorkBookmark.exe`를 실행합니다. 런타임 파일을 함께 유지하세요. 트레이에 상주하며 첫 실행에 조작을 안내합니다.
2. 평소처럼 탐색기나 Excel에서 일합니다. 새 업무를 등록할 필요가 없습니다.
3. 중단할 때 **Ctrl+Alt+B**를 한 번 누릅니다. ‘책갈피를 남겼습니다’는 DB 커밋이 완료됐다는 뜻입니다. 파일/폴더 또는 Excel 시트·셀을 읽지 못하면 저장하지 않습니다.
4. 돌아올 때 **Ctrl+Alt+J → Enter**. 맨 위 항목은 가장 최근에 저장한 위치입니다. 클릭 한 번도 재개합니다. 검색창은 이름·경로·시트·메모를 전체 기록에서 찾습니다. Esc/외부 클릭으로 목록을 닫습니다.
5. 메모는 선택 사항입니다. 저장 알림의 ‘메모’ 또는 항목 우클릭으로 500자 이내 한 줄을 적습니다. Enter/외부 클릭은 저장, Esc는 편집 취소입니다. 같은 위치를 다시 저장해도 이전 메모를 유지합니다.
6. 항목 우클릭의 ‘목록에서 지우기’는 원본을 삭제하지 않습니다. 10초간 알림 또는 트레이 메뉴에서 되돌릴 수 있습니다. 파일 접근에 실패한 항목은 ‘위치 다시 지정’으로 같은 종류의 새 경로를 검증하고 적용합니다.

트레이의 **설정**에서 두 단축키와 시작프로그램을 변경합니다. 충돌하면 해당 단축키의 비활성을 안내하며, 기존에 동작하던 조합은 새 등록이 성공할 때까지 유지합니다. 시작프로그램은 기본 꺼짐입니다. 앱을 두 번 실행하면 기존 앱의 최근 목록을 엽니다.

## 지원 범위와 결과의 뜻

- 탐색기의 실제 폴더, 선택 없음 또는 항목 하나. 홈/검색/휴지통/ZIP/다중 선택/바탕화면/파일 대화상자는 제외합니다.
- 설치형 Excel의 저장된 xlsx/xlsm/xlsb/xls, 일반 워크시트의 활성 셀 하나. 미저장 새 문서, HTTPS 문서, 차트 시트, 보호된 보기 등은 거절합니다.
- 일반 문서는 ‘열기 요청’까지만 확인합니다. 실행 파일·스크립트·바로가기·허용 목록 밖 형식은 **폴더에서 위치만 표시**합니다.
- ‘기록한 셀로 이동했습니다’는 실제 경로·시트·주소를 다시 확인한 결과입니다. 전면 전환은 별도로 안내합니다.
- 시간초과/중단은 이미 전달된 열기나 이동을 취소하지 못합니다. ‘결과를 확인하지 못했습니다’가 나오면 대상 앱을 확인하세요. 자동 반복하지 않습니다.
- 도구는 문서 저장/닫기, 셀 내용 쓰기, 매크로 실행, 보안 설정 변경을 하지 않습니다. **파일 열기·셀 이동은 기존 Excel 이벤트/추가 기능/자동저장을 유발할 수 있습니다.** 좌표는 행 삽입·정렬 후 같은 데이터를 추적하지 않습니다.
- UNC·DRM·Office 32비트 등은 호환성표의 실제 시험 상태를 따릅니다.

## 데이터·종료·삭제

데이터: `%LOCALAPPDATA%\WorkBookmark\bookmarks.db` (경로·메모 평문), `settings.json`, 순환 진단 로그. 외부 업로드/계정/텔레메트리는 없습니다. HWND/PID는 영구 저장하지 않습니다.

삭제하려면 설정에서 시작프로그램을 끄고 트레이에서 종료한 뒤 배포 폴더를 지웁니다. 기록 DB는 남습니다. 기록까지 없애려는 경우에만 사용자가 데이터 폴더를 별도로 삭제합니다. 손상 DB는 앱이 자동 초기화하지 않습니다.
