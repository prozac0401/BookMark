# 업무 책갈피 빠른 시작 · 0.2.9 로컬 릴리스 준비본

설치 파일 선택부터 백업·복원과 문제 해결까지는 **[설치 및 사용 매뉴얼](user-manual.ko.md)**을 참고하세요.

**0.2.9는 로컬 릴리스 준비본이며 공개 배포 전입니다.** 로컬 MSI·포터블 ZIP 위치는 [검증 기록](evidence/sticker-alignment-2026-10-06/README.md), 변경 내용은 [0.2.9 릴리스 준비 기록](release-notes-v0.2.9.md)을 참고하세요. 이전 공개 설치 파일은 **[0.2.8 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.8)**에 있습니다.

**0.2.9**는 **Ctrl+Alt+J로 스티커 전체 표시·숨기기**, **주변 스티커에 자석 정렬**, **가로·세로·격자 일괄 정렬**을 추가합니다. Release 빌드 경고·오류 0개, 자동검사 **746개 통과**(Desktop **351개** 포함)를 확인했습니다. 격리한 실제 앱에서는 사용자 지정 키 **Ctrl+Alt+Shift+F16**으로 **2개 표시 → 모두 숨김 → 2개 표시**와 위치·메모 보존을 확인했습니다. 기본 Ctrl+Alt+J 직접 입력, 실제 마우스 드래그·Alt 드래그·혼합 화면 배율·한글 입력기 조합과 이번 MSI 설치·업데이트 실기는 아직 미검증입니다. 상세 결과와 패키지 검사 확인 방법은 [검증 기록](evidence/sticker-alignment-2026-10-06/README.md)을 참고하세요. 패키지는 서명되지 않았습니다.

**0.2.3 이하를 사용자 지정 경로에 설치했다면 기존 MSI와 원래 INSTALLFOLDER를 지정해 먼저 제거한 뒤 새로 설치하세요.** 기본 경로 설치는 일반 업데이트를 확인했습니다. [설치 경로 이행 안내](windows-installer.ko.md)를 먼저 확인하세요.

1. 준비한 로컬 `WorkBookmark-0.2.9-win-x64.msi`를 실행합니다. 이전 MSI 설치는 자동 제거하고 새 버전을 설치하며, 책갈피와 설정은 유지합니다. 완료 화면의 **업무 책갈피 실행**을 선택한 채 마치면 바로 실행됩니다. 나중에 실행하려면 체크를 해제하세요. 기존 포터블 앱은 트레이에서 종료하세요.
2. 탐색기·Excel·Word·PowerPoint·메모장 또는 Edge·Chrome·네이버 Whale에서 **Ctrl+Alt+B**를 눌러 현재 위치를 저장합니다. ‘책갈피를 남겼습니다’는 로컬 DB 저장이 완료됐다는 뜻입니다.
3. 새 설치는 **스티커 모드**입니다. 0.2.5에서 선택한 목록/스티커 모드는 이번 업데이트에도 유지합니다. 보이는 스티커의 **오른쪽 화살표(바로가기)**로 돌아갑니다. 모두 숨겨져 있으면 **Ctrl+Alt+J**로 표시하고, 일부만 숨겼다면 **트레이 → 책갈피 보기**로 전체를 표시하세요. 목록을 원하면 **트레이 → 설정 → 목록으로 보기 → 적용**을 선택하고 **Ctrl+Alt+J → 항목 선택 → Enter**를 사용하세요.
4. 저장 알림의 **메모**, 목록 항목 우클릭, 또는 **스티커 제목 한 번 클릭**으로 한 줄 메모를 남깁니다. 메모가 없어서 URL·주소·파일명이 보일 때도 같은 제목을 누릅니다. 같은 위치를 다시 저장해도 메모는 유지됩니다.
5. 트레이의 **설정**에서 표시 방식, 단축키와 Windows 로그인 시 실행 여부를 변경합니다. 최초 설치에서는 로그인 자동 실행이 켜져 있으며, 기존에 껐다면 그 선택을 유지합니다. 트레이 **종료**는 현재 실행만 끝냅니다.

## 포스트잇으로 사용하기

스티커 모드에서는 지우지 않은 책갈피가 각각 작은 창으로 나타납니다. **메모가 있으면 메모를 제목으로**, 없으면 웹 URL·폴더 주소·파일명을 표시합니다. 메모장 보관본은 메모가 없을 때 기존 보관 제목을 사용합니다. 제목은 한 줄이며 긴 내용은 말줄임표로 줄입니다. 전체 메모·대상 정보는 툴팁과 기존 복사 메뉴로 확인합니다.

**Ctrl+Alt+J**는 스티커가 하나라도 보이면 **모두 숨기고**, 모두 숨겨져 있으면 **모두 표시**합니다. 일부만 숨겼다면 첫 입력으로 나머지도 숨기고, 다시 누르면 전체를 표시합니다. 설정에서 **책갈피 보기** 단축키를 바꿨다면 바꾼 키를 사용하세요. **트레이 → 책갈피 보기**와 트레이 아이콘 더블클릭은 항상 전체 스티커를 표시합니다. 목록 모드에서는 단축키로 목록을 엽니다.

스티커 모드로 실행하면 단축키를 누르기 전부터 스티커가 나타나며, 다른 일반 창 위에 계속 표시됩니다. 오른쪽 화살표 버튼에 마우스를 올리면 **바로가기**가 표시되며, 누른 스티커에만 처리 중 상태를 표시합니다. 평상시에는 메모 한 줄과 화살표 버튼만 표시합니다. 제목줄·종류 아이콘·접기·지우기 버튼은 없으며 다른 기능은 우클릭 메뉴에서 사용합니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 이동·크기 조절 | 스티커의 배경 여백을 끌어 이동하고, 가장자리나 모서리를 끌어 크기 변경 |
| 자석 정렬 | 주변 스티커 가까이 끌면 가장자리와 행·열을 맞춤. **Alt**를 누른 채 끌면 자유 이동. **설정 → 스티커 자석 정렬**에서 끄기 가능 |
| 작업 이어가기 | 오른쪽 화살표 버튼(**바로가기**) 클릭 |
| 접기·펼치기 | 우클릭 메뉴의 **스티커 접기 / 스티커 펼치기** 또는 **Ctrl+Space** |
| 다른 창 위에 두기 | 스티커 모드에서는 항상 위에 표시하며 고정·해제 조작 없음 |
| 스티커에 메모하기 | **제목을 한 번 클릭**하거나 **Ctrl+E**. 해당 스티커 안에서 입력한 뒤 **다른 창으로 이동하면 자동 저장**. **Enter**로 바로 저장, 저장 전 취소는 **취소 / Esc** |
| 한 스티커 잠시 숨기기 | 우클릭 메뉴의 **이 스티커 숨기기** 또는 **Esc** |
| 전체 스티커 숨기기 | 스티커가 보일 때 **Ctrl+Alt+J** 또는 **트레이 → 스티커 모두 숨기기** |
| 숨긴 스티커 다시 표시 | 모두 숨겨져 있으면 **Ctrl+Alt+J**. 일부만 숨겼어도 전체를 바로 표시하려면 **트레이 → 책갈피 보기** 또는 트레이 아이콘 더블클릭 |
| 흩어진 위치 정리 | **트레이 → 스티커 위치 모으기 → 격자로 / 가로로 / 세로로 정렬** |
| 검색하기 | **트레이 → 목록에서 찾기** |

자석 정렬은 기본으로 켜져 있습니다. 100% 배율 기준 **12픽셀 이내**에서 주변 스티커의 가장자리에 붙고, 나란히 놓을 때는 **8픽셀 간격**을 둡니다. 화면 배율에 따라 함께 조절됩니다. 일괄 정렬은 마우스가 있는 모니터에 숨긴 스티커까지 모두 표시하며, 크기·메모·접힘 상태를 유지하고 새 위치를 저장합니다.

기본 내용 영역은 100% 배율 기준 **260×36**, 최소 **240×36**이며 테두리는 별도로 더해집니다. **0.2.6의 기본 내용 크기 260×88 항목만** 새 한 줄 크기로 줄이고, 사용자가 조절한 외곽 크기와 선택한 표시 모드는 유지합니다. 기존 기본 크기를 판별할 때 화면 배율에 따른 저장 크기 차이도 반영합니다. 위치·모니터·접힘과 삭제 항목의 배치도 보존합니다. 이전 표시 규칙을 처음 적용하는 설정에는 기존 최초 적용 정책대로 새 기본 크기와 스티커 모드를 적용합니다. 목록을 원하면 **설정 → 목록으로 보기 → 적용**을 선택하세요.

메모를 편집하면 폭을 유지하고, 내용 높이가 160보다 작을 때만 **170으로 잠시 펼칩니다**. 이미 큰 창은 크기를 바꾸지 않습니다. **저장 성공·취소·자동 저장 성공 뒤 편집 직전 크기·접힘 상태로 복귀**합니다. 자동 보정한 위치는 복구하고, 사용자가 직접 이동한 위치는 유지합니다. 저장 실패 시 초안과 큰 편집 영역을 유지합니다.

스티커 메모는 **한 줄, 최대 500자**입니다. **저장 버튼은 표시하지 않습니다.** 한글 조합 중 Enter는 글자 확정만 합니다. 다른 창이나 스티커로 이동하면 자동 저장하며, 저장이 끝나도 이동한 창에서 계속 작업할 수 있습니다. 저장하지 못하면 입력한 글과 오류 안내가 남습니다. 스티커로 돌아와 **Enter**를 누르거나 다른 창으로 다시 이동해 재시도하세요. 스티커 모드에서 잠시 목록을 열어 메모를 선택해도 해당 스티커에서 입력합니다. **목록 모드에서 여는 별도 메모 창**은 기존처럼 밖을 클릭해도 저장합니다.

**스티커 우클릭 메뉴의 지우기 = 목록에서도 같은 책갈피 지우기**입니다. 원본 파일은 유지됩니다. 각 삭제 후 10초 동안 **되돌리기**로 최근 항목부터 되살릴 수 있습니다. 시간이 지났거나 앱을 다시 실행한 뒤에는 **트레이 → 최근 삭제… → 항목 선택 → 선택한 책갈피 복원**을 사용하세요. 최근 삭제 100개를 표시합니다. **숨기기 메뉴 / Esc는 삭제하지 않고 숨기기만 합니다.** 다만 메모를 편집 중일 때 **Esc**는 메모 편집을 먼저 취소합니다.

## 웹페이지

Edge·Chrome·네이버 Whale의 일반 HTTP/HTTPS 페이지 본문을 선택하고 **Ctrl+Alt+B**를 누릅니다. 브라우저 확장 프로그램은 필요하지 않습니다. 주소 표시줄을 편집 중이면 먼저 편집을 마치세요. 실제 Whale 저장·재열기는 아직 미검증이며 자동 확인이 어려우면 아래 URL 직접 입력을 사용하세요.

전체 화면·앱 모드·분할 탭·접근성 제한 등으로 주소를 정확히 읽지 못하면 **트레이 → 웹페이지 URL로 추가…**에서 전체 URL과 선택 제목을 입력합니다. 어느 브라우저의 주소든 이 방식으로 저장할 수 있습니다. 기존 Edge·Chrome용 브라우저 확장은 선택적으로 계속 사용할 수 있습니다. Whale 확장의 Native Messaging 연결 등록은 이번 지원에 포함하지 않습니다.

제목과 URL의 query·fragment를 저장합니다. 페이지 본문, 스크롤, 입력 내용, 로그인 상태는 저장하지 않습니다. 재개는 Windows 기본 브라우저에서 진행하며 사이트 인증이 필요할 수 있습니다.

## 웹 URL의 Office 문서

데스크톱 Office에서 문서를 열고 셀·본문 위치·슬라이드를 저장합니다. 닫힌 문서 재개는 해당 Office 앱에 전달합니다. 문서가 준비되지 않으면 사이트 루트에 한 번 내부 접속하고, 문서가 아직 열려 있지 않음을 확인한 경우 한 번 더 열기를 요청합니다. 전체 확인은 최대 45초입니다.

로그인이나 편집을 위해 새로 클릭·입력하면 관찰은 계속하지만 이후 위치 이동과 재열기는 중단합니다. 문서만 열린 경우 별도 알림을 표시하지 않습니다. 저장 위치까지 복원한 경우에만 ‘기록한 위치로 이동했습니다’를 표시합니다.

문서 열기를 요청한 뒤 다른 창을 클릭해도 최초 열기와 열림 확인은 계속합니다. 반복되던 ‘처리 결과를 확인하지 못했습니다’ 알림은 표시하지 않습니다. 45초는 최대 확인 시간이며, 기다리는 동안 다른 창에서 마우스와 키보드를 사용할 수 있도록 입력 감시를 분리했습니다.

Windows 통합 인증으로 완료되지 않는 로그인은 안내의 **사이트 로그인**에서 마친 뒤 책갈피를 다시 실행하세요. 자세한 조건은 [Office URL 지원 안내](office-url-support.ko.md)를 참고하세요.

## 다른 문서와 데이터

- Excel은 시트 이름·단일 셀 주소, Word는 본문 문자 위치, PowerPoint는 SlideID를 사용합니다. 문서 편집 후 같은 의미의 내용까지 추적하지는 않습니다.
- 메모장은 새 문서·미저장 본문과 선택 위치를 자동 보관하며 재개할 때 별도 복원본을 엽니다.
- 탐색기는 실제 폴더 또는 단일 선택 항목을 지원합니다. 홈·검색·휴지통·ZIP 내부·다중 선택은 제외합니다.
- 실행 파일·스크립트·바로가기 등은 직접 실행하지 않고 폴더에서 위치를 표시합니다.
- 보호된 보기·DRM·상승 권한·접근 권한 등은 앱이 우회하지 않습니다.

데이터는 `%LOCALAPPDATA%\WorkBookmark`의 `bookmarks.db`, `settings.json`, 진단 로그에 보관합니다. MSI 제거 후에도 남아 재설치하면 계속 사용할 수 있습니다. 기록까지 지우려는 경우에만 사용자가 이 폴더를 별도로 삭제합니다.

0.2.0에서 갱신된 DB는 0.1.7에서 열 수 없습니다. 변경 전 자동 백업이 남으며, 구버전 복귀가 필요하면 [백업·업데이트 안내](user-manual.ko.md#maintenance)를 먼저 확인하세요.

0.2.9도 같은 DB v5를 사용합니다. 0.2.0~0.2.8에서 업데이트할 때 새 데이터 형식 이전은 추가하지 않습니다. 기존 책갈피·메모·설정·사용자 크기는 유지하고, 자석 정렬 선택 항목이 없는 기존 설정은 켜짐으로 읽습니다. 0.2.4에서 수정한 사용자 지정 MSI 설치 경로 보존 동작도 유지합니다.

MSI는 제어판 ‘프로그램 제거’ 또는 Windows ‘설치된 앱’에서 **WorkBookmark → 제거**를 사용합니다. 포터블 ZIP은 자동 실행을 끄고 트레이에서 종료한 뒤 압축 해제한 폴더를 삭제합니다.

실제 AD 로그인·재부팅·환경별 Office/브라우저 확인 범위는 [호환성표](compatibility.md)에 정리했습니다.
