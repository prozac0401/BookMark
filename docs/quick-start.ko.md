# 업무 책갈피 빠른 시작 · 0.2.2

설치 파일 선택부터 백업·복원과 문제 해결까지는 **[설치 및 사용 매뉴얼](user-manual.ko.md)**을 참고하세요.

**[WorkBookmark 0.2.2 다운로드](https://github.com/prozac0401/BookMark/releases/tag/v0.2.2)**에서 MSI 또는 포터블 ZIP을 받으세요. 이번 버전의 변경 사항과 확인 범위는 [릴리스 기록](release-notes-v0.2.2.md)에 정리했습니다.

설치 패키지는 **서명되지 않았습니다**. Desktop 회귀검사 197개와 [합성 화면](evidence/note-click-2026-09-22/README.md)을 확인했으며, 실제 설치·마우스 입력·한글 IME·여러 모니터 실기는 미실행입니다.

1. `WorkBookmark-0.2.2-win-x64.msi`를 실행합니다. 이전 MSI 설치는 자동 제거하고 새 버전을 설치하며, 책갈피와 설정은 유지합니다. 완료 화면의 **업무 책갈피 실행**을 선택한 채 마치면 바로 실행됩니다. 나중에 실행하려면 체크를 해제하세요. 기존 포터블 앱은 트레이에서 종료하세요.
2. 탐색기·Excel·Word·PowerPoint·메모장 또는 Edge·Chrome에서 **Ctrl+Alt+B**를 눌러 현재 위치를 저장합니다. ‘책갈피를 남겼습니다’는 로컬 DB 저장이 완료됐다는 뜻입니다.
3. 기본 목록에서는 **Ctrl+Alt+J → 항목 선택 → Enter**로 돌아갑니다. 포스트잇을 쓰려면 **트레이 → 설정 → 포스트잇 스티커로 보기 → 적용**을 선택하세요.
4. 저장 알림의 **메모**, 목록 항목 우클릭, 또는 **스티커의 메모 텍스트 영역 한 번 클릭**으로 한 줄 메모를 남깁니다. 메모가 비어 있어도 같은 영역을 누릅니다. 같은 위치를 다시 저장해도 메모는 유지됩니다.
5. 트레이의 **설정**에서 표시 방식, 단축키와 Windows 로그인 시 실행 여부를 변경합니다. 최초 설치에서는 로그인 자동 실행이 켜져 있으며, 기존에 껐다면 그 선택을 유지합니다. 트레이 **종료**는 현재 실행만 끝냅니다.

## 포스트잇으로 사용하기

스티커 모드에서는 지우지 않은 책갈피가 각각 작은 창으로 나타납니다. **Ctrl+Alt+J** 또는 트레이 아이콘 더블클릭은 선택한 표시 방식으로 책갈피를 보여 줍니다.

스티커 모드로 실행하면 단축키를 누르기 전부터 스티커가 나타나며, 다른 일반 창 위에 계속 표시됩니다. **이어가기**를 누른 스티커에만 처리 중 표시가 나옵니다. 왼쪽 위에는 파일 종류를 구분하는 아이콘이 표시됩니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 이동·크기 조절 | 스티커 위쪽을 끌어 이동하고, 가장자리나 모서리를 끌어 크기 변경 |
| 작업 이어가기 | **이어가기** 클릭 |
| 화면을 덜 차지하게 하기 | **접기** / **펼치기** 클릭 |
| 다른 창 위에 두기 | 스티커 모드에서는 항상 위에 표시하며 고정·해제 조작 없음 |
| 스티커에 메모하기 | **메모 텍스트 영역을 한 번 클릭**하거나 **Ctrl+E**. 해당 스티커 안에서 입력하고 **저장 / Enter**, 취소는 **취소 / Esc** |
| 잠시 숨기기 | 스티커의 **× / Esc**, 전체는 **트레이 → 스티커 모두 숨기기** |
| 다시 표시·위치 정리 | **Ctrl+Alt+J**, 흩어진 창은 **트레이 → 스티커 위치 모으기** |
| 검색하기 | **트레이 → 목록에서 찾기** |

위치·크기·접기 상태는 다시 실행해도 유지됩니다. 이전 버전의 개별 고정 상태와 관계없이 스티커는 항상 위에 표시합니다. 목록으로 돌아가려면 **설정 → 목록으로 보기 → 적용**을 선택합니다.

스티커 메모는 **한 줄, 최대 500자**입니다. 한글 조합 중 Enter는 글자 확정만 하며, 다른 창을 클릭해도 자동 저장하지 않습니다. 저장하지 못하면 입력을 유지하므로 다시 저장할 수 있습니다. 스티커 모드에서 잠시 목록을 열어 메모를 선택해도 해당 스티커에서 입력합니다. **목록 모드에서 여는 별도 메모 창**은 기존처럼 밖을 클릭해도 저장합니다.

**스티커의 지우기 = 목록에서도 같은 책갈피 지우기**입니다. 원본 파일은 유지됩니다. 각 삭제 후 10초 동안 **되돌리기**로 최근 항목부터 되살릴 수 있습니다. 시간이 지났거나 앱을 다시 실행한 뒤에는 **트레이 → 최근 삭제… → 항목 선택 → 선택한 책갈피 복원**을 사용하세요. 최근 삭제 100개를 표시합니다. **× / Esc는 삭제하지 않고 숨기기만 합니다.** 다만 메모를 편집 중일 때 **Esc**는 메모 편집을 먼저 취소합니다.

## 웹페이지

Edge·Chrome의 일반 HTTP/HTTPS 페이지 본문을 선택하고 **Ctrl+Alt+B**를 누릅니다. 브라우저 확장 프로그램은 필요하지 않습니다. 주소 표시줄을 편집 중이면 먼저 편집을 마치세요.

전체 화면·앱 모드·분할 탭·접근성 제한 등으로 주소를 정확히 읽지 못하면 **트레이 → 웹페이지 URL로 추가…**에서 전체 URL과 선택 제목을 입력합니다. 어느 브라우저의 주소든 이 방식으로 저장할 수 있습니다. 기존 브라우저 확장은 선택적으로 계속 사용할 수 있습니다.

제목과 URL의 query·fragment를 저장합니다. 페이지 본문, 스크롤, 입력 내용, 로그인 상태는 저장하지 않습니다. 재개는 Windows 기본 브라우저에서 진행하며 사이트 인증이 필요할 수 있습니다.

## 웹 URL의 Office 문서

데스크톱 Office에서 문서를 열고 셀·본문 위치·슬라이드를 저장합니다. 닫힌 문서 재개는 해당 Office 앱에 전달합니다. 문서가 준비되지 않으면 사이트 루트에 한 번 내부 접속하고, 문서가 아직 열려 있지 않음을 확인한 경우 한 번 더 열기를 요청합니다. 전체 확인은 최대 45초입니다.

로그인이나 편집을 위해 새로 클릭·입력하면 관찰은 계속하지만 이후 위치 이동과 재열기는 중단합니다. 문서만 열린 경우 별도 알림을 표시하지 않습니다. 저장 위치까지 복원한 경우에만 ‘기록한 위치로 이동했습니다’를 표시합니다.

문서 열기를 요청한 뒤 다른 창을 클릭해도 최초 열기와 열림 확인은 계속합니다. 반복되던 ‘처리 결과를 확인하지 못했습니다’ 알림은 표시하지 않습니다. 45초는 최대 확인 시간이며, 기다리는 동안 다른 창에서 마우스와 키보드를 사용할 수 있도록 입력 감시를 분리했습니다.

Windows 통합 인증으로 완료되지 않는 로그인은 안내의 **사이트 로그인**에서 마친 뒤 책갈피를 다시 실행하세요. 자세한 조건은 [Office URL 지원 안내](office-url-support.ko.md)를 참고하세요.

## 다른 문서와 데이터

- Excel은 시트 이름·단일 셀 주소, Word는 본문 문자 위치, PowerPoint는 SlideID를 사용합니다. 문서 편집 후 같은 의미의 내용까지 추적하지는 않습니다.
- 메모장은 새 문서·미저장 본문과 선택 위치를 자동 보관하며 재개할 때 별도 복원본을 엽니다.
- 탐색기는 실제 폴더 또는 단일 선택 항목을 지원합니다. 홈·검색·휴지통·ZIP 내부·다중 선택은 제외합니다.
- 실행 파일·스크립트·바로가기 등은 직접 실행하지 않고 폴더에서 위치를 표시합니다.
- 보호된 보기·DRM·상승 권한·접근 권한 등은 앱이 우회하지 않습니다.

데이터는 `%LOCALAPPDATA%\WorkBookmark`의 `bookmarks.db`, `settings.json`, 진단 로그에 보관합니다. MSI 제거 후에도 남아 재설치하면 계속 사용할 수 있습니다. 기록까지 지우려는 경우에만 사용자가 이 폴더를 별도로 삭제합니다.

0.2.0에서 갱신된 DB는 0.1.7에서 열 수 없습니다. 변경 전 자동 백업이 남으며, 구버전 복귀가 필요하면 [백업·업데이트 안내](user-manual.ko.md#maintenance)를 먼저 확인하세요.

0.2.2도 같은 DB v5를 사용합니다. 0.2.0·0.2.1에서 업데이트할 때 새 데이터 형식 이전은 추가하지 않습니다.

MSI는 제어판 ‘프로그램 제거’ 또는 Windows ‘설치된 앱’에서 **WorkBookmark → 제거**를 사용합니다. 포터블 ZIP은 자동 실행을 끄고 트레이에서 종료한 뒤 압축 해제한 폴더를 삭제합니다.

실제 AD 로그인·재부팅·환경별 Office/브라우저 확인 범위는 [호환성표](compatibility.md)에 정리했습니다.
