# 업무 책갈피 빠른 시작 · 0.2.20

설치 파일 선택부터 백업·복원과 문제 해결까지는 **[설치 및 사용 매뉴얼](user-manual.ko.md)**을 참고하세요.

Windows에 설치하려면 **[0.2.20 MSI 다운로드](https://github.com/prozac0401/BookMark/releases/download/v0.2.20/WorkBookmark-0.2.20-win-x64.msi)**를 선택하세요. 포터블 ZIP과 나머지 배포 파일, 전체 자동검사·패키지 검사·게시 자산 대조 결과는 [0.2.20 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.20)에서 확인합니다. 변경 내용과 실기 범위는 [릴리스 안내](release-notes-v0.2.20.md)를 참고하세요.

**0.2.20은 하위 항목을 개별 둥근 카드로 정렬합니다.** 카드 사이와 모서리 바깥은 배경이 보이며, 정렬과 스크롤은 공통 영역에서 처리합니다. 최상위 스티커를 움직이면 트리 전체가 따라오며, 자식은 순서·소속을 바꾸는 방식으로 옮깁니다. 폴더를 펼치거나 편집해도 주변 스티커를 밀지 않습니다. 한글 자동저장과 서로 다른 화면 배율의 이동을 보완했고, 마지막 변경 되돌리기 범위를 넓혔습니다. **기존 DB는 백업 후 v9로 이전하며 0.2.19로 복귀하려면 이전 전 백업이 필요합니다.** 패키지는 서명되지 않았습니다.

Whale 지원은 0.2.8부터 유지합니다. 0.2.8은 기존 바이너리로 정식 채널에 전환했고, 사용자가 실제 Whale 저장·재열기의 정상 동작을 확인했습니다(USER_CONFIRMED). 정확한 Windows·Whale build와 원시 로그가 있는 통제 시험은 아니므로 모든 환경 검증으로 확대하지 않습니다. [0.2.8 정식 전환 기록](stable-release-20261005.md)을 참고하세요.

**0.2.3 이하를 사용자 지정 경로에 설치했다면 기존 MSI와 원래 INSTALLFOLDER를 지정해 먼저 제거한 뒤 새로 설치하세요.** 기본 경로의 일반 업데이트는 이전 릴리스에서 확인했습니다. 이번 릴리스의 검증 범위는 위 릴리스 안내를 참고하세요. [설치 경로 이행 안내](windows-installer.ko.md)를 먼저 확인하세요.

1. **0.2.14-test.2 등 포터블 시험판이 실행 중이면 트레이 → 종료로 먼저 완전히 종료한 뒤**, 받은 `WorkBookmark-0.2.20-win-x64.msi`를 실행합니다. 이전 MSI 설치는 자동 제거하고 새 버전을 설치하며, 책갈피와 설정은 유지합니다. 첫 실행에서 기존 DB를 백업한 뒤 v9로 이전합니다. 완료 화면의 **업무 책갈피 실행**을 선택한 채 마치면 바로 실행됩니다. 나중에 실행하려면 체크를 해제하세요.
2. 탐색기·Excel·Word·PowerPoint·메모장 또는 Edge·Chrome·네이버 Whale에서 **Ctrl+Alt+B**를 눌러 현재 위치를 저장합니다. ‘책갈피를 남겼습니다’는 로컬 DB 저장이 완료됐다는 뜻입니다.
3. 새 설치는 **스티커 모드**입니다. 0.2.5에서 선택한 목록/스티커 모드는 이번 업데이트에도 유지합니다. 보이는 스티커의 **왼쪽 청록색 이동 버튼**으로 돌아갑니다. 모두 숨겨져 있으면 **Ctrl+Alt+J**로 표시하고, 일부만 숨겼다면 **트레이 → 책갈피 보기**로 전체를 표시하세요. 목록을 원하면 **트레이 → 설정 → 목록으로 보기 → 적용**을 선택하고 **Ctrl+Alt+J → 항목 선택 → Enter**를 사용하세요.
4. 저장 알림의 **메모**, 목록 항목 우클릭, 또는 **스티커 제목 더블클릭**으로 한 줄 메모를 남깁니다. 제목을 한 번 클릭해 선택한 뒤 **F2 / Ctrl+E**를 눌러도 됩니다. 메모가 없어서 URL·주소·파일명이 보일 때도 같은 방식으로 편집합니다. 같은 위치를 다시 저장해도 메모는 유지됩니다.
5. 트레이의 **설정**에서 표시 방식, 단축키와 Windows 로그인 시 실행 여부를 변경하고 **적용**으로 저장합니다. **닫기 / Esc**는 미적용 변경을 버리고 닫습니다. 최초 설치에서는 로그인 자동 실행이 켜져 있으며, 기존에 껐다면 그 선택을 유지합니다. 트레이 **종료**는 현재 실행만 끝냅니다.

## 포스트잇으로 사용하기

스티커 모드에서는 최상위 책갈피가 작은 창으로 나타나고, 펼친 폴더의 하위 항목은 같은 패널 안의 둥근 카드로 표시됩니다. 최상위 스티커를 **루트**라고 부릅니다. 일반 책갈피는 **메모가 있으면 메모를 제목으로**, 없으면 웹 URL·디스크 폴더 주소·파일명을 표시합니다. 메모장 보관본은 메모가 없을 때 기존 보관 제목을 사용합니다. 책갈피 폴더는 폴더 이름을 표시합니다. 제목은 한 줄이며 긴 내용은 말줄임표로 줄입니다. 전체 메모·대상 정보는 툴팁과 기존 복사 메뉴로 확인합니다.

**Ctrl+Alt+J**는 스티커가 하나라도 보이면 **모두 숨기고**, 모두 숨겨져 있으면 **모두 표시**합니다. 일부만 숨겼다면 첫 입력으로 나머지도 숨기고, 다시 누르면 전체를 표시합니다. 설정에서 **책갈피 보기** 단축키를 바꿨다면 바꾼 키를 사용하세요. **트레이 → 책갈피 보기**와 트레이 아이콘 더블클릭은 항상 전체 스티커를 표시합니다. 목록 모드에서는 단축키로 목록을 엽니다.

스티커 모드로 실행하면 단축키를 누르기 전부터 스티커가 나타나며, 다른 일반 창 위에 계속 표시됩니다. 일반 책갈피의 청록색 버튼은 **북마크 위치로 이동**하며, 누른 스티커에만 처리 중 상태를 표시합니다. 폴더의 남보라색 버튼은 **자식 스티커 펼치기/접기**입니다. 폴더가 닫혀 있으면 오른쪽 방향 표시, 펼쳐져 있으면 아래쪽 방향 표시가 나타납니다. 폴더 제목 옆의 숫자는 자식 수입니다. 버튼에 마우스를 올리면 동작 설명을 확인할 수 있습니다. 평상시에는 왼쪽 28×28 버튼과 제목 한 줄을 표시하며, 버튼의 8-DIP 곡률은 Windows 11 스티커와 같습니다. 아이콘과 둥근 배경은 고해상도로 그린 뒤 축소해 매끄럽게 표시합니다. 스티커의 네모난 실선 테두리는 표시하지 않습니다. Windows 제목줄·종류 아이콘·접기·지우기 버튼은 없으며 다른 기능은 우클릭 메뉴에서 사용합니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 선택 | 제목을 한 번 클릭 |
| 트리 전체 이동 | 루트 제목이나 배경 여백을 누른 채 일정 거리 이상 끌기 |
| 자식 순서·소속 변경 | 자식을 끌어 삽입선·폴더 안으로 이동·새 폴더로 묶기 안내에 놓기 |
| 트리 폭 조절 | 루트의 손잡이 또는 창 가장자리에서 폭 조절. 루트 높이는 한 줄, 자식 폭은 패널 규칙을 따름 |
| 자석 정렬 | 루트를 다른 트리 가까이 끌면 가장자리를 맞춤. **Alt**는 루트의 자석·묶기를 끄고 자식 드래그는 취소. **설정 → 스티커 자석 정렬**에서 끄기 가능 |
| 북마크 위치로 이동 | 왼쪽 **청록색 프레임·바깥 화살표 버튼** 클릭 |
| 자식 스티커 펼치기·접기 | 왼쪽 **남보라색 폴더·방향 표시 버튼 / Ctrl+Enter** |
| 다른 창 위에 두기 | 스티커 모드에서는 항상 위에 표시하며 고정·해제 조작 없음 |
| 메모·폴더 이름 편집 | **제목 더블클릭 / F2 / Ctrl+E**. 해당 스티커 안에서 입력한 뒤 **다른 창으로 이동하면 자동 저장**. **Enter**로 바로 저장, 저장 전 취소는 **취소 / Esc** |
| 한 트리 잠시 숨기기 | 편집 중이 아닐 때 우클릭 **이 트리 숨기기** 또는 **Esc**. 선택한 항목이 속한 트리 전체를 숨김 |
| 전체 스티커 숨기기 | 스티커가 보일 때 **Ctrl+Alt+J** 또는 **트레이 → 스티커 모두 숨기기** |
| 숨긴 스티커 다시 표시 | 모두 숨겨져 있으면 **Ctrl+Alt+J**. 일부만 숨겼어도 전체를 바로 표시하려면 **트레이 → 책갈피 보기** 또는 트레이 아이콘 더블클릭 |
| 흩어진 위치 정리 | **트레이 → 스티커 위치 모으기 → 격자로 / 가로로 / 세로로 정렬** |
| 검색하기 | **트레이 → 목록에서 찾기** |
| 마지막 변경 되돌리기 | 편집을 마친 뒤 **Ctrl+Z / 마지막 변경 되돌리기** |

자석 정렬은 기본으로 켜져 있습니다. 100% 배율 기준 **12픽셀 이내**에서 주변 트리의 가장자리에 붙고, 나란히 놓을 때는 **8픽셀 간격**을 둡니다. 화면 배율에 따라 함께 조절됩니다. 자석에 붙은 상태에서도 마우스를 계속 움직이면 붙는 범위에서 빠져나옵니다. **관계를 바꾸지 않고 루트를 다른 트리 위에 겹쳐 놓으려면 Alt를 누른 채 이동하세요.** 일괄 정렬은 마우스가 있는 모니터에 숨긴 트리까지 표시하고 루트들의 위치를 저장합니다. 폴더 내부 순서는 바꾸지 않습니다.

### 관련 책갈피를 트리로 묶기

스티커 B의 **제목이나 배경 여백**을 A 위로 끌고, 표시되는 안내를 확인한 뒤 놓습니다. **행 사이 삽입선**은 그 자리로 순서·소속 변경, **폴더 가운데**는 안으로 넣기, **일반 항목 가운데의 묶기 영역**은 A와 B를 담는 새 폴더 생성입니다. B는 스티커나 폴더 어느 쪽이어도 됩니다. 폴더에는 링크가 없습니다. Shift는 필요 없으며 자기 자신이나 자신의 하위 항목으로는 옮길 수 없습니다. **Esc**로 드래그를 취소할 수 있습니다.

목록에서도 같은 관계·순서 규칙으로 드래그합니다. 스티커 폴더는 **왼쪽 버튼 / Ctrl+Enter**, 목록 폴더는 **클릭 / Enter / 왼쪽 표시**로 열고 닫습니다. **묶기로 만든 폴더는 펼친 상태**로 대상이 있던 자리에 나타나며, 대상 다음에 끌어온 항목을 둡니다. 트레이·목록의 **새 폴더**로 만든 빈 폴더는 닫힌 상태입니다. 기존 폴더 안으로 넣을 때는 그 폴더의 열림 상태를 유지합니다. 중첩 폴더도 각각 열고 닫으며 상태가 저장됩니다. 검색은 닫힌 폴더 안까지 수행하고 상위 경로도 표시합니다. 스티커의 폴더 이름은 **제목 더블클릭 / F2 / Ctrl+E**, 목록에서는 우클릭 **폴더 이름 바꾸기**로 편집합니다.

**폴더를 펼치거나 메모를 편집해도 루트와 주변 트리를 밀지 않습니다.** 자식은 저장 순서대로 공통 영역에 배치하며, 개별 둥근 카드로 표시합니다. 길어지면 함께 스크롤하고 접힌 자식은 공간을 차지하지 않습니다. 실제 카드와 스크롤바만 뒤를 가리며, 카드 사이와 둥근 모서리 바깥은 배경이 보이고 클릭·드롭도 그 뒤의 보이는 대상을 따릅니다. 표시 공간 부족 안내가 나오면 루트를 화면 안쪽으로 옮기세요. 서로 다른 배율의 모니터로 옮길 때는 도착 화면에 맞춘 루트·패널 배치를 미리 보여주며 놓은 뒤에도 그 배치를 유지합니다.

자식을 **빈 바탕화면**에 놓거나 우클릭 **최상위로 꺼내기**로 부모에서 분리합니다. 카드 사이의 투명한 여백은 그 뒤에 보이는 대상에 따라 처리하므로 놓기 전 드래그 안내를 확인하세요. 목록의 빈 영역에 놓으면 최상위로 옮깁니다. 하위 항목이 있는 폴더를 옮겨도 그 아래 관계는 유지합니다. 부모를 삭제해도 자식은 삭제되지 않으며, 부모를 복원하면 기존 관계가 돌아옵니다.

수동으로 정한 형제 순서는 다시 캡처하거나 메모를 편집해도 유지됩니다. 폴더 우클릭의 **원본 이름순 정렬 / 최근 저장순 정렬**은 한 번만 적용합니다. 원본 이름순은 메모로 바꾼 스티커 제목이 아니라 원래 책갈피 이름을 기준으로 합니다.

검색 중에는 일치 항목의 상위 경로를 임시로 펼칩니다. 검색 중의 펼침 조작은 저장하지 않으며, 검색어를 지우면 저장된 폴더 열림 상태로 돌아갑니다. 다른 앱으로 이동하면 목록은 기존처럼 숨겨집니다.

목록에서 항목을 끄는 동안에는 검색 결과가 갱신되어도 표시된 행을 유지합니다. 위·아래 가장자리에 잠시 머무르면 일정한 속도로 한 행씩 스크롤하며, 가운데로 돌아오면 멈춥니다. 드래그를 마치거나 취소하면 보류한 갱신을 반영합니다.

**우클릭 → 색상**에서 기본·노랑·초록·파랑·분홍·보라·회색 중 하나를 선택합니다. 항목별로 색상을 정할 수 있으며 스티커와 목록에 함께 반영됩니다. **기본**으로 원래 색상으로 되돌립니다. 부모와 자식의 색상은 각각 유지됩니다.

0.2.20은 관계·열림 상태와 형제 순서를 **DB v9**에 저장합니다. 기존 DB는 이전 전 `.bak` 백업을 남기며, **0.2.19로 돌아가려면 이전 전 백업을 복원해야 합니다.** 자세한 절차는 [백업·업데이트 안내](user-manual.ko.md#maintenance)를 참고하세요.

루트의 기본 내용 영역은 100% 배율 기준 **260×36**, 최소 **240×36**입니다. 위치·폭은 조절할 수 있고 높이는 한 줄 헤더로 표시합니다. 자식의 위치는 공통 배치 규칙으로 정하며, 폭은 루트의 보이는 카드 폭에 맞춥니다. 기존 루트 위치·폭과 선택한 표시 모드는 유지하며 과거 높이를 포함한 배치는 이전 전 백업에 남습니다. 목록을 원하면 **설정 → 목록으로 보기 → 적용**을 선택하세요.

**루트의 메모·폴더 이름은 기존 한 줄 헤더 안에서 편집합니다.** 자식은 패널 안의 해당 행만 100% 배율 기준 **96픽셀**로 늘리고, 필요한 경우 입력칸까지 스크롤합니다. 저장·취소 후 행 높이를 되돌리며 루트 위치와 주변 트리는 유지합니다. 저장 실패 시 초안과 편집 영역을 유지합니다. 접기·숨기기·삭제·구조 이동·종료 전에 편집을 저장하며, 실패하면 해당 작업을 중단합니다.

스티커 메모는 **한 줄, 최대 500자**, 폴더 이름은 **최대 100자**입니다. 폴더 이름은 비워 둘 수 없습니다. **저장 버튼은 표시하지 않습니다.** 한글 조합 중 첫 Enter는 글자를 확정하고 다음 Enter가 저장합니다. 다른 창이나 형제 항목으로 이동할 때도 최종 조합 결과가 반영된 뒤 자동저장하며, 이동한 창에서 계속 작업할 수 있습니다. 저장하지 못하면 입력한 글과 오류 안내가 남습니다. 스티커로 돌아와 **Enter**를 누르거나 다른 창으로 다시 이동해 재시도하세요. 스티커 모드에서 잠시 목록을 열어 메모를 선택해도 해당 스티커에서 입력합니다. **목록 모드에서 여는 별도 메모 창**은 기존처럼 밖을 클릭해도 저장합니다.

**스티커 우클릭 메뉴의 지우기 = 목록에서도 같은 책갈피 지우기**입니다. 원본 파일은 유지됩니다. 편집을 마친 뒤 **Ctrl+Z / 마지막 변경 되돌리기**는 현재 실행 세션에서 완료한 생성·재캡처, 내용·색상·경로, 묶기·소속·순서·정렬, 루트 배치·폭, 삭제·복원을 역순으로 되돌립니다. 알림이 사라져도 이력은 남습니다. 펼침·숨김·스크롤·앞뒤 순서는 제외하며, 편집기 안의 Ctrl+Z는 글자 편집만 되돌립니다.

앱을 다시 실행하면 실행 취소 이력은 초기화됩니다. 삭제 항목은 **트레이 → 최근 삭제… → 항목 선택 → 선택한 책갈피 복원**에서 최근 100개까지 찾을 수 있습니다. **숨기기 메뉴 / Esc는 선택 항목이 속한 트리 전체를 숨기며 책갈피를 지우지 않습니다.** 메모 편집 중 **Esc**는 편집을 먼저 취소합니다.

## 웹페이지

Edge·Chrome·네이버 Whale의 일반 HTTP/HTTPS 페이지 본문을 선택하고 **Ctrl+Alt+B**를 누릅니다. 브라우저 확장 프로그램은 필요하지 않습니다. 주소 표시줄을 편집 중이면 먼저 편집을 마치세요. 사용자가 Whale 저장·재열기의 정상 동작을 확인했습니다. 환경에 따라 자동 확인이 어려우면 아래 URL 직접 입력을 사용하세요.

전체 화면·앱 모드·분할 탭·접근성 제한 등으로 주소를 정확히 읽지 못하면 **트레이 → 웹페이지 URL로 추가…**에서 전체 URL과 선택 제목을 입력합니다. 어느 브라우저의 주소든 이 방식으로 저장할 수 있습니다. 기존 Edge·Chrome용 브라우저 확장은 선택적으로 계속 사용할 수 있습니다. Whale 확장의 Native Messaging 연결 등록은 이번 지원에 포함하지 않습니다.

제목과 URL의 query·fragment를 저장합니다. 페이지 본문, 스크롤, 입력 내용, 로그인 상태는 저장하지 않습니다. 재개는 Windows 기본 브라우저에서 진행하며 사이트 인증이 필요할 수 있습니다.

## 웹 URL의 Office 문서

데스크톱 Office에서 문서를 열고 셀·본문 위치·슬라이드를 저장합니다. 닫힌 문서 재개는 해당 Office 앱에 전달합니다. 문서가 준비되지 않으면 사이트 루트에 한 번 내부 접속하고, 문서가 아직 열려 있지 않음을 확인한 경우 한 번 더 열기를 요청합니다. 전체 확인은 최대 45초입니다.

로그인이나 편집을 위해 새로 클릭·입력하면 관찰은 계속하지만 이후 위치 이동과 재열기는 중단합니다. 문서만 열린 경우 별도 알림을 표시하지 않습니다. 저장 위치까지 복원한 경우에만 ‘기록한 위치로 이동했습니다’를 표시합니다.

문서 열기를 요청한 뒤 다른 창을 클릭해도 최초 열기와 열림 확인은 계속합니다. 반복되던 ‘처리 결과를 확인하지 못했습니다’ 알림은 표시하지 않습니다. 45초는 최대 확인 시간이며, 기다리는 동안 다른 창에서 마우스와 키보드를 사용할 수 있도록 입력 감시를 분리했습니다.

Windows 통합 인증으로 완료되지 않는 로그인은 안내의 **사이트 로그인**에서 마친 뒤 책갈피를 다시 실행하세요. 자세한 조건은 [Office URL 지원 안내](office-url-support.ko.md)를 참고하세요.

## 다른 문서와 데이터

- Excel은 시트 이름·단일 셀 주소, Word는 본문 문자 위치, PowerPoint는 SlideID를 사용합니다. 문서 편집 후 같은 의미의 내용까지 추적하지는 않습니다.
- 메모장은 새 문서·미저장 본문과 선택 위치를 자동 보관하며 재개할 때 별도 복원본을 엽니다.
- 탐색기는 실제 폴더 또는 단일 선택 항목을 지원합니다. 홈·검색·휴지통·ZIP 내부·다중 선택은 제외합니다.
- 실행 파일·스크립트·바로가기 등은 직접 실행하지 않고 폴더에서 위치를 표시합니다.
- 보호된 보기·DRM·상승 권한·접근 권한 등은 앱이 우회하지 않습니다.

데이터는 `%LOCALAPPDATA%\WorkBookmark`의 `bookmarks.db`, `settings.json`, 진단 로그에 보관합니다. MSI 제거 후에도 남아 재설치하면 계속 사용할 수 있습니다. 기록까지 지우려는 경우에만 사용자가 이 폴더를 별도로 삭제합니다.

**0.2.20은 기존 DB를 처음 열 때 v9로 이전합니다.** 0.2.12~0.2.19의 v8 DB도 이전 대상이며, 먼저 `bookmarks.db.pre-migration-….bak`을 남깁니다. 책갈피·메모·관계·색상·열림 상태와 기존 배치 기록을 보존하고, 새 화면에서는 자식 좌표를 공통 패널이 정합니다. 기존 설정·보기 모드와 루트 위치·폭은 유지합니다.

**0.2.19는 v9 DB를 읽을 수 없으므로 이전 전 백업 없이는 복귀할 수 없습니다.** 복귀하려면 앱을 종료하고 현재 데이터 폴더를 별도로 보존한 뒤 백업의 복사본을 복원해야 합니다. 백업 이후 추가·수정한 기록은 복원본에 포함되지 않습니다. [백업·업데이트 안내](user-manual.ko.md#maintenance)를 먼저 확인하세요. 사용자 지정 MSI 설치 경로 보존 동작은 유지합니다.

MSI는 제어판 ‘프로그램 제거’ 또는 Windows ‘설치된 앱’에서 **WorkBookmark → 제거**를 사용합니다. 포터블 ZIP은 자동 실행을 끄고 트레이에서 종료한 뒤 압축 해제한 폴더를 삭제합니다.

실제 AD 로그인·재부팅·환경별 Office/브라우저 확인 범위는 [호환성표](compatibility.md)에 정리했습니다.
