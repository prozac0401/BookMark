# 업무 책갈피 빠른 시작 · 0.1.5

1. `WorkBookmark-0.1.5-win-x64.msi`를 실행합니다. 현재 사용자에게 설치되며, Windows에 다시 로그인해도 자동으로 실행됩니다. 기존 포터블 앱은 트레이에서 종료하세요.
2. 탐색기·Excel·Word·PowerPoint·메모장 또는 Edge·Chrome에서 **Ctrl+Alt+B**를 눌러 현재 위치를 저장합니다. ‘책갈피를 남겼습니다’는 로컬 DB 저장이 완료됐다는 뜻입니다.
3. **Ctrl+Alt+J → 항목 선택 → Enter**로 돌아갑니다. 이름·경로·시트·메모를 검색할 수 있습니다.
4. 저장 알림의 ‘메모’ 또는 목록의 항목 우클릭으로 한 줄 메모를 남깁니다. 같은 위치를 다시 저장해도 메모는 유지됩니다.
5. 트레이의 ‘설정’에서 단축키와 Windows 로그인 시 실행 여부를 변경합니다. 트레이 ‘종료’는 현재 실행만 끝냅니다.

## 웹페이지

Edge·Chrome의 일반 HTTP/HTTPS 페이지 본문을 선택하고 **Ctrl+Alt+B**를 누릅니다. 브라우저 확장 프로그램은 필요하지 않습니다. 주소 표시줄을 편집 중이면 먼저 편집을 마치세요.

전체 화면·앱 모드·분할 탭·접근성 제한 등으로 주소를 정확히 읽지 못하면 **트레이 → 웹페이지 URL로 추가…**에서 전체 URL과 선택 제목을 입력합니다. 어느 브라우저의 주소든 이 방식으로 저장할 수 있습니다. 기존 브라우저 확장은 선택적으로 계속 사용할 수 있습니다.

제목과 URL의 query·fragment를 저장합니다. 페이지 본문, 스크롤, 입력 내용, 로그인 상태는 저장하지 않습니다. 재개는 Windows 기본 브라우저에서 진행하며 사이트 인증이 필요할 수 있습니다.

## 웹 URL의 Office 문서

데스크톱 Office에서 문서를 열고 셀·본문 위치·슬라이드를 저장합니다. 닫힌 문서 재개는 해당 Office 앱에 전달합니다. 문서가 준비되지 않으면 사이트 루트에 한 번 내부 접속하고, 문서가 아직 열려 있지 않음을 확인한 경우 한 번 더 열기를 요청합니다. 전체 확인은 최대 45초입니다.

로그인이나 편집을 위해 새로 클릭·입력하면 관찰은 계속하지만 이후 위치 이동과 재열기는 중단합니다. 실제로 문서가 확인되면 문서가 열렸다고 안내합니다. 저장 위치까지 복원한 경우에만 ‘기록한 위치로 이동했습니다’를 표시합니다.

Windows 통합 인증으로 완료되지 않는 로그인은 안내의 **사이트 로그인**에서 마친 뒤 책갈피를 다시 실행하세요. 자세한 조건은 [Office URL 지원 안내](office-url-support.ko.md)를 참고하세요.

## 다른 문서와 데이터

- Excel은 시트 이름·단일 셀 주소, Word는 본문 문자 위치, PowerPoint는 SlideID를 사용합니다. 문서 편집 후 같은 의미의 내용까지 추적하지는 않습니다.
- 메모장은 새 문서·미저장 본문과 선택 위치를 자동 보관하며 재개할 때 별도 복원본을 엽니다.
- 탐색기는 실제 폴더 또는 단일 선택 항목을 지원합니다. 홈·검색·휴지통·ZIP 내부·다중 선택은 제외합니다.
- 실행 파일·스크립트·바로가기 등은 직접 실행하지 않고 폴더에서 위치를 표시합니다.
- 보호된 보기·DRM·상승 권한·접근 권한 등은 앱이 우회하지 않습니다.

데이터는 `%LOCALAPPDATA%\WorkBookmark`의 `bookmarks.db`, `settings.json`, 진단 로그에 보관합니다. MSI 제거 후에도 남아 재설치하면 계속 사용할 수 있습니다. 기록까지 지우려는 경우에만 사용자가 이 폴더를 별도로 삭제합니다.

MSI는 제어판 ‘프로그램 제거’ 또는 Windows ‘설치된 앱’에서 **WorkBookmark → 제거**를 사용합니다. 포터블 ZIP은 자동 실행을 끄고 트레이에서 종료한 뒤 압축 해제한 폴더를 삭제합니다.

현재 배포는 시험판이며 실제 AD 로그인·재부팅·환경별 Office/브라우저 수용시험은 별도로 확인해야 합니다.
