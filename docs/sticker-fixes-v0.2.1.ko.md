## 수정하는 불편

사용자는 이어가기를 누르면 모든 스티커 버튼이 함께 바뀌고, 단축키를 누르기 전에는 스티커를 찾기 어려우며, 스티커에서 시작한 메모를 화면 오른쪽 아래의 별도 창에서 입력해야 한다고 보고했습니다. 파일 종류를 쉽게 구분할 아이콘도 요청했습니다. 이후 **포스트잇 모드에서는 최상단에 표시**하는 동작을 명확히 요청했습니다.

아래 동작은 로컬 0.2.1 수정 후보에 적용하는 계약입니다. [0.2.0 릴리스 노트](release-notes-v0.2.0.md)와 [최초 스티커 검토](sticker-feasibility.ko.md)는 당시 동작과 검토 이력으로 보존합니다.

## 표시와 조작

**트레이 → 설정 → 포스트잇 스티커로 보기 → 적용**을 선택합니다. 기존 기본값인 **목록으로 보기**는 유지합니다. 스티커 모드를 선택한 경우 다음 실행부터 스티커가 자동으로 표시됩니다.

모든 스티커가 항상 위에 표시되므로 **고정 / 고정됨** 버튼, 고정 메뉴와 **Ctrl+Shift+T** 고정·해제 조작은 제거합니다. 기존 배치에 고정 해제가 저장돼 있어도 항상 위에 표시합니다. 위치·크기·접기 상태는 계속 복원합니다. Windows의 보안 화면, 전체 화면 앱이나 모든 가상 데스크톱에서의 표시까지 보장하는 계약은 아닙니다.

**× / Esc**로 한 스티커를 잠시 숨기고 **스티커 모두 숨기기**로 전체를 숨길 수 있습니다. 전체를 숨긴 동안 새로 저장해도 숨김을 유지합니다. **Ctrl+Alt+J** 또는 **트레이 → 책갈피 보기**로 다시 표시합니다. 이 동작은 책갈피를 삭제하지 않습니다. 메모 편집 중 **Esc**는 편집 취소를 먼저 처리합니다.

스티커 자동 표시와 **이어가기**는 별개입니다. 표시하거나 다시 불러오는 것만으로 원본 문서를 열거나 재개 이력을 남기지 않습니다. 진행 표시를 항목별로 바꾸더라도 외부 작업은 기존처럼 **동시에 하나, 요청마다 worker 하나**만 실행합니다.

## 같은 스티커에서 메모하기

1. 원하는 스티커의 **메모 추가 / 메모 편집**을 누릅니다.
2. 그 스티커에 나타난 입력칸에 **한 줄, 최대 500자**로 적습니다.
3. **저장 / Enter**로 저장하거나 **취소 / Esc**로 현재 편집을 취소합니다.

다른 창을 클릭해도 스티커 메모를 자동 저장하지 않습니다. 저장 실패 시 입력을 유지하고 재시도할 수 있게 안내합니다. 한글 조합 중 Enter는 조합 확정만 처리합니다. 편집 중의 글자 삭제·되돌리기를 책갈피 삭제·복원으로 처리하지 않습니다. 같은 책갈피가 갱신돼도 입력 중인 글을 덮어쓰지 않아야 합니다.

**목록 모드에서 여는 별도 메모 창**은 계속 사용하며, 기존처럼 창 밖을 클릭해도 저장합니다. 스티커 모드를 선택한 상태라면 저장 알림이나 임시 검색 목록에서 메모를 요청해도 해당 스티커에서 입력합니다. 이 차이를 [매뉴얼](user-manual.ko.md#manage)과 [빠른 시작](quick-start.ko.md)에 표시합니다.

## 아이콘과 데이터 경계

파일 종류 아이콘은 저장된 대상 종류·확장자와 Windows의 아이콘 정보를 사용해 비동기로 가져옵니다. 아이콘을 얻기 위해 실제 업무 파일을 열거나 내용을 읽지 않습니다. 조회 중이거나 아이콘 정보를 얻지 못한 경우에도 기본 아이콘으로 스티커를 사용할 수 있어야 합니다. 파일 종류가 바뀌거나 창이 닫힌 뒤 도착한 오래된 조회 결과는 적용하지 않습니다.

DB는 기존 **v5**를 유지하며 새 스키마 이전은 추가하지 않습니다. 기존 책갈피·메모·삭제 기록과 스티커 위치·크기·접기를 사용합니다. 개별 고정 해제 값은 현재 표시 정책에 적용하지 않습니다. 0.1.7은 v5 DB를 읽을 수 없으므로 [백업·구버전 복귀 안내](user-manual.ko.md#maintenance)는 계속 적용됩니다.

새로 빌드한 Core·Integration·WindowsChecks 검사 실행 파일의 첫 실행에서 접근 거부가 발생했습니다. 같은 출력과 명령을 변경하지 않고 다시 실행했을 때 정상 완료됐습니다. 원인은 확인하지 못했으며, 보안 설정을 변경하지 않았습니다.

MSI·ZIP·소스 스냅샷·해시·최종 패키지 검증 JSON은 `artifacts/releases/20260922-083744-111/`에 있습니다. 패키지 안의 문서는 제작 직전 기록이며, 완료 후 확인한 54개 결과는 함께 제공하는 `WorkBookmark-0.2.1-win-x64.validation.json`에 기록돼 있습니다. 저장소의 새 검증 자료에는 요약과 합성 화면만 포함하고 사용자 기록이나 로컬 진단 로그는 복사하지 않습니다. 실제 설치·업데이트·제거·재부팅과 공개 배포는 미실행입니다.
