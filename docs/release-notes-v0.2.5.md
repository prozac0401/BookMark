# WorkBookmark 0.2.5 · 구현본, 미배포

메모를 스티커 제목으로 표시하고 기본 폭·높이와 글꼴을 줄입니다. 새 설치와 이번 업데이트 첫 실행은 스티커 모드로 시작합니다.

## 변경 사항

- 메모가 있으면 메모를 제목으로 표시합니다. 별도 파일명·주소·‘다음에 할 일’ 영역을 표시하지 않습니다.
- 메모가 없거나 공백뿐이면 웹 URL, 폴더 주소 또는 파일명을 표시합니다. 전체 내용과 대상 정보는 툴팁·기존 복사 메뉴에서 확인할 수 있습니다.
- 스티커 제목을 클릭하거나 Ctrl+E로 메모를 편집합니다. 다른 창으로 이동할 때 자동 저장, Enter 저장, Esc 취소와 실패 시 초안 보존은 유지합니다.
- 100% 배율 기준 기본 내용 영역은 260×170, 최소 크기는 240×160입니다. 제목은 10.5pt 굵게, 일반/버튼은 9pt, 보조 안내는 8.5pt, 편집 입력은 9.5pt입니다. Windows 제목줄과 테두리는 별도로 더해집니다.
- 이번 버전을 처음 적용할 때 기존 스티커도 작은 기본 크기로 바꾸고 스티커 모드를 선택합니다. 위치·접힘 상태는 유지합니다. 이후 사용자가 변경한 크기와 표시 모드는 다시 실행해도 기억합니다.
- DB는 v5를 유지합니다. 크기 적용 여부는 설정에 기록하며, 저장이 실패하면 완료 처리하지 않고 다음 실행에 재시도합니다.

## 현재 확인 상태

사용자 요청에 따라 **자동 테스트·수동 입력·화면 렌더 검증은 실행하지 않았습니다.** 관련 5개 검사 묶음의 코드를 준비했으며 별도 테스트 요청 후 실행합니다. 제품과 관련 검사 프로젝트의 Release 컴파일은 **경고 0개·오류 0개**로 통과했습니다. 컴파일은 동작 테스트 결과가 아닙니다.

MSI·ZIP 생성 및 공개 배포는 아직 진행하지 않았습니다. 이 문서는 배포 완료 안내가 아닙니다. 배포 시 기존 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·검증 JSON·SHA256SUMS.txt 형식을 사용합니다.

상세 변경 범위와 예정 검증은 [구현·테스트 계획](sticker-note-title-plan.ko.md)을 참고하세요.
