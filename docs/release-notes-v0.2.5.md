# WorkBookmark 0.2.5 · 평가판

메모를 스티커 제목으로 표시하고 기본 폭·높이와 글꼴을 줄입니다. 새 설치와 이번 업데이트 첫 실행은 스티커 모드로 시작합니다. 0.2.4의 사용자 지정 MSI 설치 경로 보존 수정도 포함합니다.

## 변경 사항

- 메모가 있으면 메모를 제목으로 표시합니다. 원래 제목·파일명·주소와 ‘다음에 할 일’ 영역은 기본 화면에서 숨깁니다.
- 메모가 없거나 공백뿐이면 웹/웹 문서는 URL, 폴더는 주소, 파일은 파일명을 표시합니다. 메모장 자동 보관본은 기존 보관 제목을 사용합니다.
- 제목은 최대 두 줄이며 긴 내용은 생략합니다. 전체 메모·대상 정보는 툴팁·편집창·기존 복사 메뉴에서 확인합니다.
- 제목 클릭 또는 **Ctrl+E**로 메모를 편집합니다. 창 전환 자동 저장, Enter 저장, 저장 전 Esc 취소와 실패 시 초안 보존·재시도는 유지합니다.
- 100% 배율 기준 기본 내용 영역은 **260×170**, 최소 **240×160**입니다. 제목 **10.5pt 굵게**, 일반·버튼 **9pt**, 보조 안내 **8.5pt**, 편집 입력 **9.5pt**입니다. Windows 제목줄·테두리는 별도로 더해지며 시스템 배율을 따릅니다.

## 업데이트 후 첫 실행

**기존 스티커 크기와 시작 모드를 처음 한 번 바꿉니다.** 기존에 목록 모드를 선택했어도 스티커로 시작합니다. 이후 사용자가 조절한 크기와 선택한 목록/스티커 모드는 다시 실행해도 유지합니다.

위치·모니터·접힘 상태는 보존하고 펼침 크기를 새 기본값으로 바꿉니다. 삭제된 책갈피의 배치도 바꾸지만 삭제 항목을 화면에 다시 표시하지는 않습니다. 화면 밖 위치는 기존 규칙에 따라 보정합니다. 시작만으로 파일이나 URL을 열지 않으며, 책갈피가 없으면 스티커 창을 만들지 않습니다.

**DB v5**를 유지합니다. 배치 저장이 성공한 뒤 적용 완료를 설정에 기록하고, 저장 실패 시 다음 실행에 재시도합니다. 손상된 설정 원본은 보존합니다. 0.2.3·0.2.4 복귀에 별도 DB 스키마 복원은 필요 없지만 예전 스티커 크기가 자동 복구되지는 않습니다.

## 검증 범위

Release 빌드를 경고 0개·오류 0개로 마쳤고 관련 5개 검사 클래스의 **93개 자동검사**를 통과했습니다. **100% 배율 합성 화면 11개**와 **150% 합성 화면 5개**를 확인했습니다. 150%에서 발견한 두 줄 제목 높이 문제를 수정한 뒤 같은 검사와 화면을 다시 확인한 결과입니다.

| 범위 | 현재 결과 |
|---|---|
| Release 컴파일 | 경고 0개·오류 0개 |
| 관련 자동검사 | 93개 통과: 제목·메모·설정·시작·배치 저장 |
| 100% 합성 화면 | 최종 코드의 11개 화면 확인 |
| 150% 합성 화면 | 최종 코드의 5개 fixture 모두 통과하고 화면 확인. 실제 150% 모니터 검증과 구분 |
| 격리 호스트 실행 | 시작·크기 전환 완료 표식·정상 종료 확인. 종료 코드 0. 최종 화면 보완 전 기록 |
| 실제 마우스 편집·한글 IME·150% Windows 제목줄·테두리·다중 모니터 | 미검증. 합성 검사와 구분 |
| MSI·ZIP와 최종 패키지 검사 | 기존 패키징 한 차례의 결과를 릴리스 첨부 검증 JSON·SourceSnapshot.json·SHA256SUMS.txt로 제공 |

[검사 로그와 화면 기록](evidence/sticker-compact-2026-09-27/README.md)을 참고하세요. 이번 결과는 이전 버전의 자동 600개·설치 수명주기 118개 등과 합산하지 않습니다. 변경하지 않은 Office·브라우저·IPC·캡처와 설치·제거·재부팅 반복 검사는 추가하지 않습니다.

## 다운로드와 검증 파일

[0.2.5 GitHub 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.5)에 기존과 같은 6종을 제공합니다: **WorkBookmark-0.2.5-win-x64.msi**, **WorkBookmark-0.2.5-win-x64.zip**, **Source.zip**, **SourceSnapshot.json**, **WorkBookmark-0.2.5-win-x64.validation.json**, **SHA256SUMS.txt**.

패키지 구조·추출 파일 검사 결과는 릴리스 첨부 [검증 JSON](https://github.com/prozac0401/BookMark/releases/download/v0.2.5/WorkBookmark-0.2.5-win-x64.validation.json), 소스 기준 커밋은 [SourceSnapshot.json](https://github.com/prozac0401/BookMark/releases/download/v0.2.5/SourceSnapshot.json), 배포 파일 해시는 [SHA256SUMS.txt](https://github.com/prozac0401/BookMark/releases/download/v0.2.5/SHA256SUMS.txt)로 제공합니다. MSI 검증 JSON은 UI 동작 검증을 대신하지 않습니다. 패키지는 서명되지 않았습니다.

**0.2.3 이하를 사용자 지정 경로에 설치했다면** 기존 MSI와 원래 INSTALLFOLDER를 지정해 먼저 제거하는 [설치 경로 이행 절차](windows-installer.ko.md)를 따르세요. 0.2.4에서 추가한 실제 설치 경로 보존 동작은 유지합니다. 포터블은 기존 앱을 종료하고 새 ZIP을 폴더 전체로 풀어 실행합니다.
