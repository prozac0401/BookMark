# WorkBookmark 0.2.14-test.2 — 목록 유지·설정 닫기 시험판

Windows x64 포터블 **prerelease**입니다. 정식 안정판은 0.2.13으로 유지합니다. 이전에 별도 전달된 0.2.14-test.1과 구분되는 새 버전입니다.

- 목록에서 폴더를 펼칠 때 스티커 표시가 포커스를 빼앗아 목록이 닫히는 경로를 수정했습니다.
- 설정의 ‘닫기’와 Esc는 미적용 변경을 저장하지 않고 닫힙니다. 적용 성공·실패/재시도 동작은 유지합니다.
- 검색 정책, 목록/스티커 폴더 상태 공유, 데이터 형식은 유지합니다. 다른 앱으로 이동한 뒤 목록을 강제로 활성화하지 않습니다.

## 검증

- **PASS:** Windows Release 빌드, 이번 변경의 집중 구성요소 검사 126개. 설정 닫기/Esc/적용, 검색 해제, 폴더 반복 전개와 DB/스티커 공유, 최초/반복 표시 포커스, 표시 후 편집을 포함합니다.
- **FAIL → 수정:** 원본에서 설정 닫기 및 스티커 표시로 목록이 숨는 구성요소 경로를 재현했습니다. 최종 집중 검사에는 FAIL이 없습니다.
- **NOT RUN:** Windows 잠금 화면으로 실제 마우스·키보드 입력, 다른 앱 Alt+Tab, 전경 목록과 스티커의 실제 창 순서를 확인하지 못했습니다. 전경 조건 검사 6개도 NOT RUN입니다. MSI 설치·업데이트 및 시작프로그램 등록도 실행하지 않았습니다.

자세한 범위와 로그는 [검증 기록](https://github.com/prozac0401/BookMark/blob/v0.2.14-test.2/docs/list-search-settings-close-checks.ko.md)을 참고하세요. 이전 시험 결과를 이번 변경의 통과 근거로 쓰지 않았습니다.

## 내려받아 실행

1. 기존 WorkBookmark를 트레이 메뉴의 **종료**로 완전히 종료합니다.
2. `%LOCALAPPDATA%\WorkBookmark` 폴더 전체를 별도 위치에 복사해 백업합니다. ZIP 포터블도 기존 앱과 이 데이터를 공유합니다. 별도 Windows 테스트 계정이면 별도 프로필을 사용할 수 있습니다. LOCALAPPDATA 환경변수만 바꿔 격리되었다고 가정하지 마세요.
3. `WorkBookmark-0.2.14-test.2-win-x64.zip`을 새 폴더에 모두 압축 해제하고 `WorkBookmark.exe`를 실행합니다. .NET 포함 포터블이며 자동 설치하지 않습니다.
4. ‘목록에서 찾기’에서 폴더 반복 열기/닫기, 검색/검색 해제, 스티커 클릭·메모 편집, 다른 앱 Alt+Tab을 확인합니다. 설정을 바꾼 뒤 닫기/Esc로 폐기되는지, 적용 후 다시 열었을 때만 변경이 남는지 확인합니다.

Source.zip, SourceSnapshot.json, Validation.json, SHA256SUMS.txt를 함께 제공합니다. 이전 버전으로 돌아갈 때는 시험판 종료 후 기존 앱을 실행하세요. 데이터 복원이 필요하면 앱을 모두 종료하고 시험 후 데이터도 별도로 보존한 다음 백업본을 사용하세요.
